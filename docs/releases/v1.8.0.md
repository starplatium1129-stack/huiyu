# 绘遇 HUIYU 1.8.0

本版集中更新创作流程、作品整理和桌面交互：旧作配方可按层沿用，作品可按生成条件检索并自动归入角色／智能画册；默认 Anima 模型迁移到 MiaoMiao 1.6，图片反推接入 GPU 常驻的 PixAI。绘制台、首页、角色档案、作品查看器、视频台与设置同步精修，并补强任务恢复、图片归属和大库响应。

> 发行准备中。以下说明汇总 `v1.7.4` 之后、功能基线 `123afee6` 已合入主线的实现；1.8.0 的最终提交、安装包、签名和 SHA-256 以受控构建及发布结果为准。目前尚未公开发布。

## 创作与生成

- 旧作配方支持完整恢复或选择性沿用画风／光色、镜头／构图、提示词／场景、生成参数；未选条件以及当前角色、服装、引擎和画册继续保留。不兼容或未记录的原作字段明确提示，避免把当前表单冒充原配方。
- 随机灵感保留场景地点、时段与关系；切换角色时可保留参考场景，参考中的颜色继续进入编译。角色身份与通用色彩预设不再自动夹带场景道具或灯光来源。
- 当前创作和维护入口的 Anima 默认统一为 MiaoMiao 1.6；历史配方、明确选择的旧模型与历史重放配置保留原身份。
- 默认反推切换为 PixAI Tagger v1.0。首次加载后复用同一个 GPU 进程，支持最多 20 MiB 图片；取消活跃推理、故障、超时或网关关闭时回收自有进程，显存不足明确报错。
- 图片批次冻结每项参数和任务身份，支持显式继续及已接收任务重连。SD 队列修复直接生成结束后的唤醒和待处理队列持久恢复；未知接收状态不会自动重提。
- 换装准备支持取消和防重入；高清重绘采用原完成任务的配方、实际 Seed 和结果身份。原作资料不足时明确拒绝复用，不补造字段。

## 作品与画册

- 新增角色自动画册，按作品保存的角色信息归组；多人作品可出现在各自角色画册，无身份记录单列为「未标注角色」。
- 新增标签智能画册，组合角色、标签、收藏、搜索和手动画册范围；标签支持全部／任一匹配，规则可创建、编辑、移除，并随作品元数据变化重新计算成员。分类不会搬移或复制图片。
- 图库支持已记录的引擎、模型、角色内服装、精确 Seed、生成尺寸和候选状态组合过滤，常用组合可保存、更新和再次沿用；缺失资料明确显示「未记录」。
- 手动画册支持创建和批量加入／移出，整理标签与生成词条分开保存，并支持条件撤销。
- 候选图支持差异参数查看、同步缩放／移动和键盘操作；关闭后释放自有图片 URL。
- 回收站恢复和确认后的清空操作完善，桌面清理在超时、重连后可恢复协调；图库删除反馈增加有界消散动效。

## 桌面交互

- 绘制台减少顶部和边框占用，保持大画布；侧栏可调宽、显示／复位集中在「布局」入口，配方检查使用独立弹窗，图片工具收进检查面板。成片揭示、边缘反馈和清空动效同步调整。
- 首页补充直接绘制入口、图片加载／失败反馈与重试；参考画册刷新保留当前浏览内容，场景卡片和故事入口的键盘操作、导航取消与焦点恢复更加稳定。
- 角色档案保持肖像／阅读结构稳定，角色卡与档案共享图片过渡；作品查看器工具带与画面分开，缩放和拖动即时响应。
- 视频台与分镜压紧层级并改善较窄桌面窗口操作；任务中心列表内部滚动，关闭和主要操作保持可达。
- 控制台、外观弹窗和确认框完善标签、忙碌状态、连续开关、Tab 循环及取消后的焦点返回；高频工具和键盘反馈遵守减少动态效果偏好。

## 稳定性与性能

- 保存作品和任务结果改为有界读取及增量更新，避免每次入册回读全库；首页最近作品减少请求，媒体清理的候选发现不再长时间阻塞轻量存储操作。
- Rust 媒体反向索引、内部二进制传输、资源单遍核验、首次任务恢复并发、Comfy 轮询退避和大结果有界解码减少重复工作。专项隔离测量见[创作流程与大库优化](../audits/2026-10-01/creator-workflow-optimization.md)和[Rust 性能报告](../audits/2026-09-30/rust-performance-six.md)，不作整应用或真实生成速度承诺。
- 修复任务／结果归属、迟到响应、视频帧与草稿、原图导出、参考读取取消、资源撤销及图库隐藏状态的竞态；WebUI 未知任务提供认证用户明确确认上游停止后的恢复入口。
- 桌面构建绑定实际 Cubism SDK 输入，防止旧载荷和路径漂移；公开发布核验原生材料及审批，核心门禁覆盖 Rust 改动。

## 模型、样张与升级

PixAI 的 Python 3.11+／CUDA PyTorch 环境和权重、MiaoMiao 1.6 生图三件套需要在本机单独准备。程序安装包只包含反推 worker 与固定清单；模型文件存在不等于真实功能已验收。准备方式见[模型开箱指南](../guides/setup-and-models.md)。Anima 加速试验没有升级为生产默认，比较和舍弃依据见[真实对照记录](../audits/2026-10-01/anima-acceleration-comparison.md)。

样张分批发布器修复为只替换本批同 ID，保留其他角色的样张、分级和审核依据。本机已修正 748 条旧图映射，并补回 401 条已有图片的遗漏索引，活跃清单为 2,042 条；这是本机资源核验结果，新增记录未自动写入既有 r1 离线 ZIP，也不代表重新生成或重新审核了图片。资源恢复细节见[索引恢复报告](../audits/2026-10-01/scene-showcase-index-recovery.md)。

本版前端和 Rust／桌面程序均有变化，升级使用完整安装包。已有个人资料和内容目录继续保留；有内容差异时使用[桌面内容同步入口](../desktop-deployment.md#数据改动如何到达桌面端)先备份再同步，不以重装替代内容更新。新机准备见[离线资源指南](../guides/offline-resources.md)。
