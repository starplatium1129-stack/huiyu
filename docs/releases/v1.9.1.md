# 绘遇 HUIYU 1.9.1

本版汇总 1.9.0 之后的更新：把绘制、角色、灵感和作品浏览统一到同一套界面体验，完善本地 AI 准备流程，接入新的 Anima 模型与终末地角色 LoRA，并更新项目介绍和实机截图。

## 新增

- **MiaoMiao Anima 2.9B Beta 1.1**：替换原 Anima 2.9B Preview 选项，使用独立模型与配方身份。已在本机完成权重校验、全年龄样图和 TeaCache 0.08 工作流验证；默认仍为 MiaoMiao 1.6，新 2.9B 暂按无角色 LoRA 路径使用。
- **终末地角色 LoRA**：接入角色合集，按角色和底模匹配训练触发词与默认绑定；不支持的扩层底模或缺少文件时明确提示。
- **首次配置与一键准备**：首次欢迎引导进入控制室，选择数据目录和 AI 工作目录，按组合准备受管 ComfyUI Portable、所需节点、llama.cpp 与 GGUF。下载保留中间进度并核对文件，长调用支持取消与有界等待。
- **本地聊天分档**：提供 Qwen 4B、9B、27B 的不同量化候选；显存较少或尚未确认设备时优先 API。绘图和聊天模型按需加载与释放。

## 优化

- **全站界面统一**：搜索、分段选择、表单、分页、导航和弹层沿用一致材质与手绘线描图标；深浅主题下保留阅读内容和图片本身的清晰度。
- **页面与画册过渡**：减少重复动画和筛选时的大面积变暗，改进角色切换、二级入口、展开内容和页面返回的连续性。
- **作品与场景浏览**：角色场景采用响应式瀑布流；灵感和角色场景复用立体观画、原图缩放及信息栏，方便沿用配方进入绘制。
- **绘制画布反馈**：成片在画布中悬浮展示，生成轨道的线条和粒子更清晰；已有百分比时进度环继续运动，未知进度不伪造数字，减少动态效果偏好继续有效。
- **MiniMax H3 路径**：更新为加速视频 VAE，匹配 Turbo 4／8 步采样与对应 LoRA；设备支持和实际效果仍按本机环境验证。
- **项目介绍**：重写中英文 README，使用项目现有手绘图标，更新首页、绘制、角色、参考画册、作品册和查看器六张实机截图。

## 修复

- 修复场景工具栏在玻璃高光出现时下跳、闪烁和点击失效。
- 修复角色目录与预览中的重复动画、焦点和 Esc 所有权问题，保留弹层键盘操作。
- 等待高清图片解码后再替换缩略图，减少作品切换时的短暂空白。
- 保存作品时保留实际生成的场景和模型信息，避免把后来修改的表单内容写入旧成片。
- 修正部分场景提示词、身份与衣装绑定的一致性；旧作品与原配方事实保留。
- 绘制布局控件按需加载，保持现有页面包体上限；无角色 LoRA 模型使用对应的能力标记。
- 旧用户升级时在内存中补齐缺失的内置模型配方，保留个人目录、自定义模型参数和原有预设，避免新模型出现在列表却无法编译。

## 下载与升级

- **新用户或修复资源**：下载 `AI-CG-Studio_1.9.1_x64-full-setup.exe`。
- **已有完整安装**：下载 `AI-CG-Studio_1.9.1_x64-upgrade-setup.exe`，或使用程序自动更新。安装器会核对保留的基础素材，不匹配时使用完整包。
- 模型权重与完整样张素材继续单独下载。本版沿用 [2026-10-06 完整素材包](https://github.com/starplatium1129-stack/huiyu/releases/tag/huiyu-resources-20261006-r1)，已有完整素材无需重复导入。
- 升级保留个人作品、聊天和设置；已有个人内容目录不会因安装程序而被全量覆盖。

## 验证与边界

本版区分源码功能、定向验证、本机模型样图与发行安装包验证。新 2.9B 的单张样图不代表全角色、所有画风、高清二采或其他设备已验收；其角色 LoRA 兼容性与 TeaCache 提速比例未测。

SD／WAI 新生成已退役，保留历史作品、原配方事实和旧任务查询／取消。语音、视频与聊天需要各自完整模型和运行环境。原生材料与设备待项继续保留在[项目状态](../project-status.md)，更新签名用于核对发行文件完整性。
