# 绘遇 HUIYU 2.2.0

## 新增

- **ChatGPT 订阅与多模型自动回退**：接入 ChatGPT 订阅额度聊天，支持模型缓存、断流重试；当前模型不可用时自动按已保存的 API 密钥依次重试（QQ 渠道同步支持双向回退）。
- **多智能体共享绘图 CLI**：新增 `cli-anything-huiyu`，支持智能体通过统一接口查询模型能力、提交绘图与排查任务状态。
- **QWEN-Manga Turbo INT8**：接入漫画化加速模型并对齐上游流程。
- **聊天、语音与渠道扩展**：整合视频工作台、全员立绘角色档案、QQ 语音回复、Muse 群聊提醒以及精选画师标记与排序。
- **界面与动效升级**：重构绘图工作台、首页画册序章、3D 展墙画廊、故事手帖书架与 Galgame 房间对话框，补充共享弹窗、滑块与骨架屏组件。

## 优化

- **推理与冷启动提速**：Anima、MOSS、Qwen 改为按提示词搬运词表行，Krea Turbo 去噪间隙驻留权重，减少采样与网点重复计算，加快首次启动内容库写入。
- **界面文案收敛**：全面精简控制面板、模型准备、绘图/视频工作台与聊天设置中的冗余说明，改以布局、键值表与按需折叠呈现。
- **桌面体验与部署**：支持直达上次工作页与延迟加载未用 UI，优化桌宠高刷拖动、首页作品切换，并加速 Windows 桌面端本机增量部署。

## 修复

- **ChatGPT 与 QQ 稳定性**：修复进入聊天房间等待模型列表过久与上游偶发超时；修复 QQ WebSocket 半开假在线断联，补充心跳看门狗与错误日志。
- **绘图与界面细节**：修复编译加速、Anima 角色名与画师样张标签格式、桌宠与聊天房间控件悬浮及跨模块类型与样式回归。
- **部署收尾兼容**：修复 Windows PowerShell 5.1 下桌面部署脚本发布日志时的文件替换报错。
