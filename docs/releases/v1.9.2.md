# 绘遇 HUIYU 1.9.2

本版汇总 1.9.1 之后的界面、性能与发行改进，更新手绘插画与应用图标，整理绘制侧栏，改善页面、角色及画册切换。

## 新增与优化

- 更新夏目应用图标、工作台插画，以及画布、画册和未找到页面的空状态插画。
- 绘制侧栏整理为绘制、图像、提示词、任务四组，集中反推、换装、高清与短片入口；常用参数与生成操作更容易找到。
- 统一折叠区、选择控件与焦点反馈，优化角色档案、作品册、参考画册的切换；场景刷新保留已有网格，减少重复挂载和读取。
- 生成等待使用更清晰的局部轨道与连续细线；旧图粒子自身变形成生成轨道，再沿用角度、时间与进度持续运行，不提前叠放另一套动画，保留减少动效设置。
- 改进目录缓存、SQLite 分页、图片与资源读取，减少重复 I/O、JSON 分配及维护校验开销；具体收益依数据与设备而异。
- 程序支持增量离线素材导入，复用已核对的基础文件；素材包继续单独发行，本版程序发布不包含另一次素材包发布。
- 安装与发行校验采用有界读取，减少大文件哈希时的瞬时内存；保持源码、产物、素材和签名核验。

## 修复

- 修复画册切换时过渡首帧被冷加载消耗的问题，减少重复入场动画。
- 下拉选项仅在展开时挂载，降低页面进入与切换开销。
- 修正场景筛选工具栏的间距与圆角，改善控件承载区域。
- 完善 PixAI 本机配置复用及取消、超时处理；桌面文件同步跳过以 SQLite 为权威的个人内容。

## 下载与升级

- 新用户或修复基础资源：下载 `AI-CG-Studio_1.9.2_x64-full-setup.exe`。
- 已有完整安装：下载 `AI-CG-Studio_1.9.2_x64-upgrade-setup.exe`，或使用程序自动更新。保留素材不匹配时请使用完整包。
- 模型权重和完整样张继续独立下载；现有完整素材见 [2026-10-06 素材发行](https://github.com/starplatium1129-stack/huiyu/releases/tag/huiyu-resources-20261006-r1)。
- 安装不覆盖个人作品、聊天、设置及现有内容记录库。

## 验证范围

沿用各工作包已有的定向验证；本次发行重新构建并核对源码、原生载荷、两种安装包和更新签名。公开上传后核对附件大小、摘要及自动更新清单。

未将已有性能样本扩大为所有设备的性能承诺；本次发布不代表完成干净 Windows 安装、全部模型或原生设备验收。原生材料的 `releaseReady=false` 与 pending 状态如实保留，按用户明确授权发布，未改写为已审批。
