# 绘遇 HUIYU 2.3.0

## 新增

- **pi-H3 DWD 2 步加速视频生成**：原生视频推理链路接入 pi-H3 DWD（Distilled World Dynamics）两步加速与 pi-Flow 调度支持，配套前端 H3 配方选项、模型清单与一键下载工作流。
- **视觉反推 API 协同融合与 MOSS 自动布局**：`POST /api/interrogate/raw` 与绘图工作台支持区分自由主体（`free`）与绑定角色（`bound`）反推协同；绑定角色自动剥离原图身份词条并保留姿态、服装与环境描述，无缝注入 Krea 2 与 MOSS 提示词；MOSS 引擎自动识别画布构图并生成标准 `abs_centralized / yxyx` 布局 JSON，切画幅自动重算坐标框且保留手动布局微调。
- **精简安装包与在线资源包按需下载**：安装包默认采用精简档位，首次启动引导与控制室「资源与素材」支持按需下载人物高清立绘包（`portraits`）与场景样张资源库（`showcase`），自动支持断点续传、SHA-256 校验与国内镜像加速。

## 优化

- **单 Release 统一资源目录**：桌面安装包、自动更新索引 `latest.json`、在线资源包索引 `media-packs.json`、立绘/样张压缩包及自训角色 LoRA 统一归集至当前最新版本发行页，所有客户端默认资源与模型下载源统一指向 `releases/latest/download/` 并启用镜像加速。
- **桌面部署与运行体验**：优化本机快速部署输出与提权前构建流程，减少重复打包耗时。
