# 绘遇 HUIYU 1.8.1

本版汇总 1.7.4 之后的创作、画册、桌面交互与稳定性更新，包含此前 1.8.0 的全部功能，以及 10 月 2 日第一至第八轮已合入主线的改动。新增统一安装／卸载界面、可查看进度和取消的程序更新，以及本地离线素材 ZIP 安装助手。

本次功能基线为 `e9adae01`，另纳入 `c1efc3d1` 的离线助手工作流声明修复，在独立工作区重新构建并校验源码绑定；未完成的后续开发不计入本版。版本提升至 1.8.1，已有 1.8.0 客户端可识别更新。

## 创作与生成

- 旧作配方可完整恢复，或选择沿用画风／光色、镜头／构图、提示词／场景、生成参数；未选择的条件保持当前设置，缺失或不兼容的原作字段明确提示。
- 默认 Anima 模型统一为 MiaoMiao 1.6，历史配方和明确选择的旧模型保留；图片反推接入可复用 GPU 进程的 PixAI Tagger v1.0，支持取消、超时与故障回收。
- 随机灵感保留地点、时段和关系，参考场景中的颜色进入编译；修正 SFW 场景动作、镜头、服装绑定以及 Krea 手动背景的保留方式。
- 反推图片时清除不适用的继承场景；换装准备支持取消和防重入，高清重绘沿用原完成任务的真实配方与 Seed。
- 图片批次冻结参数和任务身份，支持显式继续和任务重连；上游任务已完成而结果尚未入册时可继续收集，避免重复生成。
- WebUI 队列与结果入册分离；上传图片和生成文件在完整写入后才发布，减小不完整文件及迟到结果引起的失败。

## 作品、画册与浏览

- 新增角色自动画册和标签智能画册，支持收藏、搜索、标签全部／任一匹配、手动画册范围及规则维护；分类不复制或搬移原图。
- 图库可组合筛选引擎、模型、服装、Seed、尺寸和候选状态，支持保存常用筛选；手动画册提供批量整理与条件撤销。
- 候选图比较支持差异参数、同步缩放／移动和键盘操作；补齐未缓存对比原作的按需加载与取消后的重试。
- 返回画册时保留已有图片墙，补充目录独立加载；减少分页读取、无关全库回读及重复解码复制。
- 回收站提供恢复和确认后的清空；图库删除、画布清空与再次生成时的旧图消散更加连贯，减少局部残留。

## 页面与桌面体验

- 绘制台保留大画布，侧栏宽度、显示和复位集中到布局入口；图片工具与配方检查集中到检查面板，并保留切换上下文。
- 首页、发现列表、角色档案、作品查看器、视频台、任务中心和设置完善层级、加载反馈、焦点与键盘操作；深浅主题及较窄桌面窗口按各工作包验收。
- 首次打开页面时，加载提示持续到目标页面就绪；加载失败显示恢复入口，旧导航的迟到失败不再干扰已打开的新页面。
- 场景中的角色切换与路由同步，页面导航和弹窗连续开关更稳定；保存设置和档案修改后提供明确反馈。
- 语音初始化和地址探测增加失败处理与时间边界；恢复文件、图片 URL 和其他长生命周期资源及时释放。

## 安装、升级与离线素材

- 安装与卸载采用统一品牌、深浅主题和原生操作反馈。默认卸载保留作品、设置与已导入资源；选择清理应用数据时列出目录并再次确认。
- 程序更新可查看实际下载进度并取消，失败信息更明确；保留更新签名及文件完整性校验。
- 离线素材助手可选择本地 ZIP，检查批准的版本和完整性后安装；助手入口及所需脚本已纳入桌面载荷。
- 本版包含前端、Rust 后端和桌面宿主更新，请使用完整安装包。原有个人资料与已导入内容继续保留。
- 完整素材继续使用已发布的 [2026-10-02 素材包](https://github.com/starplatium1129-stack/huiyu/releases/tag/huiyu-resources-20261002-r1)：471 项基础资源、2,042 条样张、4,084 个原图／缩略图文件。程序升级不重复打包该 ZIP，也不自动覆盖个人内容。
- 生图模型、PixAI 权重与 Python／上游运行环境仍需单独准备；安装包不包含生图模型。参考 [模型与环境指南](https://github.com/starplatium1129-stack/huiyu/blob/main/docs/guides/setup-and-models.md)。

## 稳定性与数据保护

- 任务结果的整文件校验移出 SQLite 查询线程，保留哈希、文件身份、归属和事务复核，减少提交结果时对画册及任务查询的阻塞。
- 媒体索引、分块传输、恢复并发、轮询退避、后台清理和读取取消减少重复工作；不将隔离夹具数据表述为真实生成速度提升。
- 工作区迁移、保存和归档恢复保留确认、重试及只读保护；未知任务状态不会自动重复提交。
- 本机与远程访问的分级边界不变，远程、隧道及未授权请求继续拒绝受限内容。

## 验证与已知限制

各工作包已有定向行为、浏览器、双主题、构建预算及 Rust 隔离验证记录。本次安装／更新相关检查 38 项通过，1 项非 Windows 专用检查按平台跳过；21 步静态检查范围均通过（首轮缺少 Bash 路径及参考素材根，修正本地检查环境后仅重跑失败项）。2,534 条已登记参考 URL 均能找到文件；4,571 项 pending 保持未交付状态。本次另行构建最终桌面载荷、安装器及更新签名，并核对源码与附件字节绑定；最终结果随发布回执记录。未执行本版真实安装／卸载、UAC、物理断电、干净 Windows 或全部真实模型验收。

本次按用户明确指令发布，原生依赖材料中的待验状态如实保留：libvips 链接依赖通知、工具链／对应源码来源及重分发审核尚未闭合，`releaseReady=false`。发布动作不代表这些材料已完成核验。详见 [原生材料记录](https://github.com/starplatium1129-stack/huiyu/blob/main/runtime-rs/native-licenses/README.md)。

安装包附 `.sig` 与 `.sha256`，自动更新使用同版本 `latest.json`。Updater 签名用于客户端完整性验证，不等同于 Windows Authenticode 证书。
