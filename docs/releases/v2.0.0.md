# 绘遇 HUIYU 2.0.0

- 更新角色头像，以及祀的档案、服装与场景目录。
- 新增祀的 Anima Base LoRA，触发词为 `si_(arknights)`，建议强度 0.8；权重已附在发布页。
- 更新水族馆场景的玻璃、展厅地面和光照描述；场景样张与祀的新立绘包含在完整资源包中。
- 调整粒子与原图的交接，避免低分辨率图层覆盖已完成的原图。
- 本版仅提供一个完整安装包，用于首次安装、升级及修复；保留更新签名与个人数据保护。

安装包、宁宁、夏目与祀的 LoRA 均见 [2.0 发布页](https://github.com/starplatium1129-stack/huiyu/releases/tag/v2.0.0)。部署脚本修复时，保留安装包旁同名的 `.deployment.json`。

新版完整资源包因上传连接限制分为 28 卷。下载以下文件到同一文件夹，双击下载器；它会下载、逐卷校验并合成 ZIP，已完成的分卷可在重试时复用：

- [资源包下载器.cmd](https://github.com/starplatium1129-stack/huiyu/releases/download/v2.0.0/Download-Huiyu-Resource-Parts.cmd)
- [资源包下载器.ps1](https://github.com/starplatium1129-stack/huiyu/releases/download/v2.0.0/Download-Huiyu-Resource-Parts.ps1)

然后下载同页的 [安装助手.cmd](https://github.com/starplatium1129-stack/huiyu/releases/download/v2.0.0/Install-OfflineResources.cmd)、[安装助手界面.ps1](https://github.com/starplatium1129-stack/huiyu/releases/download/v2.0.0/offline-resource-assistant.ps1) 和[安装程序.ps1](https://github.com/starplatium1129-stack/huiyu/releases/download/v2.0.0/Install-OfflineResources.ps1)到同一文件夹。完全退出桌面端后，运行安装助手并选择合成的 ZIP；旧版助手不识别本次资源包。

资源包更新祀的立绘原图和缩略图；旧版客户端中的人物粒子过渡可能仍使用内置的旧点云。
