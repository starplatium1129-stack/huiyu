## 安装与升级

1. 下载并运行上面的完整安装包。已有用户直接覆盖升级，无需先卸载；也可以通过客户端的更新提示安装。
2. 首次使用时，在控制室准备所需模型与运行环境。电脑尚未安装 WebView2 时，安装程序需要联网安装它，也可提前离线安装。原生功能还需要微软 VC++ x64 运行库，详见[模型与运行环境配置](https://github.com/starplatium1129-stack/huiyu/blob/main/docs/guides/setup-and-models.md)。
3. 需要离线素材时，下载上面的完整 ZIP；在控制室进入“资源与素材”→“打开安装助手”，选择 ZIP 完成接入，再返回画室。已有素材无需重复下载。
4. 需要角色 LoRA 时，将权重放入对应引擎的 LoRA 目录。ComfyUI 使用 `ComfyUI/models/loras/`；原生绘图按控制室的模型准备入口配置。宁宁和夏目也可以选择不使用角色 LoRA。

使用部署脚本进行安装或修复时，将[安装文件清单](https://github.com/starplatium1129-stack/huiyu/releases/download/v2.1.1/AI-CG-Studio_2.1.1_x64-full-setup.exe.deployment.json)与 EXE 放在同一目录，并保留原文件名。普通用户直接运行 EXE 即可。
