# 绘遇 HUIYU 1.0.0

绘遇（HUIYU）首个正式公开版本，集成多引擎本地生图、角色场景蓝图库、深度酒馆与原生桌面 Live2D 陪伴工作台。

## 核心能力

- **多引擎本地创作与视频分镜**：原生支持 Anima、Krea 2、Qwen、MOSS 生图与局部换装，内置 TeaCache 加速与空闲显存自动回收；支持 pi-H3 DWD 两步加速与 Wan 2.2 分镜短片生成，以及自由/绑定主体视觉反推协同与 MOSS 自动构图布局。
- **热门角色档案与全分级场景蓝图库**：内置 310+ 热门角色完整档案、服装拆分与 3800+ 场景蓝图，支持多角色混搭同框、无画师配方出图与原图立体缩放浏览。
- **深度角色酒馆与原生 Live2D 桌宠**：支持 Tavern V2 角色卡导入导出、世界书与长期记忆、6 表情立绘与单句配图、Muse/QQ 通道联动；桌面端采用 Tauri 2 + Rust 网关 + 原生 DX12 Live2D 渲染线程，支持像素级透明穿透与独立悬浮对白窗。
- **桌面端全链路性能优化**：支持托盘隐藏时自动降低 WebView2 内存占用、SQLite 读写分离与预览缓存前置 304 校验、Anima 跨底模复用推理进程与按需加速、以及 Live2D 低功耗核显优先选卡与静态/动态网格拆分渲染。
- **精简安装包与在线资源按需下载**：安装包默认采用精简档位，首次启动引导与控制室「资源与素材」支持按需下载高清立绘包（`portraits`）与场景样张资源库（`showcase`），自带断点续传、SHA-256 校验与镜像加速。
