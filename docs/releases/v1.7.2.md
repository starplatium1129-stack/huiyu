# 绘遇 HUIYU 1.7.2

本版汇总 `v1.7.1` 之后合入主线的工作台体验、内容边界、桌面端可靠性与工程维护更新。

## 主要更新

- 完善角色参考资料、服装登记、热门角色与场景蓝图的数据分片和维护流程，修复热门场景提示词矛盾与缺失引用。
- 改进陪伴、Live2D、聊天归档、资源恢复、模型校准和桌面工作区的状态恢复与并发边界。
- 扩展画廊、场景浏览、提示词工作台、视频分镜、模型工作室和页面导航体验，保持深浅主题与可访问性约束。
- 收紧本机资源、远程接入、路径、存储、生成任务和桌面 IPC 的安全边界。
- 将维护脚本、运行时生成、测试与桌面构建身份绑定纳入更稳定的 TypeScript 工作流。

## 发布边界

版本发布使用完整桌面构建、隔离网关启动验证和受控发行回执；真实模型出图、设备级验收及用户本机私有资源仍按对应机器单独验收。
