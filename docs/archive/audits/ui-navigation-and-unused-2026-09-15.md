# UI 动效、页面切换与闲置实现核查

日期：2026-09-15。第一阶段完成导航、绘制工作台入场、预热及生产构建验证；随后按用户要求删除两处闲置实现及旧草稿仓库的专属测试，并整理状态与待办文档。两阶段验证分开记录；尚未同步桌面安装版。

## 已完成的体验改进

| 问题 | 本次实现 | 验证依据 |
| --- | --- | --- |
| 整页缩放、淡出叠加，结束后仍保留变换效果 | 页面改为 220ms、6px 轻移，文字全程不透明；动画结束或中断时释放效果，恢复正常布局上下文 | 缓存页面返回、连续反向切页后根节点 `transform: none`，只有一个可交互页面 |
| 离开中的旧页面仍可接收操作 | 下一页准备好时立即停用并移出旧页面，缓存重新激活时恢复交互 | 连续切换中页面不残留 `inert`，绘制栏仍可见 |
| 慢加载缺少明确目标提示，减少动效时进度完全消失 | 导航即时标记待打开目标，主内容标记忙碌；超过 180ms 显示顶部进度和读屏提示，减少动效时使用静态线条 | 双主题、正常及减少动效、延迟资源、失败恢复与窄屏导航 |
| 旧跳转完成或失败可能关闭新跳转的提示 | 加载状态按路由对象归属清理；返回当前页也能取消等待提示 | 真实内存路由和可控异步加载测试 |
| 鼠标掠过导航就触发预热和全量场景读取 | 悬停 90ms 后预热，移出取消；键盘聚焦和按下立即预热。移除导航预热中的场景全库加载；共享成功及进行中的模块预热，失败允许再次尝试 | 指针掠过、键盘意图、节省流量模式与模块去重测试 |
| 工作台内部重复入场造成文字模糊、延迟显现 | 去除工作区与左右列三层叠加动画及其失效关键帧；画布入场改为 200ms、4px 轻移，取消模糊和整体缩放 | 入场期间直接检查容器的透明度和滤镜，并查看双主题截图 |

主要实现位于 [页面布局](../../../src/components/AppLayout.vue)、[页面动效](../../../src/composables/useRouteTransition.ts)、[加载状态](../../../src/composables/useNavigationFeedback.ts)、[导航](../../../src/components/AppNav.vue)、[意图预热入口](../../../src/components/AppInteractionLayer.vue)及[预热去重](../../../src/router/prefetch.ts)。

上述毫秒数是动画与反馈的配置值，不是网络或整页加载性能测量。本次没有声称首次进入耗时降低了某个百分比。进入或离开 Live2D 页面所需的文档安全策略切换继续使用原有整页导航；没有通过放宽安全策略换取切页速度。

## 已删除的闲置实现

删除前以 `src/main.ts` 为入口，解析 Vue 脚本块及 TypeScript 导入关联，排除测试与声明文件，扫描 375 个源模块，其中 373 个与入口关联。两个未关联模块又经源代码、测试、服务、桌面、工具和维护目录的名称引用核查。这里的结论是“当前应用未使用的实现”，不是用户使用频率统计，也不等于所有后端功能的可达性证明。

| 已删除项 | 为什么能确认闲置 | 保留的现行能力 |
| --- | --- | --- |
| `src/stores/promptDraftStore.ts` 及 `src/stores/promptDraftStore.spec.ts` | 运行时代码没有引用 `usePromptDraftStore`；代码消费者只有它自己的单元测试。实际草稿保存、恢复由 `promptBuilderStore` 提供，`usePromptLifecycle` 和 `usePromptDeepLink` 调用现行接口 | 保留现行自动保存、解析器和仍在使用的 `aics_pb_last_draft` 数据键；不清理浏览器内的用户草稿 |
| `src/components/popular/PopularRecipePicker.vue` | 没有导入、挂载或事件消费入口。现行热门角色提示词装配已按蓝图和引擎自动解析配方 | 保留配方目录、自动选择和分级约束；不删除 Krea 风格功能 |

现行替代实现可核对 [promptBuilderStore](../../../src/stores/promptBuilderStore.ts)、[草稿生命周期](../../../src/composables/prompt/usePromptLifecycle.ts)、[深链接恢复](../../../src/composables/prompt/usePromptDeepLink.ts)和[热门角色提示词装配](../../../src/composables/prompt/usePopularPromptAssembly.ts)。

**目前没有证据把任何现存整页功能认定为“完全无用”。** 训练页已不在当前路由，不计为本轮新发现；粒子肖像属于保留功能；历史存储键的清理代码承担兼容职责，也不属于可直接删除的无用功能。上述两个孤立模块本来就未接入前端入口，删除它们主要减少维护混淆，不能据此宣称首屏包会明显变小。
