开始你的第一张 CG

选场景、确认画面、生成并保存。先浏览灵感，再按自己的节奏开始创作。

生成前，确认绘图服务可用

  • 浏览参考画册与场景不需要先启动绘图模型。
  • 生成需要对应的服务：SD 使用 WebUI，Anima / Krea 2 使用 ComfyUI。
  • 在绘制台选择引擎并查看连接状态；服务未就绪时先完成配置。等待时间取决于设备、模型与画幅。

本机用户可打开控制面板检查服务。远程访客请联系画室管理者确认生成权限与服务状态。

1

浏览灵感场景

打开顶栏的「灵感」，浏览场景的故事、角色与画面设定；想寻找特定角色时，使用「角色场景」。

先到参考画册了解构图与风格。样张用于参考，每次生成不保证完全一致。
浏览灵感场景 →
2

选一个你喜欢的场景

搜索「教室」「夏日」「咖啡」等题材，打开喜欢的场景查看设定，再从场景进入绘制台。

场景设定会带入绘制台。生成前再次确认角色、服装、引擎与画幅，按需要调整画面。

3

确认后生成图片

确认画面与连接状态后，使用绘制台的生成按钮提交任务。打开「任务」查看执行进度。

生成失败时，先阅读页面提示并检查服务，再重试。模型、参数和随机种子都会影响最终画面。

先用一张图确认效果，再考虑批量创作。
打开绘制台 →
生成后，保存你的作品
在我的作品回看已保存的图片，或回到首页继续最近的创作。重要作品请下载备份：本地档案与当前浏览器或桌面应用的数据有关，清理浏览器数据前先确认已保存。
