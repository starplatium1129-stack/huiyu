关键结果

经用户批准，已从官方来源安装与仓库 CI 相同的 Rust 1.98.1 minimal，独立保存工具链和 Cargo 缓存，不修改系统 PATH。locked Cargo 编译成功，原独立推理及 TeaCache 控制接口没有编译错误。

新增应用内离线运行库准备、完整 Anima Diffusers 目录检查与明确导入入口。仍需要可信的本地 Python 和 wheelhouse；完整 Windows 发行材料、真实模型/GPU 出图尚未完成。

新增使用闭环

  • 离线准备：用户填写可信 Python、wheelhouse 和当前工作区并确认，后台只调用固定随包准备器，目标固定为工作区 inference。创建前离线解析依赖，拒绝覆盖既有或部分运行库，不下载模型或依赖。
  • 完成后明确“填入设置”，再保存并重启；不会自动选择 native 或改变正在执行的任务。原首次配置入口明确标为 ComfyUI，避免与独立路径混淆。
  • 完整模型目录先做只读布局检查，绑定已登记 Anima modelId 和已保存模型根目录；确认后复制，不移动源、不覆盖目标。原始单文件仍使用已存在的架构严格转换入口。
  • 复制拒绝链接、路径重叠、未知业务文件、远端代码或量化配置。流式 SHA-256 复核复制字节与未变的来源，完成后才无覆盖发布。失败临时目录保留供检查，不能当成已完成模型。
  • 运行库准备和导入复用本机控制面的操作互斥、状态与取消。取消等待受管活进程停止；请求超时或关闭界面不等于后台任务已结束。

此前独立能力仍保留

无 ComfyUI 的 Anima 文生图、图生图、兼容 LoRA、逐步蒙版采样/合成、本地 CLIPSeg、严格单文件转换、应用引擎配置及诊断。TeaCache 实际 block 跳算和本机校准/留出验收入口保留，默认关闭；未验收档不能用于生成，没有借用未经校准系数或承诺速度。

仍需验收与已知限制

  • 没有安装 ML 大包、下载权重、生成真实图片或运行 TeaCache 校准；模拟协议通过不代表设备画质、性能和显存通过。
  • Windows 安装包、目录发布分支、驱动/CUDA、签名 Python/wheel 发行材料未验收。macOS 目录发布分支也未执行。真实 UI 画面验收未完成。
  • 完整目录检查只证明布局和复制字节，不证明未知 MiaoMiao 架构兼容；每种真实权重仍需加载出图。裸单文件不能直接作为完整目录导入。
  • 普通取消使用已有受管进程机制，活父进程和等待中的后代由夹具验证；既有机制对父进程已被外部杀死/崩溃后的孤儿后代清理并未全面保证，本阶段未改动通用进程框架。
  • Remacri/RealESRGAN、RCAS、Krea2、SDXL 等独立能力尚未覆盖，高清修复明确拒绝。默认 Comfy 路径保留；显式 native 不静默回退。
