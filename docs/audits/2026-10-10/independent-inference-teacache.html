本阶段结论

独立 Anima 已接入真正跳过 transformer block 计算的 TeaCache 路径、应用内开关，以及离线采集、拟合、留出对照与人工验收入口。默认关闭；不随包提供未经校准的系数，未验收校准档不能用于产品生成。

当前没有真实模型/GPU 速度或画质证据，不能承诺提速比例。此候选尚不是新机安装后放单文件模型即可生成的完整替代发行。

实现范围

  • 固定 Diffusers 0.41 标准 Anima/Cosmos：首层 norm1 代理与 block 栈残差复用，保留外层预处理和输出头。并非直接复制其他模型系数；MiaoMiao 仅限经真实结构与本机校准确认的版本。
  • 每任务独立进程；CFG 分支缓存隔离，实际首尾步全算，连续跳步有界。条件、shape、dtype、设备与时间序列变化重置；异常恢复原方法，保留取消、进度和原子 PNG 输出。
  • 图生图、LoRA、手绘及 CLIPSeg 局部重绘保留原路径。校准档绑定模型组件字节、LoRA/强度、尺寸、步数、CFG、设备、编辑模式与遮罩参数；变化需重新校准。
  • 应用开关默认关闭；缺档拒绝，文件存在仅表示可尝试验证。旧 Comfy 阈值需明确清除，不静默沿用或降级。单张、局部重绘与逐张图片批次共用能力检查。
  • 离线校准默认只读计划。显式 --run 才出图；新拟合与未参与拟合的提示词/种子对照。--accept-run 配合画质/性能确认，核验实际跳步、完整证据和真实端到端收益后才安装档。

  • 校准/验收定向测试：10 通过，无真实模型；涵盖默认不运行、拟合与留出、接受门槛、源图片/遮罩完整性、已有档保护和取消流程。
  • 前端定向：QuickPanel/session/inpaint 29 通过；settings/modal/workspace 16 通过；最终 session/batch 38 通过。部分覆盖重叠，不相加冒充独立测试数。vue-tsc 与受影响文件 ESLint 通过。
  • 资源 staging：12 通过，4 项 Windows 条件跳过；工作流 runner：31 通过、1 跳过；条件注册：12 通过。Node 工具构建通过。
  • 两项独立源码审查未发现剩余阻塞项；不是 Rust 编译或真实设备验收。

主力机最小入口

用已准备好的独立 Python 和本地模型，运行 scripts/maintenance/calibrate-anima-teacache.py，提供 --calibration-job、--validation-job 和全新 --output-dir。先看默认计划，再明确加 --run。阅读生成的 review.html，逐对查看人物、构图、纹理、局部区域和边界；整图像素误差不能代替画质判断。

缓存端到端时间包含每任务完整模型哈希成本，无缓存基线不执行缓存哈希/代理。管线时间含编码、采样、解码；显存是进程分配峰值。维护身份核对在计时外，可能预热文件缓存。所有结果均需在用户设备测量。

只有认可留出图片及实际耗时，才执行 --accept-run <目录> --accept-quality --accept-performance；已有档需精确摘要授权替换。之后仍需手动开启应用开关。
