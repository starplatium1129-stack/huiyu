优化落在 LoRA 热路径

两份 v21 LoRA 均有 280 个 rank-32 Linear 目标，未融合时每次完整 transformer 前向增加 560 次小矩阵乘法。隔离 GPU 探针测到 BF16 base/A/B 下，前向从 235.92 ms 降到 207.50 ms，约减少 12.0%；一次融合约 0.123 秒。输出仍有限，但浮点计算顺序变化，因此没有沿用旧模式校准。

新增显式 compiled-fused-sage 模式：融合只发生在驻留模型内存中，先保存被修改基座的原始 CPU 权重。强度改变或换组前逐字节恢复，再应用新适配器和强度；不依赖 BF16 减法反向还原。相同模型/LoRA/强度的热任务不重复融合。GPU 实测每个角色快照为 3,523,215,360 字节，即额外 3.28125 GiB 系统内存；空 LoRA、换组和退出会释放相应快照，源文件不改写。

首轮未融合宁宁的留出基线约 12.04 秒，Tea 约 6.98 秒，仍不足以超过产品 Comfy。最终模式重新拟合各角色，并显式评估连续最多跳两次：宁宁留出约 10.31 → 4.79 秒，夏目约 10.36 → 4.80 秒。校准对照双方关闭文本缓存，完整 API 保留产品文本缓存，二者计时不能混用。

代码保留原 native、sage、compiled-sage 行为；新模式改变计算顺序，绑定独立 execution/revision。校准器新增 --max-consecutive-skips，默认仍是 1，范围 1–3；首尾步、误差阈值和验收条件保持生效，不减少请求步数。GPU 探针 · 实际快照与切换记录。
