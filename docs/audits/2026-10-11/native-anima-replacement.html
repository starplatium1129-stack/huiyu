绘遇 Anima 独立后端

绘遇现有 Anima 主流程已接入独立引擎：六个模型真实出图，支持 LoRA、图生图、蒙版、高清和圆括号权重。已校准角色组合的完整 API 热任务耗时减少 22.3%，并消除受保护加载路径约 3.28 GiB 的额外 CPU 原权重快照。

本报告只记录这轮变化、验证与限制。默认引擎和加速环境设置未改，未执行桌面部署；非 Anima 模型和视频不在本次实现范围。

提示词权重

CPU 与真实 GPU 已验证 14 项真实 tokenizer 对照匹配当前 Comfy Anima 的 Qwen/T5 token ID 与权重规则，8 项定向测试通过，加权提示词真实 GPU 出图成功。普通提示词 PNG SHA256 与接入前完全一致。

  • (text) 为继承权重乘 1.1，(text:number) 使用显式值，支持嵌套和转义括号；正向、负向均适用。
  • [] 与 BREAK 保持字面文本，不宣称减权或分段语义。
  • 不平衡括号、非法/非有限权重及超过 512 token 的输入明确拒绝，不静默截断。
  • 加权请求使用独立 TeaCache 范围，普通档不能复用。token 对齐不等于跨后端随机噪声、运算或像素等价。

TeaCache：整项高清操作单独验收

高清 scope 绑定倍率、重绘幅度、实际 upscaler、第二轮采样器/调度器、精修版本及 Remacri 文件 SHA256；同时保留模型、LoRA、强度、设备、执行版本等原有绑定。第二轮开始前清空残差，完整流程已在 GPU 捕获 24 + 14 次采样更新。
