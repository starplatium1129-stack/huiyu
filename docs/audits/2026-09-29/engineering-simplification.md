## 不应按“复杂”直接删除的部分

- Web 与 desktop 是两个仍在使用的平台，仓库端口、迁移屏障和单写权威并非重复存储。
- 任务幂等键、CAS、writer epoch、取消意图、恢复状态及结果补偿分别保护不同故障；媒体锁/并发许可和 health 刷新去重也有实际并发职责。
- 旧 Node 后端仍被 `gateway-test-stack`、Rust/Node parity 和任务 fingerprint 对照调用；本轮没有整目录删除的依据。
- API 工厂虽常只有一个生产实例，但测试通过依赖注入验证传输失败行为，保留有效测试边界。

后续候选：四个手工 CDP 工具重复连接/选页且含旧选择器，可对照原生验收后合并；两个 inpaint 候选工具的传输函数有重复，可在对应生成链路验收时收口。本轮未扩大到设备/模型流程改造。
