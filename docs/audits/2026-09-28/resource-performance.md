## 4070 Ti S 主力机接续验收

办公机默认 SD WebUI/ComfyUI/Ollama 端口未监听；没有启动真实模型。4070 Ti S 的模型吞吐、显存峰值和功耗仍需主力机执行，不能以 880M 或模拟上游关闭这些项目。

1. 使用同一候选源码/构建，固定模型、输入、分辨率、步数、种子和电源状态，先记录现有配置；不改定稿场景或模型质量参数。
2. 分开测界面空闲/预览/Live2D、单个真实模型任务及界面与模型并发；分别记录进程 CPU/RSS、GPU busy、显存、耗时和取消后回收。
3. GPU busy 与显存必须分开比较；高利用率可以代表更好的有效吞吐，不能单独作为退化。不要为利用率下降而默认限帧或降低生成质量。
4. 发现具体主力机瓶颈后再选择推理后端、批量/队列、精度或模型卸载策略；在该设备不存在的办公机上不作未经实测的参数变更。

本轮不执行桌面安装/UAC或发布。以上主力机项是待设备验证，不是已经完成的实际生成验收。
