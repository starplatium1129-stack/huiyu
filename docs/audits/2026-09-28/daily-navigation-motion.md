# 日常导航过渡细节优化

日期：2026-09-28。范围为同级工作区切换、快速中断后的视觉衔接及桌面 hash 路由预取；保留本轮之前的 Live2D 内存/工具栏修复，不重新解释为本次过渡优化的成果。

## 行为变化

- 同级页面取消按固定路由序号左右移动。新页 180ms 淡入、旧页 140ms 淡出，控件位置保持不动；真正的 `/popular-scenes` 与 `/character` 目录/详情关系继续保留双向 8px 提示。返回缓存页面保留原有 120ms 轻淡入与 DOM/滚动状态。
- Vue 在调用 leave 前会先取消 enter。旧代码此时取消 WAAPI 并恢复底层样式，离场又从 opacity=1 开始，导致未完成的入场瞬间变成全显。现在在取消前读取实际呈现的 opacity/transform，用 WeakMap 只交接该元素下一段动画；下一段消费后删除，减少动态效果、停用和卸载时清空。返回尚未淡完的缓存页面同样从当前画面恢复，不强制回到 0 或 .88。
- 这保证视觉位置/透明度接续，不宣称固定时长 WAAPI 已变为保留速度的弹簧。现有浮层弹簧、图片来源过渡继续复用，没有增加新的动画库、页面缓存或永久合成层。
- 桌面使用 `/#/目标`，原模块预取却取 pathname+search，实际可能预取首页。`AppInteractionLayer` 现在与导航意图共用 `routeDestination()`：桌面取 hash 内路由，网页取 history 路由，保留 query/hash。90ms hover 停留、焦点预取、节省流量模式和点击时资源预取边界不变。
