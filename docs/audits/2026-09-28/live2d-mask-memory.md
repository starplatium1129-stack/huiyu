# Live2D 遮罩内存与桌宠按钮交互优化

日期：2026-09-28。基线 `5fe5c698200477d4919239387f08b34935992962`。用户报告打开桌宠后应用总占用约 1.8 GB；本轮定位原生渲染资源并完成局部优化，没有替换已安装客户端。

## 原因与实现

原渲染器为每组裁剪遮罩预分配全渲染尺寸 RGBA8 纹理，但最终只读取 alpha。桌面默认 2 倍超采样让遮罩宽高各翻倍，四通道成本继续乘四；窗口物理像素增长会进一步放大分配。这是可优化的常驻资源，不凭启动时的跳升判定泄漏。

将遮罩改为 R8Unorm，以 red 存储/采样覆盖率；保留 8 位精度、原分辨率、超采样、预热与 `src + dst * (1-src)` 遮罩并集。反转遮罩仍为 `1-coverage`。遮罩像素数据从每像素 4 字节降为 1 字节（75%），不等于整个应用内存降低 75%。模型色彩贴图、动作和卸载生命周期不变。遮罩分配与诊断读回提取到 `renderer_mask.rs`；诊断继续输出 alpha 承载覆盖率的 RGBA。

修复已有 `renderer_soak` 调用遗漏 `supersample` 参数而无法编译的问题，明确传 `true` 对齐桌面默认；基线和候选都应用这一相同测试修复。

模型原始贴图单份 RGBA payload：宁宁 1 × 8192² × 4 = 256 MiB；夏目 14 × 4096² × 4 = 896 MiB。PNG/WebP 磁盘压缩体积不代表上传后纹理大小，仍有设备资源池、上传及 WebView 成本；不能预期加载原始模型后仍保持几十 MiB。

## 本次对照

Windows / AMD Radeon 880M / DX12，驱动 `32.0.31021.5001`。复用相同已有模型，以隔离 `renderer_soak.exe` 串行测量，原始贴图、1080×1080 物理像素离屏目标、2 倍超采样（2160×2160）、目标 60 FPS、每 15 秒换角色，总长各 45 秒。此离屏测试没有 CSS 视口、浏览器缩放或系统 DPI 映射，不声称完成桌面分辨率矩阵验收。

PowerShell 每约 500 ms 读取**该渲染进程**的 PrivateMemorySize64 / WorkingSet64。稳态窗口按进程启动后的 5–14、23–29、35–44 秒选取，分别 18、12、18 个样本；加载/切换间隙排除。用户当前应用保持原状，不将其进程混入统计。

宁宁私有提交减少约 510 MiB（41%），夏目减少约 242 MiB（16%）。私有提交不是独占物理内存；这也不是应用分组总占用，更不能直接用 1.8 GB 减去此数字声称安装版新占用。

两轮均正常退出，2 次角色切换、3 次资源释放检查通过，稳定帧创建资源数为 0。扣除角色加载后的渲染速率约 59.29 / 59.62 FPS；p95 CPU 帧耗时为 5.43 / 7.13 ms，短样本不证明提速，亦不代表 GPU 时间或长期功耗。首轮采样器曾未保留进程句柄而读不到 ExitCode，已修正并完整重跑；表格只使用重跑成功的基线。

候选另跑 120 秒复验：7 次角色切换、8 次释放检查均通过，稳态/末帧资源创建为 0。进程启动后 7/37/67/97 秒起各 4 秒的宁宁私有提交均值约 728/728/728/729 MiB；24/54/84/114 秒起各 4 秒的夏目约 1203/1197/1198/1207 MiB。该短周期未见随换角持续堆积，但不据此宣称长期无泄漏。期间有一次短暂 CPU 编译，此轮只用于资源复用/内存趋势，不比较性能。

## 桌宠悬浮工具栏点击

用户补充多个按钮有按压动画但无动作。在真实 Edge 鼠标事件中复现：按下图标按钮后向旁边移动 6 CSS px，在同一扇形背景松开，浏览器将 click 派发给二者的共同父节点 `.orbit-segment`。旧实现仅在 button/path 分别注册处理器，该 click 因而丢失；修复前新增回归明确失败（置顶仍为 false）。

`CompanionOrbitMenu.vue` 改为同一扇区共同处理 click，移除子按钮/path 的重复处理器。保留原生按钮的键盘语义、原有动作映射与外观；button、path、跨边界共同目标均只触发一次。未凭推测修改原生窗口 Z 序或穿透逻辑。

验证：组件/手势 Vitest 8/8；真实 Edge 下深浅主题共 6 项定向 E2E 通过，覆盖跨图标/扇区点击的置顶与聊天桥调用、普通点击、角色选择、穿透开关、设置弹层、焦点返回、键盘和 AA 文本对比度。已查看两种主题工具栏截图。使用 540×760 CSS 桌宠窗口、Playwright 默认 DPR 1/页面缩放 100%，这是独立浏览器夹具而非系统物理屏幕验收。应用类型检查通过。

E2E 复用 `companion-frameless.spec.ts` 的隔离宿主桥，测试服务只开本次 Vite 5188；没有启动或驱动用户安装版。真实 native IPC/Windows 系统动作仍需安装后复验。未连接的本机额外角色目录/样张 manifest 产生既有代理警告，此轮只验证内置角色工具栏，不把它当成资产加载验收。截图在被忽略的 `runtime/pet-click-20260928/`。

## 交付边界

本轮不改默认纹理画质，不依靠降分辨率减少占用。未打包/安装、未运行真实 AI 生成、未修改生产资料。当前运行的客户端尚未包含此次优化；完整安装后仍需以相同窗口、角色、画质对照应用进程树及显隐循环。不同显卡、窗口大小、多屏/DPI、长时间驻留与所有动作不由本次短样本代替。
