# 参考画册画幅与预览优化（2026-09-28）

针对桌面反馈的横图过小、行内空白和预览工具栏遮图，调整展墙与预览排版，保留现有配色、卡片材质、图片内容和分级规则。

## 调整

- 展墙按原图比例分配行宽，同排图片等高，横图得到更宽的展示面积。末行不强行拉满；标题保留两行空间，阅读和键盘顺序仍与目录一致。
- 目录缺少尺寸时，用已加载图片的自然尺寸校正布局；刷新标题等资料不清空已测比例，换图时才重置，拒绝迟到的旧资源事件。
- 预览取消原有 1160px / 900px 尺寸上限，面板随当前图片比例和可用 CSS 视口调整，完整显示横竖图。常规画幅的内侧留边实测 8–16px。
- 图片裁切区域与缩放工具栏各占独立一行，按钮、比例和提示不覆盖画面；超长竖图保留足够的按钮宽度。缩放后的图片也不会画到工具栏所在区域。
- 共用预览组件的其他宿主继续使用原有工具栏位置。图片缩略图过渡、冷加载、方向键、Esc 与关闭后的阅读位置保持。
