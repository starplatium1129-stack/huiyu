# 桌面 UI 细节审计与修整

日期：2026-09-28。按 macOS 界面常见的形状一致性、可读性、反馈和控件精度审查，保留绘遇的品牌、字体层级和页面结构。

## 已修复

| 问题 | 调整与实际结果 |
| --- | --- |
| 画册、作品库的胶囊选中背景与按钮悬停轮廓不一致 | 移除全局材质层强制设置的小圆角；灵感与角色场景的筛选也恢复页面定义的胶囊形。画册、作品库按钮与选中背景均为 `999px`。 |
| 键盘聚焦时按钮突然变方 | 全局焦点规则仅负责轮廓线，保留控件自己的圆角。首页主按钮聚焦前后均为 `16px`，修复前聚焦会变成 `6px`。 |
| 绘制区结果标签没有对应圆角和悬停反馈 | 标签与滑动背景统一为 `10px`，未选中的标签补上轻量悬停底色。 |
| 部分操作命中区域过小 | 带文字开关、角色目录“定位”、语音设置、陪伴聊天配置入口采用至少 `32px` 高度；问候关闭按钮改为真实 `32×32px` 区域和共享线条图标，避免伪元素扩区与文字重叠。 |
| 控件混入浏览器默认字体 | 原生控件默认继承页面字体，已有专用字体样式继续优先。陪伴页加载入口原为 Arial，现使用项目字体、字号和行高。 |
| 陪伴页空错误提示显示为红色细条 | 没有错误内容时隐藏提示容器；实际错误仍使用原有状态区。两主题均确认空提示不再可见。 |
| 陪伴页加载入口和画质说明在浅色下不协调 | 加载入口采用对应主题的实底与文字令牌。选中画质的说明文字对比度由浅色 `3.72:1` 提升至 `6.34:1`，深色为 `7.12:1`；选中与焦点边线使用可读的主题强调色。 |
| 设置中的主次文案挤在同一行 | “勿扰模式”的说明独立成行，并保留适当间距和次级文字颜色。 |

## 审查范围与证据

覆盖首页、参考画册、灵感场景、角色场景、我的作品、绘制工作台、故事短片、角色档案、画风、模型资料、色彩情绪、剧本模式、场景维护、角色房间、控制面板、陪伴页、陪伴聊天与 404，共 18 个入口。

逐页查看深浅主题首屏及长页面的下一屏；另外打开导航菜单、搜索、任务中心、外观设置、筛选下拉、角色选择弹窗、维护编辑表单、对话与角色设置、陪伴设置、含作品的图库及原图查看器菜单。图库使用独立浏览器资料中的六条视觉夹具，画册只读现有全年龄样张；不修改个人作品、场景或图片数据。

桌面 CSS 视口为 `1280×800`、`1440×900`、`1920×1080`、`2560×1440`、`3840×2160`。18 个入口 × 两主题 × 五种视口，共 180 组布局取样未发现页面横向溢出或可见选中背景与目标按钮的圆角不匹配；这不是 180 条新增测试。重点页面额外保留多尺寸截图，并检查菜单可达性与文本是否受装饰干扰。

本机主显示器为 `2880×1800`，系统 DPI 为 `192`、缩放 `200%`。本轮使用 Headless Edge，浏览器缩放 `100%`、DPR `1`，实际 CSS 视口单独记录，不将模拟视口称作原生 4K 设备验收。

原始截图、测量和日志放在被忽略的 `runtime/ui-craft-audit/`：`before/`、`after/`、`before-contrast/`、`environment.json`、`build.log`、`contrast.log`。候选前端位于 `runtime/ui-craft-dist/`，避免重建共享 `dist/` 干扰其他工作。
