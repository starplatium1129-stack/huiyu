# 页面数据链路性能根因与验证

本轮针对页面冷启动、浏览筛选和推荐读取。此前的 UI 动画、布局及并行会话的图库、粒子、Rust 流解析和存储索引改动不计入本轮收益。原始样本、范围和源码哈希见 [证据](../../evidence/ui-data-performance-2026-09-28.json)。

## 根因与修复

1. **浏览依赖工作台全量数据。** 灵感页只需 curation 与场景分片，却先等候角色、蓝图和模型目录。新增浏览专用读取入口；热门场景、画册和角色档案按各自依赖加载。预取清单同步收窄，避免入口已经拆分但预取仍拉取无关数据。
2. **全局场景列表被不同页面共用为可变视图。** 浏览返回独立快照，不替换工作台正在使用的列表；核心分片加入现有缓存与在途去重，切换角色再回核心视图不再依赖不准确的布尔标记。工作台入口仍补齐其完整元数据。
3. **推荐计算搬运整条作品。** Web 只复制 id、scene、character、favorite、timestamp；桌面通过原有受保护的列表接口请求 preference 投影，在 SQLite 查询阶段截取字段。保留分页、工作区权限、版本一致性和软删除筛选。
4. **比较器重复扫描与评分。** 场景排序每条结果只评分一次，复用 Collator；主题计数只随源数据变化重算。六类排序与相关度平分的输出逐条对照，保持原有优先级和稳定顺序。
5. **异步读取缺少页面意图隔离。** 数据与偏好读取并行；筛选只在所需分片范围变化时请求。页面加载修订号阻止晚到响应覆盖最新筛选，离开页面后不再发布状态，并释放闪示定时器。共享传输仍由数据缓存持有，不因一个页面离开而取消其他消费者的请求。

## 当次结果

| 对照 | 修改前 | 修改后 | 范围 |
| --- | ---: | ---: | --- |
| 灵感页静态 JSON 请求 | 10 | 3 | 独立浏览器上下文直接进入 |
| JSON 原始字节 | 6,785,657 | 69,874 | 不含字体、脚本与压缩传输差异 |
| 首屏场景可用时间中位数 | 1152.9 ms | 802.0 ms | 4K、三轮交替、同一份数据，结果 ID 与顺序相同 |
| 302 条真实场景的 50 次多模式排序回放中位数 | 85.97 ms | 19.18 ms | 五轮、新旧输出相同，不代表整体 FPS |
| 单条人工长提示词记录的列表 JSON | 262,340 字节 | 163 字节 | 同一条记录、同一分页条件，未做 HTTP 压缩 |

20 轮四页面往返后，DOM 节点保持 2446、监听器保持 957、活动路由始终为一个。强制 GC 后 JS 堆从第 10 轮的 23,475,636 字节到第 20 轮的 23,660,568 字节，没有观察到 DOM/监听器线性增长。此检查使用隔离数据和空画册 manifest，不涵盖真实大图、Live2D 或模型进程。

## 验证与边界

- 全量前端：239 个测试文件、1627 项通过。随后核心缓存契约和预取清单的受影响测试共 33 项通过。
- Rust 工作流：格式、Clippy 与隔离测试通过，95 项通过、7 项按原约定忽略；最终投影测试另行通过。
- API 投影校验分页、布尔字段、修订号、删除记录排除及未知投影拒绝；没有增加工作区读权限。
- 浏览器注入延迟核心分片，验证全库切换后旧响应不回写；连续搜索不重复请求相同覆盖范围。展开详情与深浅主题检查正常。
- 应用类型、依赖边界、样式、单体体量及前端生产构建检查通过。

尚未同步桌面安装版；前后端应一起交付。Web 旧 IndexedDB 格式仍需读出原存储对象，本轮消除了后续大对象复制，未迁移其持久格式。冷渲染、字体和真实素材/模型仍可能产生长帧，本报告不宣称所有机器或所有业务流程零卡顿。
