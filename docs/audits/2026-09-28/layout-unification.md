# 全站布局审计与统一（2026-09-28）

本次修复绘制工作台右栏留白，并审查全部 18 个路由页面（含 404）、主要二级导航和弹层。保持角色视觉、樱粉/紫色强调、手绘 ArchiveIcon、深浅主题和现有业务行为。

## 修复结果

| 区域 | 原因与修改 |
| --- | --- |
| 绘制右栏 | Tooltip 的 anchor 占满网格，内部引擎按钮按文字收缩。按钮改为填满行，三引擎同宽；整理分组间距、基础模型框与推荐配方折叠入口，空配方不显示。 |
| 高级放大设置 | 绝对定位、至少 390px 的浮层会被约 300px 的滚动栏裁切。改为栏内展开，两列输入随实际宽度收缩，长提示换行。 |
| 主导航与更多 | 紧凑导航统一 2×3 入口，工具组独占整行；更多按发现/美学/工坊分组，桌面三列、手机单列滚动。菜单实底避免后层文字透出，打开后聚焦首个页面入口。 |
| 资料二级导航 | 画风、色彩、模型、剧本使用一致的等宽分段导航，手机 2×2，统一选中态、44px 点击高度和下方间距。 |
| 共享控件 | 标签空间不足时在容器内滚动；下拉选项的长模型名换行，勾选图标不被压缩。 |
| 跨页样式 | 维护页的 inspector 样式限定在 `.manager-workspace`；作品查看器的 viewer 样式限定在 `.art-viewer`，避免 SPA 保留样式后污染绘制页或参考画册。 |
| 场景维护 | 修复单列表单被两列规则覆盖；工具、样张卡片根据可用宽度排列，状态文字允许换行。 |
| 视频、色彩、模型 | 高级视频参数按容器宽度分列，时长行/长模型名换行；色彩映射卡、光照卡和 LoRA 长词条不再撑破窄容器。 |
| 手机聊天 | 角色工具条恢复到画面下方，避免加载立绘、导入模型和设置相互覆盖。加载入口用布局居中，消除变换叠层中的点击命中错位。 |

引擎栏实测：原来 311.6px 栏中三个按钮约为 163.3 / 129.1 / 193.3px；现在预留稳定滚动条后，有效栏宽 301.6px，三个按钮均为 301.6px。热门角色模式下实际按钮及副文案最低对比度为浅色 4.93:1、深色 5.80:1（包含禁用 SD）。

布局组织参考 [InvokeAI](https://github.com/invoke-ai/InvokeAI)、其 [CanvasLaunchpadPanel](https://github.com/invoke-ai/InvokeAI/blob/main/invokeai/frontend/web/src/features/ui/layouts/CanvasLaunchpadPanel.tsx) 与 [ComfyUI_frontend](https://github.com/Comfy-Org/ComfyUI_frontend)。本次归纳采用画布与参数分区、按任务分组和渐进展开；实现继续使用项目现有 Vue/Reka、主题令牌和图标。
