## 焦点回归及修复

正式浏览器回归发现图库预览关闭后偶尔无法恢复焦点。失败附件证明原按钮已经脱离 DOM，页面上同一作品的新按钮仍存在。

根因是 `watch(() => [route.query.compare, route.query.batch], …)` 每次返回新数组。搜索 / 标签同步 URL 时会误触发整个作品库重读，切换 loading 状态并重建展墙。已改为分别监听 compare 和 batch 的实际值；普通筛选不再重读库。新增用例在旧实现上失败，修复后通过；原浏览器焦点断言保持，正式串行复验通过。
