# 办公机工程尾项交付

本轮承接用户确认的三项工程尾项：聊天归档并发、剩余保存失败补偿、Live2D 检查与导入校准。起点 `0502f13`，原工作树干净。主会话负责接线、浏览器验收与集成；三个独立子任务分别处理归档、保存/导入服务、模型检查与前端复审。没有安装桌面包、调用生成模型、下载素材或修改生产角色/场景数据。

## 实现范围

- **归档**：IndexedDB 专用记录成为权威来源；同源跨窗口锁保护新增、单角色/全部清空及恢复。逐角色清除世代拒绝旧窗口待提交数据，旧 localStorage 仅作首次迁移源。保存成功后才裁剪源对话，失败保留原消息。备份仍输出兼容的归档 JSON，恢复与作品元数据同事务写入；暂不可用的本机角色归档保留。
- **保存补偿**：本地图片入册在回执丢失时读回记录及图片身份；备份批量写入失败后核对全部目标键。已发布按成功处理，无法确定则保留原图和设置，只有确认未发布才补偿。清理失败包含操作编号和图片 ID，不静默删除未知结果。
- **模型检查**：支持完整 Cubism 3 文件夹；前后端独立拒绝路径穿越、链接逃逸、大小写重复、缺引用、异常 JSON 和超限资源。限 512 文件、单文件 64 MiB、总 256 MiB、JSON 4 MiB/32 层、纹理边长 8192 且不超过 32M 像素。包含 UserData、纹理、动作、表情、物理及姿态引用。静态候选和运行时实际参数范围分别呈现。
- **导入与校准**：房间/桌宠角色区提供按需加载的模型工作室。文件检查→独立预览→实际参数枚举→口型/眨眼端点校准→本机持久化→角色列表。支持反向端点、模拟音量、作者动作/表情、视线预览、停止复位、草稿、撤销、指纹绑定配置导入/导出、版本冲突检测、上一配置回滚和停用。停用保留文件、聊天和记忆；重新载入后角色目录生效。
- **运行边界**：新校准配置使用浏览器后端，不假称原生参数校准已适配。停止预览取消异步表情预留，关闭/切换释放会话和资源；校准能力保持待设备验证。作者声音不在新文件预览中自动播放。模型来源与许可必须填写，不自动推断人格或音色。

## 验证与修正历史

首轮归档 Web Locks + localStorage 在真实双页中复现丢失新增和清空复活，已改为 IndexedDB 权威记录后复验。静态模拟没有被用来关闭该问题。

浏览器首轮发现窄屏角色设置浮层中的新入口被对话区遮挡，入口已移到角色区可达位置。宽/窄、深/浅校准流程采用中性隔离夹具，保存请求在浏览器测试中拦截，后端真实写盘在临时目录单独验收。

真实宁宁模型的原 8192² 纹理超过新导入像素上限，被正确拒绝；实际预览测试只对隔离副本将纹理缩至 2048，未改原素材。真实预览又发现 SDK 对 blob 依赖 URL 的解析问题，以及首版取景把人物放到画布外的问题；保留失败记录，后续用实际画布像素和截图验收。预览依赖另限 96 MiB/编码后 128 MiB，避免扩大临时内存；不改变原有已接入模型的运行资源策略。

首次构建聊天页闭包超原预算，改为加载模型时才载入浏览器后端及参数枚举；不提高预算。首轮质量检查发现新增浏览器测试的换行和 CI 分组登记问题，已修正；完整执行日志和后续复验分别保存，不把首轮失败写成通过。

## 主力机交接

按部署指南同步本次最终源码及匹配构建后，仍需完成安装/UAC、升级回滚、WebView2/多屏/DPI、真实模型/音频、GPU 与长期运行验收。模型工作室仅支持上述有界 Cubism 3 导入；ZIP、Cubism2 新导入、原生端点校准和新模型的来源采购不在本轮交付中。旧已接入模型不因新导入约束被重写。

素材逐图审核、提示词最终 Token/画面对照、长期架构演进以及已暂停的研究任务继续按 roadmap；本轮不把这些额外事项伪报完成。旧摘要删除墓碑继续保留，不以数量裁剪冒充已确认水位。
