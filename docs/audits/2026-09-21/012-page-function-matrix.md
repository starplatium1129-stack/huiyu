## 跨页面必须走通的完整旅程

J01 新用户→教程→场景→绘制（模拟）→入册→重新打开；J02 热门角色/服装/蓝图→绘制→查看实际请求；J03 剧本夏目→绘制/分镜→返回；J04 色彩/画风→工作台→保持角色草稿；J05 作品→重做/比较/视频→正确ID；J06 备份→中性新库恢复→重载与搜索；J07 房间→桌宠→独立聊天窗→断线重连；J08 失败/取消→任务中心→恢复原结果；J09 维护临时库→预览→冲突→保存→读取；J10 普通/远程/桌面只读与不支持能力→合法恢复入口。
