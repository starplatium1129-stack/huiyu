# 绘制台、角色档案与作品查看器精修

2026-10-01。以 b76b7611 的画布简化与成片显现为整合基础；本轮修改展示、交互和动效，不改角色内容、服装、蓝图、提示词或生成参数，不调用真实模型，不安装或发布桌面包。

## 完成范围

- 绘制台顶部介绍合并为紧凑两行，1920×1080 CSS 视口中的画布起点由约 257px 上移至 191px。保留大画布、默认侧栏比例与独立配方弹窗，降低素材/参数分组的边框密度；结果架预览的工具带有独立空间。
- 入册状态连续显示等待、保存中、已入册。保存按钮变为作品册链接时延续键盘焦点；用户已移到其他控件时不抢焦点。
- 角色卡与档案用一个共享图片代理连接。240ms 内分别补偿裁切框和原比例图像；快速反向从当前可见几何开始，落位后同步恢复真实图，避免中间双像。返回恢复卡片焦点和阅读锚点。
- 宽桌面档案固定肖像/阅读两栏，角色和粒子/原画切换不再由图片自然比例改变结构；较窄窗口按可用空间堆叠。卡片、目录、人物名与资料的文字层级保持双主题一致。
- 作品查看器把缩放控件放到画面下方独立工具带，信息面板用留白与安静的表面分组；滚轮、拖动和键盘缩放即时响应，保持指针落点。
- Toast 采用 220ms 入场、140ms 同路径退场，从当前 WAAPI 状态连续响应；拖拽暂停过期、限制单指针并释放捕获。应用和系统的减少动态效果偏好均即时生效。
- Select、Popover、Combobox 沿 Reka 的触发点出现；菜单、标签、按钮采用既有 120–160ms 节奏。键盘选择/按压/关闭不播放移动补间，菜单关闭立即恢复焦点。

## 验证

恢复后的受控源码完成 16 个关联 Vitest 文件、89 项行为断言：角色 31、查看器/通知 40、保存/内容反馈/选择器 18。应用类型检查、定向 ESLint、双主题全局及角色颜色检查、动画合成器门禁、500 行门禁与构建体积预算通过。ESLint 仅保留测试多组件/console 类警告。

4 个关联浏览器文件共 21 个场景已通过：完整批次保留 20 个通过证据，最后的模拟生成/取消/失败/重试/保存场景修复旧工具入口选择器和 Toast 移除等待竞态后定向重跑通过。该修复保留“工具可达、通知确实移除、保存完成”的断言；未放宽校验。浏览器后端使用隔离 Rust 夹具，图像/模型请求使用本地替身。

深浅主题各检查以下实际 CSS 视口，覆盖绘制台、角色卡、档案、查看器和受影响菜单。合计 48 个页面/主题/视口记录；主要文字与控件现场抽样最低对比度 5.33:1，无横向溢出、绘制主行动仍可达，查看工具带与图像区域分开。图片上的文字仍以实际截图审查，令牌通过不视为页面全部内容的自动认证。

## 动效复核

使用 apple-design 指导实施，按 review-animations 的标准复核并闭环以下问题。

| Before | After | Why |
| --- | --- | --- |
| 下拉箭头在混合键鼠路径仍补间 | 捕获浮层中的键盘输入，删除高频搜索框箭头补间 | 键盘即时反馈 |
| 低优先级规则未覆盖按钮键盘按压 | 受影响页面使用明确优先级覆盖 | 键盘激活不缩放 |
| 共享图片与真实目标提前淡入交叠 | 全程只显示一个代理，终点同步交接 | 消除双角色重影 |
| 通知打断会先跳到终点 | 从当前 WAAPI 状态接续 | 连续响应 |
| 查看工具带内距挤压画面行 | 工具带独立布局且不额外撑大行高 | 控件不遮作品 |

结论：Approve。没有剩余阻塞项；动态属性限 transform/opacity，减少动态效果、取消、后台和卸载释放均已覆盖。现场捕捉共享过渡的进入、返回与快速反向中间帧，只有一个图片代理，完成后清理，焦点与滚动位置恢复。
