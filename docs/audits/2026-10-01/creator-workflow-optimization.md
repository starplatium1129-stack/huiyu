## 已完成范围

| 工作包 | 交付行为 |
| --- | --- |
| 保存、任务入册与图片导入 | `appendArtwork` 仅确认提交，单条读取核对已有作品与未知应答；成功保存增量更新历史，并拒绝旧加载覆盖新记录。未知提交保留原图，不反复回读全库 |
| 首页最近作品 | 桌面一次原子读取 id／原始时间／revision 摘要，再取三个正文；保留 JS 日期、ID 回退、稳定排序、取消和版本一致性校验 |
| 图库整理 | 批量加入／移出画册、独立 `collectionTags` 与条件撤销；同步作品和 `history_ids`，保留生成词条。退出选择模式后仍可撤销；单组最多 64×200 幅，防止活跃撤销记录提前失效 |
| 工作台布局 | 默认三栏回到原 `clamp(...,21rem/26rem)` 比例；可调宽度保留画布下限，窄窗口适应当前 CSS 空间。侧栏显示与复位收进一个“布局”入口，拖动和键盘均可调宽 |
| 配方检查 | 原作生成字段与当前编译／提交投影逐项比较，缺失保留未知。复用真实 SD 请求投影；检查按需打开独立弹窗，不占画布高度；场景推荐与专家参数明确区分 |
| 候选对比 | 仅看差异参数、同步缩放／移动、键盘操作和复位；最多两路原图读取、四个自有 URL，关闭和停用释放资源 |
| 导航 | “我的作品”常驻主导航；紧凑桌面窗口维持导航可达 |
| 图片批次 | 每项冻结参数、稳定请求键、接收身份与进度。桌面按窗口角色持久恢复；用户显式继续，已接收项只重连。未通知提交的离页保留 pending，未知接收暂停；清空期间禁止启动／续跑／重试 |
| 媒体清理 | 每 workspace 一个有界发现线程；删除仍回 actor 事务，重新核对 refs／leases、路径与原生文件身份、owner／writer epoch、候选文件版本。取消、关闭和迟到结果保持保护 |

Web 批次计划覆盖同标签页刷新。传统 SD／Anima／Krea 有接收 ID 时只 GET 重连；没有接收 ID 的未知状态不重新提交。终态必须绑定原 ID，读取错误不冒充任务失败。批次保存经既有 profile 草稿权威，不双写另一持久任务库。

## 画布收口与实际视觉检查

首版固定像素侧栏上限扩大了默认侧栏，配方表展开时又占用画布高度；浏览器结构通过没有证明观感合格。收到用户反馈后恢复原默认比例，把布局控制收成次级入口，把配方表移出页面流。新增验证明确检查打开配方弹窗前后画布宽高不变，以及旧配方进入工作台后仍保留大画布。

深浅主题覆盖 CSS 视口 1024×720、1280×720、1920×1080、2560×1440、3840×2160；浏览器缩放 100%，DPR 分别按既有矩阵 1／1.5 设置。Windows `AppliedDPI=168` 是当次系统偏好，不代表每屏 DPI；上述 CSS／DPR 不冒充原生、多屏或物理分辨率验收。

另用真实 Rust 网关、隔离上游与真实 896×1344／1344×896 中性 PNG 验证成片展示；两主题四个场景中生成前后画布面积保持一致。测试图只验证画幅与布局，不证明模型画质。人工查看了默认大屏、窄窗口、配方弹窗、整理与候选对比，以及横竖成片截图。

## 隔离性能测量

初始一万条中性作品，三轮交替中位数；真实 Rust Storage actor、旧／新 TypeScript 仓储与保存编排。原始材料位于忽略的 `runtime/artwork-read-optimization/`。

| 测量 | 之前 | 之后 |
| --- | ---: | ---: |
| 单次入册 | 705.08 ms／52 请求 | 4.73 ms／1 请求 |
| 任务结果入册 | 1355.43 ms／103 请求 | 6.65 ms／2 请求 |
| 十条连续入册 | 6243.03 ms／520 请求 | 135.35 ms／10 请求 |
| 首页最近作品 | 602.84 ms／52 请求 | 54.60 ms／2 请求 |
| GC 期间轻量请求的 actor 等待 | 1867.095 ms | 0.0813 ms |
| GC 自身总时长 | 1894.72 ms | 2031.71 ms |

保存计时包含实际提交、媒体核验与隐式全库读取，排除图片上传、尺寸解码；逐轮作品正文与最近顺序 SHA 一致。loopback 夹具省略真实 workspace envelope、认证和压缩，字节计数是解码后的夹具正文，不是压缩网络量。GC 使用一万当前文件、零删除负载；probe 在 GC 未完成时发送，计时包含存储排队。优化改善其它操作响应，没有让清理总时长变短，也没有据此宣称真实生成或整应用提速。摘要、候选发现仍 O(n)，大量实际删除和 staging 整理仍在 actor。
