# 首页、发现列表与导航精修

2026-10-01。第二批在 d0c2efaf 的视觉/动效基线上实施，整合到 27bde11f 的主线状态。范围为首页与创作入口、参考画册、场景灵感和角色场景列表、导航及关联提示/状态。本轮不改配方恢复、任务状态、图库检索或持久化逻辑，不改生产内容/生成参数，不调用模型，不安装发布桌面包。

## 改进

- 首页缩减标题与说明的视觉重量，压紧段落留白，去掉重复边框。保留继续创作行为，补充明确的直接绘制入口；创作预览跟随当前角色。角色图框固定、图片仅 160ms 淡化，键盘与减少动态效果即时切换。
- 首页主视觉有加载/失败反馈和显式重试。重试卸载按钮时，只在原按钮持有焦点且焦点落到 body 时延续到当前角色按钮，用户已移到别处时不抢焦点。Journal 去掉长悬浮位移，Guide 保留轻量且可取消的反馈。
- 浏览区统一标题、说明、标签层级与工具栏分组，减少胶囊描边，修正图像徽标重叠，长故事可在弹层内部滚动。卡片保持固定裁切与静态边缘反馈，移除跟随指针的光纹及重复抬升/缩放。
- SceneCard 只处理卡根自己的 Enter/Space，不再拦截内部故事按钮和绘制链接的原生键盘操作。筛选与返回继续使用既有算法和阅读锚点，不重建持久化逻辑。
- 参考画册刷新时保留当前样张/画册，只显示轻量加载或失败状态；重试恢复后继续浏览。首次空加载和目录不可用仍显示独立状态。
- 导航减少外框密度，更多菜单按组保持明确层级。模块在指针/焦点意图时预热，使用单个下载 Promise；下载期间再次点击、Escape、外部点击/焦点移动均可取消打开意图，下载完成不会抢回输入焦点。
- 工具 Tooltip 和高频全局搜索直接显示/关闭，保留原有焦点陷阱与恢复。菜单初始和加载后的箭头均无补间。搜索算法、数据读取与持久化未修改。

## 验证

8 个相关 Vitest 文件共 38 项通过：首页资源 8、浏览组件/画册导航 15、Tooltip/搜索 15。应用类型、定向 ESLint、双主题令牌/角色强调色、动态样式编译、动画合成器、500 行门禁与构建预算通过；只保留 SceneExplorer 既有 v-html 警告。

6 个关联 E2E 文件共 42 项通过，加上既有故事抽屉的 Enter/嵌套原生对话框/返回焦点用例 1 项通过。覆盖首页真实解码和失败重试、导航取消与焦点、筛选返回阅读位置、参考图详情及返回。新菜单下载取消用例补的是单 Promise 与外部焦点的实际竞态；没有新增套件或为局部样式堆叠字符串断言。

独立 Edge 行为记录进一步确认：搜索面板 transform=none、活动动画为 0，Escape 恢复入口焦点；加载后更多箭头 transitionDuration=0s；系统正常但应用选择 reduce 时，Guide/工具/角色小卡 hover 和导航指针按压 transform 均为 none；Tooltip 无动画。画册刷新 pending/503 后保留同一个卡片 DOM，恢复请求后重试成功。

深浅主题各覆盖首页、画册、灵感列表、角色场景库的六种实际 CSS 视口，共 48 个页面记录：1920×1080、2560×1440、3840×2160、1120×800、1280×720、1707×960。无横向溢出，主要文字现场抽样最低 5.79:1；菜单另以 900/1440 窄桌面与标准窗口回归检查。图片和渐变上的文字同时做截图审查，抽样不等同于全页面自动认证。

矩阵为 Microsoft Edge headless，浏览器缩放 100%，visualViewport.scale=1，默认 DPR=1；不以 DPR 模拟声称原生显示器验收。主机只读查询为 3840×2160、168 DPI（175%）。本轮 IAB 无可用连接，未声明独立 IAB 或原生客户端验收；没有手机/平板适配。

## 动效复核

沿用已核对的 LobeHub 层级/双主题、InvokeAI 内容优先和 Inspira UI 局部交互方向，使用 apple-design 指导并按 review-animations 复核。

| Before | After | Why |
| --- | --- | --- |
| 首图/陪伴图 560ms 缩放、Journal 长悬浮 | 160ms opacity，固定画框与静态图片 | 高频浏览稳定 |
| 菜单下载完成可能抢回输入焦点 | 取消打开意图，保留共享下载 | 连续操作与用户控制 |
| 重试后焦点落到 body | 条件性延续到当前角色按钮 | 键盘路径完整 |
| 搜索、Tooltip 和菜单箭头仍运动 | 高频工具立即显示与关闭 | 键盘/高频操作无等待 |
| 前置 scoped :global 写法丢失后缀 | 完整且已核对编译产物的选择器 | 减少动态规则实际生效 |
| 应用 reduce 仍瞬间抬升/按压缩放 | 具体元素的强优先级静态反馈 | 尊重应用与系统偏好 |

结论：Approve，无剩余本轮阻塞发现。只使用 transform/opacity；快速连续操作、取消、焦点和减少动态效果均已闭环。修正了一个共享图片组件的既有无效 reduce 选择器，没有重做第一批查看器或档案布局。
