# SEC-03 远程内容投影设计

状态：2026-09-21 已接入网关统一远程拦截与审核索引校验。办公机通过中性 HTTP 夹具；真实素材审核、远程页面完整浏览与正式发布尚未验收。未配置审核索引时远程内容返回 `CONTENT_NOT_PUBLISHED`，本机完整库保留。

## 当前接入与运维

`server/remote-content.ts` 在安装资源、预压、参考 release 和普通静态服务之前统一判定 `/data`、`/assets`、`/character-references`、`/scene-showcase`。路径别名、压缩兄弟文件、未知资源、未审核资源均拒绝；本机响应使用 private 缓存，远程投影使用 private/no-store。Range 不绕过授权，已审核图片返回完整已核验字节；远程不复用本机 ETag 或预压内容。

本机运行目录 `state/remote-content-release.json` 是显式发布索引，格式为 `{ "version": 1, "resources": [...] }`。每个条目需有唯一 `url`、`rating: "All"`、完整原文件 `sha256`、`bytes` 和真实人工审核 `reviewedAt`。图片只接受现有资产/样张根内的 PNG/JPEG/WebP/AVIF，拒绝链接越界、私有候选模型和参考库。JSON 源须来自现有公开文件白名单；校验整份源文件哈希后，只投影明确 All、无冲突分级的 ID/名称/分类元数据，不提供配方或原图位置。哈希或索引改变立即失效；读取大小有界，不在用户请求中写发布索引。

该索引是受信本机操作员的人工发布声明，不是自动审核证明。不要把真实源文件哈希填写后直接视作审核通过；没有逐资源决定就保持缺失/拒绝状态。远程配方和完整可浏览媒体目录尚需后续前端接入及实物验收；目前不通过补空提示词让目录冒充可生成内容，也没有自动从旧 manifest 升级发布决定。参考库继续使用独立不可变 release 契约并仅限本机。

回滚可删除该远程审核索引以即时停止远程内容发布，保留本机源与图片。不得撤掉前置授权恢复整库静态访问。HTTP 反例与挑战应答的可复现中性测试在 `scripts/tests/test-remote-content.ts`，已加入 contract 清单。

## 目标与边界

远程共享 token 只获得明确发布的内容投影；本机直连继续使用完整本机数据。请求体中的 `adultEnabled`、前端筛选、图片模糊和已知 URL 都不能扩大远程授权。未知分级、缺少发布决定、来源/版本不一致时 fail-closed。

访问身份只由网关从请求生成：`isDirectLocalRequest(req) === true` 为本机，否则为远程。投影函数只接收已核验的上下文与只读源数据，不读取请求体中的权限字段，也不改写源数据、定稿字段或用户库。

## 远程最小集合

| 资源 | 本机 | 远程初版 | 拒绝条件 |
| --- | --- | --- | --- |
| 场景/角色/蓝图 JSON | 当前完整白名单 | 仅公开目录字段：稳定 ID、标题、作品/角色标签、类别和明确 `All` 分级；不发 prompt、negative、身份 token、LoRA、成人字段 | 缺字段、未知分级、非 All、源版本不一致 |
| `character-reference-view` | 已核验的本机 release 投影 | 先拒绝；待有单独审核发布索引后再提供最小 view | 未绑定 release、任一 reference 未有发布决定或字节哈希不匹配 |
| showcase manifest | 当前本机 manifest | 只投影明确 All 且已发布的条目及其稳定 ID/标题/尺寸/缩略图定位 | R15/R18、未知 rating、未发布或路径未绑定 |
| showcase 缩略图 | 本机已登记媒体 | 仅允许 All 发布索引绑定的 thumb | 无登记、路径不匹配、版本/哈希不一致 |
| showcase 原图 | 本机已登记媒体 | 默认不开放；后续若发布决定明确允许，仍须按 ID 映射提供 | 未单独授权原图、未知分级、Range/路径越界 |
| `/assets` 角色/粒子等运行时媒体 | 本机资源 | 不因拥有共享 token 自动开放；逐类加入发布索引后再接入 | 未列入远程发布索引或身份/缓存边界不明 |

“公开目录字段”不等于公开提示词或原图。远程前端若需要生成，应使用专门的已审核配方投影，不复用本机完整 JSON；没有该投影时展示目录但不伪造可生成字段。

## 服务端结构

1. 新增纯投影模块，输入为 `(domain, source, release, accessContext)`，输出为不可变 JSON/媒体授权结果；本机返回当前行为，远程走最小集合。
2. 在普通静态、预压和 `express.static` 之前选择投影。投影响应不得复用完整源文件的 `.br/.gz`；压缩必须针对投影后的字节生成或由响应层现场压缩。
3. 远程投影响应使用 `Cache-Control: private, no-store`，并按访问身份设置 `Vary`；本机完整数据继续使用当前 ETag/no-cache 规则。禁止共享缓存把本机完整响应提供给远程身份。
4. 图片只接受发布索引中的稳定 ID，服务端把 ID 映射到明确目录内的文件；不接受客户端提交文件路径、URL、rating 或 `mature` 作为授权依据。
5. 参考库继续沿用当前版本化 release 校验；在远程 projection 可用前，`character-reference-view` 与 reference 原图保持本机拒绝策略。

## 验收矩阵

每个数据域和媒体域至少覆盖：本机无 token、远程带有效 token、远程无 token、远程带转发头、未知 rating、All、R15/R18、缺失发布决定、HEAD、Range、identity/br/gzip、304。夹具只使用中性文本和哨兵图片，不读取真实用户素材。

验收必须同时证明：

- 远程响应不含受限字段或原始字节；本机完整响应不被改变。
- 普通路径与压缩路径得到同一投影结果，不能通过 `.br/.gz` 取回完整源。
- 未知和过期 release 拒绝，且不留下可共享的缓存响应。
- 前端缺失字段显示可解释的“仅本机可用/暂未发布”状态，不伪造生成按钮或成功资产。

本设计不包含真实图片审核、批量补图、远程发布切换或桌面安装验收；这些仍属于后续 A6/V01/V02 范围。
