## 执行入口收敛

- Node 清单改为六个直接登记列表，移除“先登记再用多份 Set 重分类”的重复结构。除上述四个删除项外，各 lane 成员和顺序均核对不变。
- `test:optional` 对已登记测试自身变化只派发对应文件，并稳定去重；消费者代码变化仍运行相关完整 lane，配置、未知路径或无有效 CI 基线仍回退全部专项。现有工作流用例同时检查选择计划和真实入口的子进程参数，防止计划正确但实际仍整组运行。
- `validate:all` 在 `npm run check` 后只补其余五个 Node lane，消除重复 check；独立 `test:node:all` 仍包含六个 lane。移除已指向不存在文件的 `test:gallery` 别名。
- CI 测试不再锁住 job 名称、命令完整字符串、cron 时刻及步骤拼写；保留清单不漏不重、真实设备信任边界、官方 Action 固定 SHA、截图上传约束和实际 baseline-fetch 行为。Windows 从现有 Git 安装寻找 Bash，无需改系统 PATH 或跳过验证。
- 实测发现蓝图事务夹具每例复制全库，前八例耗时 177.6 秒，第九例被 180 秒文件预算截断。改为 11 场景、20 蓝图/2 分片及必要关联的隔离基线：346 JSON / 24.27MiB→28 JSON / 449,836 字节。9 个原测试正文完全不变，四个真实校验 CLI 均通过且校验零写入；完整九例 **54.7 秒通过**。生产全语料门禁未缩小，不增加测试套件或放宽时间预算。
- Windows 部署夹具的通知文件改为写完 pending 后同目录原子发布，避免宿主观察半写文件；异步等待命令以保留宿主 stderr/退出诊断。5 秒协议期限、15 秒外层超时及所有身份/退出断言不变。代码竞态已确认，原失败缺少 stderr，不能断言它必然是当次超时根因。
