## Windows 原生边界

使用本机既有 Tauri release 壳的隔离副本，以及本轮源码生成的 UI 和 Rust debug 网关，在系统临时目录创建独立配置、WebView2 profile 和 SQLite 候选。没有操作已安装应用的配置或个人库，也没有安装、发布或调用模型。验证的是本次迁移协议及 UI，不是新安装包的完整发行验收。

原生 `atelier`、`companion`、`companion-chat` 三窗验证：

1. 目录选择未返回时取消，迟到结果不创建候选，也不启动迁移。
2. 原生激活实际完成后故意丢失 renderer 回执，并抑制其他窗口确认，持久来源屏障保留，三个窗口的旧来源写入均拒绝。
3. 恢复另一窗口的消息通道，但移除其握手的 `activeMigrationId`，只读核对仍拒绝解除屏障。
4. 恢复全部真实握手后显式核对成功，各窗口活动身份与磁盘指针一致；激活命令总共调用一次，后续核对没有重发。磁盘指针的备份及恢复候选身份存在。

目录选择器使用受控延迟 Promise/OPFS 夹具，不等同于用户实际选择外部备份盘；原生网关的 SQLite 备份/恢复副本经过真实流程。未覆盖真实个人大库、物理断电、其他机器或所有旧版本。
