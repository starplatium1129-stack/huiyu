# 二级界面与读取性能精修

2026-10-02，主会话与三个子代理并行实施，另做交叉审查。范围为共享菜单/确认框、创作资料导航与搜索、作品库生命周期和 Rust 参考档案读取。沿用樱粉与夜蓝双主题、角色插画和手绘线条图标，无新增依赖。

## 实际改进

- 聊天“更多”采用已有 Reka 菜单能力，统一浮层表面、视口避让、方向键/Home/End/Escape 与焦点恢复；清空操作置于分隔线后。修复菜单关闭延迟抢走确认框焦点的问题。
- 确认说明独立滚动并可通过键盘聚焦、滚动，短窗口保留取消/确认操作，危险操作默认仍聚焦取消。Popover、Combobox 对齐原生 dialog 内的门户归属；这是共享原语边界回归，当前 Popover 页面消费者不在原生 dialog，Combobox 尚无产品消费者。
- 四个创作资料页共享带手绘图标和选中标识的导航；LoRA 搜索有自定义清除、焦点返回和统一空状态，局部隐藏原生重复清除钮；LoRA/剧本详情补齐展开箭头与悬停反馈。移除覆盖 LoRA 卡片最小宽度的旧全局规则，窄桌面窗口不再挤成三列。
- 作品库批量媒体失效合并到一次 DOM 更新后扫描。在同一 60 条合成媒体更新用例中，旧实现扫描 61 次，新实现 1 次，仍加载全部更新媒体。这是 DOM/Observer 工作次数减少约 98%，不是整页耗时或帧率提升 98%。KeepAlive 停用时释放尺寸监听，隐藏宽度为零时保留列数，重入按容器实际宽度恢复。
- 修复作品查看器标签筛选被旧 URL 覆盖：关闭动画可能早于 300ms URL 同步，无条件恢复会清空新标签。现在仅恢复确实被查看器延后的导航状态，并保留较新的本地筛选。初始主线同样存在该问题，回归先复现失败再修复；两主题完整浏览/选择/恢复流程复验通过。
- Rust 参考档案与图片请求改为异步等待共享 reader，30 秒排队上限，断开/关闭后退出等待。排队者不再占用 blocking pool，已开始读盘的 worker 持有锁直至操作结束；首次资源路径探测也移入该 worker。保留本机鉴权、发布校验和访问限制。
