## 图库生产包浏览器联动

使用真实生产包、独立临时浏览器上下文、本地 HTTP 夹具和中性作品记录；模型接口被替代且外部请求阻断，没有读取个人作品库。冷启动 `/gallery?project=round4-album` 的实际资料请求由 **11 → 7**，浏览器 Resource Timing 的响应正文为 **7,890,220 → 1,920,182 B**，减少 **5,970,038 B（约 75.7%）**。夹具未启用压缩，该数值不能称为生产 Brotli 传输减量。

不再请求 `characters.json`、`tags.json`、`presets.json`、`scene-blueprints.json`。阻塞 LoRA 等辅助资料期间，画册筛选及两个匹配作品已可用。离开到绘制台、切换右栏工具再返回时，图库发起新读取并保留原展墙 DOM；注入读取失败后错误与旧作品同时显示，重试恢复。绘制台切换提示词/生成分组前后的中心画布边界完全相同。

深浅主题均覆盖 CSS 1920×1080、2560×1440、3840×2160、1024×720，8 张截图已复核，无横向溢出；窄桌面中重试按钮可滚动到达。错误标题、正文和按钮实测最小对比度为深色 5.33、浅色 6.29，均达到 AA。浏览器 DPR=1、缩放 100%；系统 DPI 未采样，这不是原生 Windows 175% 缩放验收。

首次临时检查把窄窗口下“重试必须无需滚动就可见”当作前提而失败；定位为按钮位于首屏下方后，检查改为正常滚动到达再验证可见性，保留原失败证据。产品代码没有为此修改，保墙、错误及恢复断言全部保留。
