# 安装产物的普通用户审计（2026-10-02）

范围为安装模板、随包离线资源助手、桌面暂存清单和说明。没有运行真实安装、升级或卸载，没有停止当前绘遇，没有访问或修改个人作品与配置；没有修改 updater 或通用 Rust 任务实现。工作区其他会话的这些文件改动不属于本审计。

发现并作最小修复：

- **入口难找**：现成 1.8.1 只创建主程序快捷方式。修复后为选择创建快捷方式的安装添加“绘遇 · 资源安装助手”；升级保留已有入口并为已有主入口补助手，`/NS` 不新增。不覆盖同名的个人链接，卸载仅删目标属于该安装的助手链接。
- **运行中的程序可能被强杀**：旧 NSIS 检查在静默分支调用 `RmShutdown`，而现代界面固定用 `/S` 调用核心。改为只检查主程序和同包网关占用，运行中或状态未知即拒绝，用户退出后重试；不强制结束进程。
- **助手可能选到另一份安装或确认后换目标**：随包助手优先定位自身目录，独立附件仍查卸载登记；确认安装绑定成功校验时显示的程序与运行目录。
- **缺件仍可能成功暂存**：白名单只能保证已有文件被复制，不能保证文件存在。现改为三件套缺失或空文件即拒绝发布暂存，保留上一份完整暂存。
- **说明不足**：在校验阶段检查原生安全取消能力；区分未解压完与完整暂存的重试提示；说明安装阶段取消可能需要先恢复才能启动；保留自定义样张路径不会自动切库。卸载清理二次确认显示执行账户的实际路径，避免跨账户 UAC 下“当前用户”的歧义。

这些修复目前在源码和安全测试产物中，**未重建或替换上述 1.8.1 正式安装包**，没有发布。现有包仍须先手动退出程序再安装/卸载，并通过文件入口打开助手。

## 普通用户实际操作

1. 从官方来源取得配套程序和完整资源 ZIP。保存工作，从托盘完全退出绘遇并等待资源任务结束，再安装或升级程序；按提示由管理员完成 UAC。程序为所有用户安装，普通账户无管理员授权时无法安装。
2. 现成 1.8.1：右键绘遇快捷方式 → 打开文件所在的位置，必要时对开始菜单中的绘遇链接再做一次；在程序安装目录进入 `gateway → tools`，双击 `Install-OfflineResources.cmd`。修复版也可从开始菜单搜索“绘遇 · 资源安装助手”。
3. 用自己的普通用户身份打开助手，选择已下载的 ZIP。核对界面中的程序位置与运行目录；默认运行目录为自己的 `%APPDATA%\com.aics.studio\gateway`，独立配置在高级选项选择对应 gateway。无需源码、开发目录、Node/npm、Python 或手输命令，也无需 E 盘。
4. 等待校验通过，确认已从托盘退出，勾选退出确认后点击“确认安装”。如果仍占用，退出后在同一助手重试，不更换运行目录绕过锁。
5. 取消后等待任务安全结束。进入原生安装阶段后可能保留待恢复事务；用**同一 ZIP**重试完成恢复，再启动绘遇。不要删除尚待恢复的暂存输入。成功后重新启动，检查角色原图、场景卡片与样张画册；模型及其运行环境另行准备。
6. 卸载时保持“清理账户数据”不勾选，即默认保留作品、配置和导入资源。仅在自己确需清理时核对二次确认中的实际路径。外部作品/独立目录不在该清理范围，其他用户的数据也不会一并清除。

保留承诺针对用户资料和导入库：程序安装目录的随包文件属于升级替换/卸载范围，手工修改这些文件或把作品放入安装目录不受此保护，应另存副本。

更完整步骤见[离线资源安装指南](../../guides/offline-resources.md)。

仍需在获得真实操作授权后确认：重建最终包的安装后文件/开始菜单点击；干净 Windows 的 WebView2/VC++ 前置、SmartScreen/UAC；独立标准账户及跨账户管理员授权；真正无 E 盘机器；程序新装、升级、卸载和重装后的个人数据；约 1.28 GiB 官方包 GUI 全流程、取消恢复与重启断网浏览；1080p/QHD/4K 系统 DPI/分屏/键鼠。权限拒绝、磁盘耗尽、断电与安装检查后立即重启程序的并发场景也未做实机注入。

本次不要求新增后端接口。现有 `offline-import --cancel-stdin`、最终结果 JSON、目录锁与恢复协议足以支持此次修复。原生导入不提供可靠百分比，因此界面保留不定进度；如果以后要求逐文件进度或查询恢复状态，应另提接口需求，不在本轮修改 Rust 任务逻辑。
