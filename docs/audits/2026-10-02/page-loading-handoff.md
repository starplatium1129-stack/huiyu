# 页面加载衔接核查

2026-10-02，从安全 main `a6014f88` 建立独立分支 `codex/round6-loading-experience-oct2`。本轮只处理实际加载反馈和过期失败提示；没有调整页面动效时长、缓存架构、图库请求策略或绘制右栏。

## 保留的机制与核查结果

- `AppLayout` 没有 `out-in` 串行切换。实测旧页退出 140ms、新页进入 180ms；本轮样本新页约在旧页开始退出后 14ms 开始进入，没有等待其完成。缓存返回为 120ms、透明度从 0.88 恢复，未重播初入动画。该观测用于确认衔接，不是性能基准。
- 慢路由等待时旧绘制台仍在，加载状态出现；中途改去图库后，旧成功回执没有改变目标页面。返回绘制台仍是原缓存节点。快速往返、同页面查询和浏览器返回的既有用例通过。
- 减少动态效果会清理活动页面动画，返回页面不再 inert；完成后 `aria-busy` 清除。没有修改全局扫光、Telegram 消散或生成聚像。
- 双主题分别延迟首页两张真实已有图片；等待时改选夏目，再依次完成宁宁、夏目图片。迟到的宁宁加载没有夺回选择，夏目真实解码后移除加载提示。图片区加载前后尺寸同为约 638.89×598 CSS px，坐标一致。
- 第四轮图库 `loadHome/loadLoraCatalog` 和旧墙保留实现未改动；本轮仅核对图库路由返回，未重复模拟图库刷新或大库请求基准。右栏五组及草稿/滚动/焦点逻辑未改动，也未处理主线程正在修复的旧 selector、生成错误展示用例。
