## 用户可见结果

- API 服务商切换不再沿用上一家的密钥；重复点击当前服务商保留已编辑的地址、模型和密钥。各服务商草稿独立恢复，清除密钥反馈可见。自定义模型仍能自由输入，原生 datalist 换为已有 StudioSelect，编辑模型不会抹掉发现列表，端点或凭据变化会清理旧候选。
- 语音设置改为入口按钮锚定的统一浮层，支持视口避让、内部滚动、键盘操作及关闭后回焦。原先在 1097×617 CSS 视口中，622px 高的表单从 y=406 开始，被 419px 高且 overflow:hidden 的聊天卡片裁掉；现在保存和关闭均可通过真实 Tab 操作滚入浮层可见区域。表单采用容器宽度决定列数，补齐手绘图标、按钮换行和焦点。
- 全局搜索在模态窗口占用键盘时不打开不可操作的底层弹层；首次懒加载和已加载两条路径均覆盖。短窗口约束整体高度，结果区独立滚动，头尾操作保持可见；键盘选择行保留滚动边距。
- 任务中心关闭时卸载结果预览，取消图片读取、释放 Blob URL 和媒体授权刷新。播放器卸载会显式暂停并移除来源、重置加载。筛选与展开任务保留，重新打开同任务时具体结果索引回到第一项；运行时任务与已保存结果不受关闭影响。
- 单视频取消会停止旧轮询；迟到的运行状态不再覆盖取消结果。分镜页面 KeepAlive 停用时中止只读请求，返回后刷新；重试、取消等写操作期间暂停轮询，过期错误不再污染新状态。离页不取消运行时已接受的生成任务。
- Rust 已缓存媒体的文件身份复核不再等待两个完整哈希名额：最多四个轻量身份检查并行，冷文件仍由原来的两个哈希名额约束。文件身份变化仍走完整校验，保持路径锁、工作区所有权、取消与关闭排空。旧实现的暖缓存阻塞用例实际失败，修复后通过；未据此声称真实大图库的整体加速比例。
