已接通的核心路径

  • 官方 Diffusers Anima 独立 Python 子进程：文生图、图生图、兼容角色 LoRA、手绘与自动 CLIPSeg 蒙版重绘。仅使用可信本地资源，不启动/导入 ComfyUI。
  • 蒙版参与每步采样，复用同一噪声恢复下一步参考，并保留最终原图遮罩外像素。自动分割先在 CPU 完成，再加载 Anima；不宣称与旧采样器/模糊核效果相同。
  • 应用内引擎、模型/LoRA目录、解释器与worker配置，当前/已保存状态、重启提示、依赖/CUDA诊断。默认仍为既有引擎，native不静默回退。
  • 任务进度、拥有者输入保护、不可变输入副本、取消/超时/进程清理与独立后端身份接入现有任务协议。共享session中遗留的手绘拦截已单独修复并补回归测试。
  • 提供不下载的运行库计划/离线wheelhouse准备入口：创建venv前强制完整依赖dry-run，拒绝直接URL依赖，安装完成复用worker完整诊断；桌面打包包含独立worker、蒙版/CLIPSeg和转换工具。

未知/多余/冲突键与错误形状拒绝，不静默丢弃张量。保存后复核键/形状/dtype和tokenizer token ID，校验worker目录布局；最后发布模型索引，不覆盖原始权重或现有输出。不是对所有 MiaoMiao 版本的泛化兼容承诺。
