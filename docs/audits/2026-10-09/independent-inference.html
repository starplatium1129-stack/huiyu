结论

已实现无 ComfyUI 的 Anima 文生图候选代码路径，接入原有 Rust 任务链。尚未完成整套替代，也未通过 Rust 编译或真实 GPU 出图验收。不会发布、合并或修改用户电脑。

本次实现

  • 真实 Diffusers worker：官方 Anima modular pipeline，显式本地组件类与 safetensors，离线加载、实际采样进度、PNG 原子写出；每任务一个子进程。
  • Rust native provider：环境变量选择，默认旧引擎保留；现有任务身份、结果权限和收集 hooks；GPU 串行、超时、取消、进程清理、重启中断报告。
  • 独立运行库：新的 venv 与回执，默认只读预览，显式从可信本地 wheelhouse 安装；不联网下载、不复用 ComfyUI、不覆盖既有环境。桌面暂存包含 worker、清单与准备器。
  • 现有权重检查：有界 safetensors 头部检查、结构/配套资源报告；官方转换器固定 2B 配置不匹配时明确阻塞，不盲转 MiaoMiao 变体。

实际支持与缺口

候选独立路径目前仅支持完整本地 Diffusers 目录的 Anima 文生图、CUDA、单张 PNG、原生 FlowMatch Euler 调度。状态仅报告文件可用性，不把它当作 GPU 就绪。现有 MiaoMiao 裸单文件仍需模型特定转换与配套材料，真实文件本轮不可用。

图生图、LoRA、mask/CLIPSeg、原图回贴、TeaCache、Remacri/RealESRGAN、RCAS、Krea 2、SDXL、低显存/offload 尚未接入此独立切片，明确拒绝或列为未支持。依赖代码许可证与模型权重许可分别处理；没有搬运 ComfyUI GPL 代码。

尚未提供完整签名 Python/CUDA 发行包和首次安装配置 UI。因此不能宣称已实现“安装后放一个权重即可生成”。

最小下一步

  1. 先在授权的 Rust 环境编译并运行新增 native 定向测试，解决任何编译/行为失败后才进入实机。
  2. 准备专用 venv 与完整本地 Anima Diffusers 模型，运行 worker 的 --validate，另检查现有单文件的转换阻塞。
  3. 主力设备退出 ComfyUI，设置 HUIYU_IMAGE_ENGINE=native，测试一张图、取消/再提交、结果入册与重启；记录模型哈希和显存。
  4. 依据各 MiaoMiao 真实 shape 实现转换，逐项补回高级功能，再完成安装器运行库管理。
