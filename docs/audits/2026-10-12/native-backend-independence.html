Native 生图后端接入续报

本轮补齐 Anima 独立引擎的控制室入口与显存交接，修复非有限推理输出可能被转成正常 PNG 的漏洞。已有六模型 GPU 记录属于上一轮，本次没有新增真实出图或速度结论。

本次改动

范围完成的源码行为
绘图优先按活跃引擎选择入口。Native 检查独立 Python/worker 文件，在生成时按需加载；保持已有空闲驻留，不启动 ComfyUI。普通 API 与持久任务进入 GPU 前停止应用持有的 llama.cpp。
聊天显存交接聊天／语音优先及 llama.cpp 加载占住全部 native 任务准入，检查 GPU 槽，停止空闲 Worker；权限保留到启动与健康检查结束。已有 prepared、排队、运行或结算任务时明确忙碌，不自动取消生图。
退出未确认Native 关闭后续准入和 GPU 槽，排队任务按真实取消状态结算并保留失败原因。llama.cpp 保留退出未知标记，停止等待结束和新进程启动前复查；句柄消失不再等同于显存已释放。恢复需完全退出并重启应用。
结果保护VAE 实际输入与原始解码输出在显示 clamp／PIL 转换前检查；Latent 首轮在放大前检查，Remacri 在 raw core clamp 前检查。异常拒绝发布；采样、量化与蒙版合成保留原数值路径。
控制室状态展示活跃引擎与独立入口文件状态，Native 模式不再因 ComfyUI 离线误报等待绘图；文件存在不表示依赖、模型或 CUDA 通过。同步修正项目状态与规划中的过时 TeaCache 描述。
