Native Anima：完成一轮源码对齐与资源优化

2026-10-12。参考现有 Anima 工作流与固定 ComfyUI 版本，补齐分阶段显存管理、共享组件冷切复用和高清张量清理，并修正采样基础差异。当前仍为待 CUDA 验收的替代候选，默认引擎仍是 ComfyUI。

本轮实际改动

  • 低显存：新增本机设置 inference.memoryPolicy，默认 resident；offload 在 Qwen、conditioner、transformer、VAE 实际 forward 间切换整个组件，去噪循环内保留 transformer，Remacri 前卸载 Anima。采用已锁定 Diffusers ComponentsManager API。LoRA 融合逐组件在 CUDA 完成，再回 CPU。
  • 冷加载与切模型：GPU packed storage 从跨组件共用改为组件＋dtype 分开，单个组件能释放自身存储。利用既有完整字节哈希计算组件摘要，跨底模复用精确 class/dtype 与字节都一致的 Qwen、VAE、两个 tokenizer；只有 encoder＋两个 tokenizer 实际复用才保留原始文本缓存。已适配 transformer/conditioner 不跨底模复用。
  • 高清：释放首轮结果和二轮输入的过期张量，解码前释放 Tea 残差，非蒙版 Remacri 最终缩放留 CPU，避免无用 H2D/D2H；Qwen VAE 分块缓存卷积计数，保留原 tile 和 blend。普通 VAE 在内部 clamp 前临时观察 decoder 原始输出，补齐 Inf 漏检；逐 tile 仅设备标量聚合，最终合并一次既有读回。临时 hook/方法均在 finally 恢复。
  • 采样：Euler/simple 统一训练表抽样；图生图从完整 int(N/denoise) 网格取尾部 N 次更新，避免 Diffusers 再缩短；两阶段使用 CPU FP32 RNG；取消 native 对 CFG<1 的额外拒绝，下界与产品 0.5 对齐。图生图此前可能少执行更新，本次完整 N 步可能增加单张时间，这是语义修正。
  • 落地：显存策略经过 UI、保存、环境覆盖、依赖诊断与 Worker；旧设置默认 resident。两个新 helper 已登记桌面资源白名单。nativeRuntime 增加 memoryPolicy、componentReuse、samplingRevision，并保留后处理时间；可选观测在 Rust 边界校验。

启用入口：本机控制室 → 绘图引擎设置 → 独立引擎显存策略 → 分阶段加载 → 保存并重启。显式环境覆盖为 HUIYU_INFERENCE_MEMORY=offload。尚无 transformer 块级流式卸载，去噪器＋活跃张量仍须放入显存；更多 CPU 内存与 PCIe 传输是代价，不能承诺任意 4/8 GB 设备可用。

Remacri4x RRDB；512 tile、32 overlap、feather；Lanczos 经 uint8固定权重/路线已接入；仍192 core＋32 halo硬裁拼接和float-channel Lanczos。最终 CPU 路径已精简，拼接/量化待对齐。
Latent 高清与 VAEbicubic、二轮 max(12,round(N×0.6))、普通 VAE，OOM 分块回退倍率/步数/种子沿用；VAE 仍固定512/384分块。临时缓存与生命周期已优化，分块算法/速度及画面仍需设备对照。
