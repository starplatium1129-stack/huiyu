图像准备的重复工作 · 云端续测 2026-10-12 UTC

候选由当前代码确定：手动遮罩先转换 RGB、缩放三色画布，最终只读取 R；普通 RGB 同模式转换及同尺寸 resize 也各复制整图。最终改动只让手动遮罩在原 RGB 转换后选择 R，再用同一 contain／Lanczos／中心黑边几何缩放 L；共享 helper 只读借用已经规范化的 RGB，同 fitted 尺寸省去中间副本，最终仍写入独立新画布。非 RGB 的调色板／CMYK／RGBA 转换保留。上游转置 EXIF 后必要的规范化副本、解码／大小／单帧校验、FP32 除法、nearest-exact、增长、采样和参数未改。

按固定 Pillow 11.3.0 Resample.c 源码，RGB／L 的 8-bit Lanczos 使用相同逐带系数、定点归一化、舍入、裁剪及中间量化；Image.py 同模式／同尺寸分支只做 copy，无 mask paste 复制到目标，不共享源像素。新画布原本不继承 EXIF/info，未关闭或修改借用源。主会话与独立审查据此保留 manual v3／Tea 身份；这是固定版本的源码结论，不代替真实设备图像验收。

每 MiB 同步的内部 Bytes 候选：实测收益不足，已撤回

当前 native 完成图与冻结输入都经 Output::Bytes → task_runtime/media::persist → typed task_media_chunk → SQLite worker 内 write_all＋sync_all；不是每步推理写 SQLite。以 b6d371c7 为基线，局部提案将全量 owned Bytes／File 交既有 admitted copy，共用私有 Read＋Seek 流程；删除仅此消费者的内部 chunk API，HTTP Encoded 分块的编码／偏移／重试冲突／每块同步不变。主会话与独立源码审查未发现阻断缺陷，候选 cargo check 与 release 观测工具编译通过，但没有崩溃模拟、行为断言或物理设备验收。

自动遮罩方形增长 · 云端续测 2026-10-12 UTC

本项由 558d2cf35295fd05c5d87021f005ab2cb7d089eb 当前源码确定。与已否决的手动菱形循环不同，自动 CLIPSeg 的 logits_mask 在首次分割和 logits cache 命中后均执行 CPU 方形 max_pool2d；原 k×k 窗口在实际 512–1536 目标、grow 0–32 范围内也有显著工作量。固定 Torch 2.8 CPU 内核遍历每个窗口，仅选最大值；grow6／8／32 的内部像素理论窗口访问 k²=169／289／4225，两轴提案为 2k=26／34／130。这是工作量推导，不等同于实测吞吐比例。

最终只替换增长段为水平 (1,k)／padding(0,g)，然后垂直 (k,1)／padding(g,0)，stride仍1、dilation默认1、ceil_mode默认false。阈值比较后的 .float() 是精确 FP32 0/1，原方形和两轴取同一 Cartesian 裁剪窗口的 max，没有浮点加和／除法；默认不返回 argmax、输入不需梯度，两轴 tie 的索引次序不被观察。每个窗口含中心，同轴 negative-infinity padding 保持边界和形状，grow0仍跳过。CPU 池化按 input.suggest_memory_format 与输出尺寸生成 canonical layout；两次保持 N1C1/H/W，同一 canonical NCHW／NHWC 都是布局识别固定点，因此最终 strides／后续原卷积分派条件保留（输出分配、布局识别）。固定依据：CPU MaxPoolKernel 与 2.8 max_pool2d 参数契约。

原前平滑及后三轮浮点 reflect blur 的每一行、阈值、clamp、非空／finite检查、模型前向、phrase 顺序与重复、checkpoint指纹／owner／缓存与取消路径全部不变；没有把浮点模糊改为不同平均顺序，也不将本项套给手动遮罩。临时两轴 Tensor 是每次调用私有结果，无新增共享状态。主会话与独立源码证明支持保留 clipseg-single-image-vision-v1／Tea scope；这是有限二值 selector 的固定实现结论，不宣称真实边界图像已验收。
