暖模型身份检查相同精确模型路径与有序 LoRA 路径、原连续保护有效时，直接复用独立 SHA 身份副本，strength 取当前值。每暖身份检查递归 inventory 由三次降为零，不再重开全组文件、祖先目录和通知句柄。保留文件写入 / 删除拒绝、父目录与子树通知及加载后复核；另核对实际驱动器映射、精确路径大小写，大小写碰撞与不支持路径保守回退完整哈希。只支持能证明连续保护的直接固定本地 NTFS；首次、映射 / 目录变化或失效仍用原完整取得路径。映射复核为边界快照，不能保证抵御管理员强制瞬时重映射。未延长 120 秒驻留，未更改模型数学或 Tea 档位。
内容批量写入经过既有场景定稿校验的批次，共用一次解析的基线，提交 / 预览返回前再完整读字节核对；普通 N 个已有场景批次由 N 次读取 / 解析降至两次读取、一次解析。依赖变更用首项索引，减少不断增长的线性查找，省去修改前的整份 JSON 比较拷贝；策展只读场景 ID，退役只解码相关文档。逐记录保护字段及校验位置保持；快照终检发现基线变化则拒绝整批，数据库后备基线经 seed 更新后失效。专用定稿文档导入、未触发场景定稿校验的批次沿用原校验，不纳入新增字节终检保证；最后读文件与提交之间仍有原文件系统竞态。引用顺序、重复项、缺键 Null 插入、修订与 history 保留。相关文档继续完整解析；无关文档的 JSON 损坏不再阻断定向退役。没有修改真实内容、保护基线或提示词。
