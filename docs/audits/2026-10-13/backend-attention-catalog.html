2026-10-13。本轮完成三处优化，无新增依赖、数据库迁移或生产内容写入。以下收益为源码操作量推导，尚未测量实际耗时、峰值 RAM / VRAM 或端到端提速。

范围实际改动与收益边界与取舍
默认 Anima 注意力native 也安装现有 Cosmos processor，仅对精确的原始 processor 类型生效，省去重复因子为 1 的 K/V 拷贝。1024²、4096 图像 token、28 层、16×128 heads、BF16、CFG 两分支全部执行、24 步的示例，仅 self-attention 就省去 42 GiB 累计拷贝载荷写入及同量读取；不计 cross-attention，且不是峰值显存。保留 projection、QK normalization、RoPE、非单位重复和 native attention dispatch；没有启用 Sage 或 compile。K/V 存储布局会改变，当前 CUDA 内核表现及像素一致性未验收。native 独立更新执行身份，旧 native Tea 档在 auto 回退完整计算、严格启用时拒绝；Sage 三模式身份保留。
大 Live2D 依赖组超过 64 MiB 的组复用已有并发 hash-only flight，随后各 body 单独读取并验证目标文件。同一 flight 内，N 个请求的全组哈希读取由 N×G 降为 G＋各目标文件字节合计。示例：200 MiB 组、12 个重叠请求、目标合计 200 MiB，2400 MiB 降为 400 MiB。保留整组每个文件的 SHA256、长度与路径检查，以及响应前挂载身份复核；不缓存已完成校验，不扩大 64 MiB 整组保留预算。串行请求没有共享收益；单个 body 请求会多读一遍自身文件。大组现也受原 flight 的两工作者和 60 秒等待约束；目标文件 body 分配沿用原路径。
内容导入与批量写入比较阶段的两条查询移到循环外准备，N 条导入从 2N 次语句准备调用降为 2 次；put、history、seed upsert 复用连接已有语句缓存，写入循环复用 current 查询。已解析 incoming records 直接移入 seeds，省掉一整份记录数据及元信息的深克隆。保留记录顺序、退役标记、重复身份拒绝、修订 / 本地冲突、逐条校验、history、预览回滚与 pin 基线终检。JSON 解码、changes / diff 分配、真实 SQL 执行次数仍有成本；缓存淘汰或 schema 变化可重新编译。未修改任何提示词、定稿基线或工作库内容。

执行身份与源码依据

新增 native 身份 cosmos-v3-native-no-kv-repeat-v1，由共用 teacache_profile.RUNTIME 覆盖产品选择、采集、拟合、评估、接受与安装。README 和 runtime manifest 同步说明当前边界；anima-workflow-effects-v3 和自动遮罩身份保留。

核对本机 Diffusers 0.41.0 的原始 Cosmos forward 和 native dispatch。重复因子为 1 仍复制的依据为 PyTorch 2.8 固定版本实现；native 的 GPU 内核由参数及设备约束选择，见 固定版本 SDPA 选择实现。旧设备成绩不能验证本轮新 native 路径。
