范围实际实现与收益保留边界
CLIPSeg 单图视觉编码查询图像只执行一次 CPU FP32 视觉编码，按已安装 Transformers 5.10.1 原 forward 选取 hidden_states[extract_layer+1]，每批四个短语的 decoder 使用只读 expand。32 个短语由处理 32 份相同图像降为 1 份；视觉塔调用由 8 批降为 1 批。decoder 与文本条件仍保留原分批。保留短语顺序、重复权重、短尾批平均、77-token 拒绝、完整加载 / 模型字节校验、finite logits、阈值、增长及羽化。没有跳过 decoder 或后处理，也不代表总生成耗时降为 1/32。
同图修改遮罩提示词最多保留一张图的选定视觉层 CPU 副本，张量 payload 上限 16 MiB。完整模型字节、执行版本、图像 mode / size / 像素 SHA-256 相同时，改短语可跳过视觉塔和图像预处理；原 mean-logit 与 64 KiB 条件缓存继续工作。仅成功生成遮罩后写入，超限不保留视觉层；模型变化、异常与 worker 退出清空。缓存独立拥有选定层，不持有完整 hidden-state 集合。上限不包括模型、临时张量或整个进程 RSS。
中日翻译分句 LRU在常驻模型锁内，仅把去重后的未命中片段送入 generate，最终按原顺序恢复全部分句及重复段。只改一段时，已缓存的其余段落不再生成；全命中不调用 generate。最多 512 段，源文与译文 UTF-8 payload 合计不超过 2 MiB。保留分句规则、源文本、规范化、换行拼接与 HTTP / stdin 响应协议。缓存绑定实际已加载 tokenizer / model 对象、beams 和规范化函数；新实例 / 策略变化时清空。磁盘替换不热重载已加载权重。批次数量完整、译文全非空后才入缓存；异常或不完整输出不新增记录。对象数量也有上限，2 MiB 不等于进程 RAM 上限。
