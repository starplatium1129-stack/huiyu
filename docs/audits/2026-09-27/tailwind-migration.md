# Tailwind 全站样式迁移

日期：2026-09-27。开始时工作区干净，基线 `a81ee1f0`。目标是将现有 Vue 应用的常规样式迁到 Tailwind，同时保持主题、布局、交互和内容边界。未改提示词、模型请求、内容登记或生产资料。

## 实施范围

- Tailwind CSS / Vite 插件固定 4.3.3；测试使用同版本 Node 编译器。Web 与 desktop 构建共用入口。Firefox 最低支持版本经用户确认由 113 调整为 128，其余浏览器目标保持。
- `tw:` 前缀、现有 reset、未分层 utilities 与 `@theme inline` 的运行时主题别名。没有启用 Preflight、引入第二套色板或安装 shadcn。
- 公共控件、业务组件、页面与共享/路由样式中的常规声明使用模板工具类或原选择器中的 `@apply`；原有媒体条件、状态选择器和测试 hook 保留。
- `@apply` 保留原 specificity 的场景包括浮层、共享控件、父子组件覆盖和复杂组合选择器。背景/font shorthand、材质、遮罩、关键帧及动态原生窗口定位仍用必要 CSS。仅包含主题变量、材质或 import 的文件无需制造工具类。
- 页面直接引用的旧声明在迁移时删除，不保留双写兜底。字体、手绘 SVG、双主题令牌、分级与数据访问行为保持。
- 场景卡、色彩卡和查看器样式改由真实消费者按需导入；构建使用官方编译器跳过已支持的 `color-mix` 冗余回退，保留 `@property` 回退，详情和移除条件记在 Vite 配置及维护指南。
- 颜色、字面量和动画门禁增加工具类取样，覆盖模板、TS 完整类名映射与 `@apply`，防止把违规从 CSS 藏到 class 中。主题对比度解析支持前置 `@reference`。
- Showcase 布局契约现在验证实际编译 CSS。浏览器旧用例修正为当前角色 Select 的键盘交互，不再误把按钮当成输入框。另修复既有浏览器测试图片类型收窄和两个文件混合行尾，保证验证入口可运行。
- 本次改动覆盖 103 个 Vue 文件、80 个 CSS 文件（含 10 份外置控件样式及 Tailwind 入口）。未改的 Vue 主要为无独立样式的组合组件或使用已迁移的外部样式；纯变量、材质、import 入口和独立首帧占位仍保留必要 CSS，不宣称“零 CSS”。
- 部分公共控件外置 `@apply` 样式，避免扫描 Vue style 块时再生成一份未在模板使用的工具类；保持原来的 scoped/global。聊天的归档、个人档案与长期记忆面板改为打开时懒加载，其行为和主题通过真实菜单操作验收。语音设置 code 标签原有 5px 圆角收敛至 `--r-xs`（6px），由新增取样范围检出，未放宽门禁。

迁移规则及后续维护见 [Tailwind 样式维护](../../guides/engineering/tailwind-styling.md)。一次性转换/展开审查脚本仅存于被忽略的 `scripts/archive/`，不构成新增运行时或长期转换层。
