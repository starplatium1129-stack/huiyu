## 本轮性能测量

Windows、Node 24.18.0、无头 Edge 154.0.4258.37，三轮串行新上下文。真实 GlobalSearch 的 script/template 与真实索引函数通过现有 esbuild/Vue 编译器打包；仓库、路由和外围组件为隔离夹具，未连接应用后端、模型或用户库。夹具包含 10,000 条作品（每条 prompt 2,035 字符）与 2,000 条场景。每轮索引 10 次，三类查询分别更新 20 次；表中为三轮中位数的中位数，结果文字及顺序逐轮一致。

| 测量项 | 之前 | 之后 |
| --- | ---: | ---: |
| 索引构建 | 19.2 ms | 13.2 ms |
| 打开空面板，含组件挂载与场景夹具索引 | 58.7 ms | 33.7 ms |
| 空面板触发的 readHistory 次数 | 1 | 0 |
| 常见词命中，含 Vue/DOM 更新 | 13.1 ms | 0.2 ms |
| 全库无匹配，含 Vue/DOM 更新 | 15.7 ms | 8.9 ms |
| 找到最旧作品，含 Vue/DOM 更新 | 13.4 ms | 6.3 ms |
| 首条非空查询，旧版此前已建好索引 | 18.9 ms | 39.2 ms |

首次输入承担了延后的读取/索引成本，不能把最后一行宣称为提速。新版本该项三轮为 30.5–51.0 ms，存在冷启动与 GC 波动。微基准没有网络、真实 SQLite 分页、图片、CSS 动画或 GPU 成本；没有把这些局部数字换算成整应用提速百分比。关闭后组件丢弃索引有明确代码与行为证据，未测量进程堆回收量，也不代表桌面离线历史快照一并释放。

原始采样、源码 SHA-256、前后源快照、日志及截图保留在忽略目录 `runtime/performance-simplification-2026-09-30/`；一次性工具位于 `scripts/archive/global-search-audit.mjs`，不登记为常驻维护能力。
