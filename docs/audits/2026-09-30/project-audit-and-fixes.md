# 项目多维审计与修复

> 日期：2026-09-30；范围为当前源码、隔离运行时及桌面浏览器。开始时工作区干净；本轮未调用真实模型、安装、部署或发布。

本轮审计安全与数据边界、持久任务、资源回收、前端异步、桌面布局与键鼠交互、工程门禁及构建交付。确认的问题已合批修复，不把结构测试、模拟上游或浏览器 DPR 视为真实模型、设备和安装验收。

## 已修复的问题

| 范围 | 复现的问题 | 修复和回归边界 |
| --- | --- | --- |
| 构建文件边界 | 旧 manifest 中的 `server/../../…` 可令孤儿清理删除项目外文件；输出或缓存经链接可覆盖外部字节 | 拒绝非规范相对路径、symlink/junction 和目标硬链接；所有待发布产物先统一预检。隔离回归保留外部哨兵字节及正常缓存复用断言 |
| 任务身份与内存 | 不存在或非所属任务的 reconcile 先分配执行绑定，再返回拒绝，重复请求留下无效记录 | 身份验证提前到绑定分配和锁等待之前；旧实现回归真实失败，修复后通过 |
| 丢弃结果与媒体 | 部分输出提交后丢弃任务，未提交输出 lease 仍占用资源；迟到 commit 在持久引用判断前发布文件 | 发布前拒绝 discarded 输出命令；丢弃事务释放待提交 lease；未提交 staging 按原保留期回收。双输出、部分提交、丢弃、迟到提交和 GC 有行为回归 |
| 视频草稿与任务重连 | 旧图片读取可覆盖用户新帧或在卸载后重建 Blob；旧任务 404 可清除新任务记录 | 核对帧/任务身份与生命期，取消过期读取；只由当前请求修改状态 |
| 视频页面与上传 | KeepAlive 停用后继续轮询；旧环境应答覆盖新状态；换帧或卸载期间完成的图片写入留下孤儿记录 | 停用停止页面查询，恢复后继续读取；中止过期上传并回收其自有图片。已接收任务继续保留重连身份，不由离页取消 |
| Windows 工具路径 | Git 返回长路径，TEMP 使用 `ADMINI~1` 短路径，合法同一目录被交付/内容审计误判为不同工作树根 | 双方按 native 实路径与 Windows 大小写规则比较；保留子目录拒绝、Git 零写入与路径越界断言 |
| 专家工作台大屏 | 三档 CSS 视口下三栏宽度只有 1776/2240/3104px，外层页面 cap 锁住画布空间 | 仅桌面专家模式解除 max-width，保留原边距和侧栏约束；原可用宽度、滚动、焦点及按钮可达性断言复验 |
| 隔离夹具可靠性 | sibling junction 删除顺序造成清理失败；Git 初始化 symlink 能力探针留下不可跟随的目录项，干扰全 `.git` 字节快照 | 复用既有安全清理器先撤销链接；夹具固定 `core.symlinks=false`，只在临时仓库关闭自动维护。没有删除有效断言或延长原超时 |

源码主要位于 `runtime-rs/src/task_runtime/`、`runtime-rs/src/storage/`、`src/components/video/`、`src/composables/video/`、`src/assets/css/director/atelier.css` 与 `scripts/`。没有修改角色、服装、蓝图、提示词、定稿场景或参考数据。

当前交付为源码、网页产物和 Rust release 候选；已安装的 1.7.4 仍是原已签名版本，本轮没有桌面同步、NSIS、UAC、安装或发布。真实模型、视频/语音效果、原生 Live2D/GPU、长时功耗、大规模用户库、物理断电和其他设备仍按 roadmap 的对应条目验收。本轮没有开展新的性能基准，不把取消无效查询或补资源回收转述成未经测量的整体性能提升。
