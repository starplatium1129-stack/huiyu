### 图库空筛选释放观察节点

旧 `scanWallCards` 在结果为空时先返回，没有解除旧卡片的 IntersectionObserver 观察与 Map 引用。已排队的旧回调随后可以读取已不可见作品的原图。

现在先解除旧观察并清空映射，再判断是否需要扫描新墙；同时拒绝卸载后的延迟扫描。既有缩略图合并、8路并发和过时队列取消保持原样。

确定性 Vue/Observer 夹具对真实旧源码执行失败：筛选至空后投递旧回调，`getImage('image-1')` 被调用1次。相同回归对修复代码通过：无用读取为0、观察节点为0，清空筛选后正常读取1次。这里证明读取调度与资源引用修复，不是浏览器帧率或真实数据库耗时测量。

### Rust mount 命中前过滤与缩短锁范围

旧资源 overlay 在确认快照是否包含所求路径之前，先在全局状态 mutex 内读配置/current 并执行挂载资格核验。仅内置资源的未命中请求也承担这一成本，磁盘核验还串行阻塞其它请求和关闭操作。

现在锁内只取快照、检查路径成员资格；未命中直接返回原 bundled fallback。命中仍按原逻辑在读取资源前后核验配置、current、路径与完整资源字节，但把 mount 控制文件核验移到锁外，回锁确认配置及快照的 Arc 代次、active/closed。失败只撤销本代次，旧结果不能发布或撤销刷新后的同 identity 快照。

中性夹具统计实际控制文件读取：10次旧未命中机制读取配置20次、current 10次；新路径均为0。命中仍执行核验，改变配置字节仍撤销挂载。另以真实文件读取 checkpoint 验证锁可被未命中请求取得、关闭后不发布，以及相同 identity 刷新时旧成功/失败结果均不能影响新代次。checkpoint 仅在 `cfg(test)` 中复用已有测试设施，不进入产品构建。

以上仅为控制文件读取量与锁范围证据，不声称整个应用同比提速。首次 refresh、status 的锁内磁盘工作未改；GC、聊天导入和恢复观察等更宽候选没有扩展实施。

## 追加的相邻问题与验证

用户要求继续修相关问题并提交后，fetch 确认远端仍是同一基线；保留首次全部改动，限定审查图库加载、资源读取及异步状态。

1. **停用图库不再改写下一页 URL**：取消 KeepAlive deactivation 前排队的300ms筛选同步，并在调度和发布处检查页面活跃状态。旧代码两项确定性回归都发生了非预期 `router.replace`；最终回归还覆盖重新进入后正常同步。
2. **缺图/暂时失败可在返回时恢复**：原图释放时清除 missing-image 负缓存。旧代码在当前 KeepAlive 实例中持续把短暂传输错误和曾不存在的图片记为缺失，返回图库仍不重新读取。两项回归分别复现；同一次活跃期间继续抑制重复读取，避免失败重试循环。
3. **后台缩略图按当前请求归属发布**：每次异步生成持有临时token，删除、显式发布或更新的生成使旧结果失效；完成/失败后按token清理在途记录。旧代码三项回归分别复现删除后缓存复活、旧生成覆盖显式预览、迟到旧生成覆盖新结果。新测试同时验证失败后可以重试，没有永久失败标记。
4. **关闭资源服务立即请求停止读取**：Service 增加由gateway shutdown派生的只读任务child token，close在等待状态mutex前取消。overlay GET/HEAD/304及snapshot核验沿用现有512KiB checkpoint协作停止。管理任务、回滚授权和父gateway token不改变。这里只停止在途读取/哈希，不宣称close已经等待所有overlay worker完全退出，也不改请求断开语义。
