# 可选玻璃材质：轻盈与液态

基线 `1793c45`。按用户要求提供适合办公笔记本的低成本默认材质，以及可主动开启的液态玻璃。参考 [Apple 材质指南](https://developer.apple.com/design/human-interface-guidelines/materials) 的控制层、层次与可读性原则；这是网页实现，不是 Apple 原生 Liquid Glass 渲染器。没有新增依赖或调用子代理。

## 使用与实现

入口为「更多 → 外观与动态效果 → 玻璃材质」。

- **轻盈玻璃**：默认。用静态底色、渐变与内侧高光表达层次；关闭背景滤镜，不创建 SVG 折射、Canvas 贴图、表面 ResizeObserver / IntersectionObserver 或全页面 DOM 观察器。
- **液态玻璃**：手动开启。复用已有圆角边缘折射实现，用于导航、工具条和绘图操作条，正文不扭曲。贴图仍受 360 像素边长、32 项缓存、12 个同时使用表面的上限约束；避免嵌套折射。
- 液态样式按需加载，设置卡片首次打开才加载；不扩大原入口 CSS 或路由预算。浏览器能力检测不通过时使用静态磨砂回退。
- 切回轻盈、文档隐藏、系统高对比度/减少透明度/强制颜色生效时释放已拥有的折射资源。恢复可见且偏好仍为液态时重新建立。
- 在已有 `atelier-desktop-appearance-v1` 中增加 `glass: light | liquid`，缺省、旧数据及未知值均为 light；不自动用硬件参数猜测设备性能。首次绘制前恢复材质，切换即时生效，跨窗口同步。
- 原「降低玻璃效果」和系统辅助显示设置优先生效，但不覆写用户选择；动效偏好与材质选择独立。

同时修复 `RouteAtmosphere` 的 scoped/global 选择器：旧写法会把 `display:none` 应用到根元素，导致降低玻璃效果时整页不可见。新写法只隐藏背景氛围层。绘图操作条的液态规则也明确覆盖旧静态材质规则。

## 性能边界

Headless Edge、1440×960、隔离上游，在同一页面按轻盈 → 液态 → 轻盈采样，每段滚动 1.4 秒：两主题轻盈档均为 0 折射滤镜/贴图，液态档为 2，返回轻盈后为 0。六段采样的 RAF 间隔 P95 为 8.4–8.5ms，未出现 >32ms 的间隔。数据为 `performance.json`；文字像素采样为 `pixel-contrast.json`。

这证明本轮场景的资源开关和调度行为，不是 GPU 时间、显存测量或低端设备性能认证，也不能据此承诺所有设备达到 120fps。未安装桌面版、未测试真实办公笔记本/高刷屏/电池功耗，不改 Live2D 的质量设置，不调用真实模型。
