# GitHub 参考方案落地与既有提交复审

2026-09-19；基线 `95b48c7`。全程单会话执行，没有调用子代理。研究依据见 [原调研](github-reference-research-2026-09-19.md)。本记录区分代码实现、隔离验证与真实设备验收。

## 落地范围

| 方向 | 本次实现 | 保留边界 |
| --- | --- | --- |
| P1 / Tag Autocomplete | 本地 tags 适配为 canonicalTag、zhLabel、aliases、category、description、source/version；手输、随机、反推、草稿和 Remix 写入同一 manualTags 归一入口。歧义别名不猜测，权重与 LoRA 大小写保留；中文/英文/别名搜索和原生键盘补全共用词典。 | 没有复制 A1111 DOM 注入代码或第三方词库，没有建立第二套翻译数据。 |
| Dynamic Prompts | 情绪家族与色彩联动迁入版本化数据；固定 uint32 种子、1–8 个有界候选、界面三组预览、应用和 JSON 种子/配置快照导出。重放函数使用快照中的标签、服装与身份排除集，并拒绝版本不兼容。 | 保留原随机约束与三引擎编译。导出是机器可重放的配置；界面可用固定种子重抽，但本批没有新增任意模板语言或 JSON 文件导入器。 |
| P2 / PhotoSwipe | 固定 5.4.4，按需加载。作品信息栏内「尝试手势观画」进入试验，「返回原查看器」退出。滚轮/双指缩放、拖动、切图交给 PhotoSwipe；业务、键盘、焦点与滚动锁继续由 Gallery 持有。原图异步读取、真实尺寸解码、邻图缓存上限与关闭释放均由适配层管理。 | 默认查看器未替换；单一 dialog / focus trap。浏览器触摸模拟不是实体触屏或 Tauri 手势验收。 |
| P3 / 测量 | 新增固定图库、20 次开关、DOM/Blob URL 趋势探针，复用 3,000 条历史的首屏 60 卡与全库搜索测试。SD 请求组装与快速参数应用按需加载，沿用原包体预算。 | 不以 DOM/URL 数冒充 GPU/纹理/进程内存；009 四类 KeepAlive 真机趋势仍开放。没有证据支持新增 TanStack Virtual。 |
| P4 / SwarmUI | 图像与视频共用阶段规范，区分 submitting、queued、loading、generating、cancelling 与终态；未知进度保持 null，未知阶段待检查。任务中心兼容原存储状态；失败/取消后新任务不覆盖旧记录。视频执行同时核对 online、available、executable 和输入模式。 | loading 仅在上游明确报告时使用；未根据时间或文字猜测模型加载，也未迁移后端。 |
| P5 / InvokeAI | 恢复热门/工作室角色决策、项目、种子、合法零值和手选参数；清理旧草稿残留，保护恢复结果不再被初始化推荐覆盖。支持字符串作品 ID。后端校验后的底模、LoRA、尺寸、采样参数变化进入可关闭的常驻配方检查栏。 | 旧作品未知引擎不静默执行；缺字段如实提示。Prompt 按当前角色/编译器重建，检查栏明确说明，不声称逐字原参复现。 |
| P6 / AIRI / Open-LLM-VTuber | 停止时撤销播放器监听/超时/预热请求，旧播放 Promise 与翻译不能写入新会话；重播停止可结束等待；音量 0 保留；后台停止口型帧循环。角色清空确认绑定发起时身份，卸载后异步初始化不能再启动轮询。 | 沿用注册表、Profile、Tauri 与 Live2D 两后端；真实 TTS、设备音画同步与原生窗口仍待验。 |

Reka UI 与 fflate 的引入条件本次均未触发：已有焦点管理能承担本批单层浮层，备份格式也未变更。没有为覆盖参考清单而安装它们。

| 恢复完成后生命周期再次应用推荐尺寸/蓝图底模；深链成功 toast 覆盖兼容差异。 | 区分历史恢复与推荐初始化；统一输出持久检查栏，后端发现完成后记录实际差异。 |
| 图片旧请求失败时会清空新查看器 URL，复制提示与缩略图异步回写缺少生命周期约束。 | URL 失败分支增加代际守卫；复制逻辑归入导出模块并清理定时器；销毁后的缩略图回写被丢弃。 |
| SD 取消使用中文状态文本推断，已停止可能被识别为失败/旧图成功；提交延迟时取消可能漏掉被接受任务。 | 显式任务状态、局部 controller、迟到任务删除、延迟初始化取消与输入冻结测试。 |
| 同一任务 owner 在失败或取消后重试，旧终态被覆盖；视频只检查 available。 | 新建重试摘要并保留旧记录；video executable 能力进入实际提交守卫。 |
| 语音 stop 只暂停元素，未结束重播 Promise、旧 timeout 和事件；预热存在 A→B→A 竞态。 | 显式取消句柄、代际及 AbortController；模拟音频覆盖旧事件、重播中断、迟到翻译和预热响应。 |
| 清空对话确认期间换角可能操作新的 activeChar；卸载后初始化仍可能建立状态轮询。 | 清空操作绑定目标角色并检查仍有效；异步初始化各等待点检查 disposed。 |
| 浅色主题下深色观画层的按钮沿用了普通页面暗文字。 | 观画操作使用 on-art 文字/边框/背景令牌，双主题重新截图。 |

## 依赖与来源复核

唯一新增运行依赖是 `photoswipe@5.4.4`，锁定版本。npm 元数据本次返回 MIT、解包约 1.2 MB、最后修改 2024-05-24；不能据此宣称维护高频。官方文档说明 v6 开发中，因此本批维持可退出 Spike，不改默认查看器。源码核对了 contentLoad、缓存移除、destroy、键盘和 viewport/appendTo 接口；发行包许可完整保留于 `public/licenses/PhotoSwipe.txt`，随构建发布。
