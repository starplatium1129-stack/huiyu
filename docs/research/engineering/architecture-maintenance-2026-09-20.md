# 生成链路与工作台维护性整理

基线 `db0b9a1`。按用户要求单会话实施，不使用子代理；隔离工作区保护主工作区现有的页面和样式改动。本次处理生成路由职责混杂、工作台状态与存储耦合、相关边界缺乏可靠类型三个问题，不把局部修复记为全仓技术债归零。

## 实际变更

- `routes/generation.ts` 只接收 HTTP 请求、执行身份/限流、返回信封或传输结果。`server/generation/` 分别维护校验、WAI 工作流、资源探测、WebUI 传输与业务编排；直接复用已有 Anima **服务**，不再从 Anima HTTP 路由取得业务能力。既有兼容导出、引擎优先级、成人门控及已提交 Comfy 任务不自动重试 WebUI 的语义保留。
- WAI 请求、状态和 WebUI 任务使用明确类型；网络返回保持 unknown，目录名称逐项解析。LoRA 和采样器查询不再接受原型链属性。业务错误保持状态码和 code。
- WebUI 探测缓存归属每个服务实例；提交使用新探测，旧探测晚到不得覆盖新缓存。关闭服务会清理 WebUI 定时器和结果，晚到的结果不能复活已关闭任务，关闭期间的提交不能创建新任务。
- 工作台通过 `usePromptDraft`、`usePromptSceneFilters`、`usePromptArtworkHistory` 分别管理草稿、显示筛选和作品存储适配。Store 保留现有公开接口和创作状态；草稿公共恢复字段只有一处实现，计时器随 Store 作用域释放。
- 工作台目录经过 `promptCatalog` 校验，不再用 `as unknown as` 声明整批数据有效。角色特征显式兼容字符串与结构化条目；工作室特征面板只消费结构化条目。真实目录的字段、扩展信息及提示词字节由回归比对。
- 保存作品在调用开始时复制输入、上下文及兼容默认值，覆盖等待暂存、写图和测量期间的变化。用户此时切换故事或项目不会改变待保存记录，输入数组不保留外部可变引用。作品格式、ID、暂存保护、记录成功后发布和失败补偿路径保持。
- 保存准备与持久化实现分开：同步捕获快照，首次保存才加载持久化用例，减少工作台首屏代码。包体预算保持原上限，工作台主块为 139.7 KiB / 140 KiB，工作台静态闭包 530.0 KiB / 580 KiB。
- ESLint 增加生成服务/工作台适配依赖方向检查及本次模块禁止显式 any 的规则；新增允许/拒绝夹具。已有业务类型的间接依赖门禁继续保留。
- 修正基线中两份浏览器测试的 Window 扩展声明，取代不兼容的断言，不改变测试运行逻辑或断言。
- 聊天契约测试使用自有临时 SPA 页面、共享 CSS 副本和中性数据夹具，真实网关继续验证路由回退、CSP、缓存和压缩，不再依赖开发目录已有的 dist。
- 两项聊天记忆浏览器回归改用按钮的可访问名称定位，避免复用的样式类选中“复制”；保留记忆写入成功、失败可重试及后续 system prompt 的全部断言。

## 验证

完整入口 `gate:full` 在 `AICS_REFERENCE_AUDIT_MODE=structure` 下通过，耗时 5 分 50 秒：19 项质量检查、1,016 项前端测试、1,073 项 Node 单测（另 2 项环境跳过）、34 组契约、生产构建和原包体预算通过。参考素材只核对结构，不代表实物验收。

完整入口之后，仅追加 WebUI 切换上游地址时的缓存失效修正和对应生成契约回归；重新执行严格运行时/测试编译、受影响文件 ESLint（0 error，既有测试夹具 any 警告保留）及 `test-generation-routes`，均通过。前端、存储和工作流源码没有再改，复用其已通过证据；不把完整入口日志写成末次源码重新全跑。

中间失败记录保留：换行和浏览器夹具声明、旧模块接线断言、干净工作区缺少 SPA 构建、工作台包体超限。分别修正源格式、声明、新适配器接线断言、自有夹具及按需加载；未放宽预算、超时或删除行为断言。

48 组 WAI 参数正规化及工作流与 `db0b9a1` 逐项深比较一致；两份浏览器声明修复擦除类型后的 JavaScript 与基线完全一致。

浏览器选择 `flows`、`random-inspiration`、`github-reference`、`compare-snapshot-lifecycle`、`library-concurrency`，隔离端口偏移 19000，使用模拟上游和独立浏览器资料。首轮 49/51 通过，两项旧记忆选择器修正后定向 2/2 通过，共 51 项分批覆盖；不把首轮日志改为全绿。生成/队列入册、配方/草稿恢复、跨页清理互斥、双主题取消/恢复、结果对比和查看器生命周期均在此次范围内。

本机日志位于隔离工作区 `runtime/architecture-maintenance/`：`browser.log`、`browser-memory.log`、`build-verified.log`；完整入口记录为 `gate-delivery.log` 与 `reports-delivery/`，末次增量为 `final-runtime.log`、`final-generation.log`。首次失败日志保留在同目录，不混用历史通过记录。

定向回归覆盖草稿合并写入/作用域释放/损坏输入、原场景与编辑后场景恢复、真实目录兼容性、保存时切换项目和数组修改、WebUI 状态并发及新旧探测、服务关闭、任务归属、原型属性拒绝、路由选型和失败后不重复提交。

## 边界与回退

本次无用户数据迁移、依赖安装、真实模型调用、桌面安装或发布。生成图的文本/工作流构造沿用原实现；不将隔离上游测试视为真实出图或设备验收。

保存时快照防止**保存开始后**状态变化，不能替代每个生成入口在**任务提交时**捕获完整配方。A02.2/3 的入口盘点与迁移、旧记录缺失事实、提交结果不确定时的核对、补偿失败诊断仍是明确的后续边界。其他生成引擎和全仓旧 any 不在本次已消除范围。

无数据库格式变更，可按本次提交回退。回退会一并撤销保存时快照、缓存代际保护及关闭清理，应保留新增回归作为问题证据。
