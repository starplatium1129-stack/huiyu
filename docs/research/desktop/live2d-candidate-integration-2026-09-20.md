## 适配器与产品行为

- 服务统一处理 Cubism 2/3 引用、中文 URL、原始/标准/节能贴图；缺核心或必需引用不登记为可用。
- 房间与陪伴窗口在初始化前加载本机角色注册表；每个角色使用独立身份、存储键和聊天人格。新角色未配置音色，不借用宁宁或夏目的声音。
- 新增可选择并复位的作者表情；激活表情所用的眼部参数不再被通用眨眼覆写。复位同步清除旧表情状态，避免动作后复活旧表情。
- 浏览器口型按 Profile 范围钳制。实测四个 Cubism 3 模型的口型均为 0–1，默认闭嘴为 0；芙莉莲/菲伦眼睛虽允许超过 1，正常睁眼默认均为 1，不直接照搬 VTube 输入映射的放大量。
- 本机新增模型使用浏览器后端；请求原生时按 Profile 选择浏览器，切回原生兼容的内置角色可恢复原生选择。
- 多角色小窗采用顶栏选择框；首次模型可见后立即居中，不依赖绝对定位舞台触发 ResizeObserver。
- 本机接口拒绝远程/转发请求，原始候选路径和未登记导入文件不通过通用静态资源接口开放。
