# 项目未来规划

整理日期：2026-10-09。本页是未完成事项的唯一入口，合并原 004 / 009 / 010 / 013 计划及旧审计剩余条件。当前实现与安装身份见[项目状态](project-status.md)。文档整理不执行下述模型、设备或发布操作，不把历史通过记为今日通过。

## 当前优先级

1. **内容一致性与回归维护**：固定提示词长度配额已按 studio-prompt-craft 移除，sc009／sc027 正文未改。四项过时内容约束及 Rust 格式失败在 PR #69 中修复，保留 SFW 可选、角色／衣装有效关联、分级与成人隔离、当前道具载荷保真；不改定稿内容来凑类别、衣橱或形状配额。后续依照[现行契约](engineering-contracts.md#角色接入)维护回归，源码检查与真实渲染分别验收。旧长度失败只保留为[历史记录](audits/2026-10-09/fullstack-performance.html#content-warnings)。
2. **目标安装版验收**：源码、公开发行与已安装程序分别核对。使用[部署入口](desktop-deployment.md)检查源码、构建、EXE/DLL、资料保持和重启身份，UAC 由用户操作。
3. **真实模型与设备**：明确能力、机器与范围后取得对应证据。原生许可材料 releaseReady=false / pending 继续登记，不等同已审批。
4. **按测量优化**：图库冷进入仍有 56–72 ms 长任务样本；同机同负载测量后决定改动，合成浏览器样本不代表原生 WebView2、GPU 或长期趋势。

旧 Node 产品后端已退出；Rust 网关、持久任务、SQLite workspace、内容记录库及既有界面改进不再列为待开发。主力机承担模型、显存、音频、多屏和休眠验收，办公机/隔离夹具仅证明相应代码行为。

## 性能、陪伴与 Rust 专项

### 009：性能

S03/S08、高刷、高负载、四类 KeepAlive、GPU/纹理/进程内存与功耗继续开放；F7 目标设备按 V05/V07 合并。S01–S08 的操作保留在[验收清单](architecture/acceptance-checklist.md#性能场景009)。测量冷/热进入、首次操作、长任务、释放和多轮静置趋势，保留失败和撤回方案。3,000 条分页、DOM/Blob URL 探针不足以证明需要引入虚拟列表。

### 010：陪伴与 Live2D

滚动/阅读位置、取消/换角隔离、能力接线、检查器和有界 Cubism3 本机导入校准已实现。剩余为 C6/C7 真机组合、原生参数枚举及端点校准、未支持模型与来源/自制决定；ZIP/Cubism2 新导入另定范围。检查器枚举不证明语义映射正确，内置 Profile 需浏览器/原生配对证据才从 needs-confirmation 升级。具体 UX/L2/AV/PF/RC 场景见[清单](architecture/acceptance-checklist.md#陪伴场景010)。默认 Tauri 与原生线程；独立进程和 Electron 正式采用另定范围，不恢复旧 Node PoC 产品路径。

### 013：Rust 与发行

旧 server/routes/services 及 legacy 测试 lane 已退出，维护工具归 scripts/lib；旧协议/指纹/库格式由固定夹具和独立 SQLite 检查承接。剩余原生来源/许可材料、真实模型、支持升级跨度内旧库、实际远程分享与目标机器；不能启动第二后端同时写 workspace。Windows 符号链接拒绝用例因权限错误 1314 保留未验证，不关闭断言换绿。

## 创作、研究与接线

- 叙事、人物壁纸和手机壁纸分别小样对照：固定 checkpoint/参数/seeds，保留全部输出和硬条件失败，核查最终请求与画面。[指南](guides/README.md#prompts)与[研究来源](research/README.md)不是本地画质增益证明，不自动扩批或更改定稿。
- 角色绘画工具当前只准备草稿。接受控队列时明确 queued/running/succeeded/failed，真实出图验收后再启用图片成功结果与奖励。
- PhotoSwipe 保持按需试验，实体触屏、Windows/Tauri、大图集缩放/拖拽和资源趋势对照后再决定替换默认查看器；fflate/压缩待实际 manifest/原图包需求。
- 剧情内容按明确题材和批次开展，不按历史配额机械扩写。粒子肖像按[现行管线](guides/characters/particle-portrait-pipeline.md)维护。
