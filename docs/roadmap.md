# 项目未来规划

本页维护未完成事项与后续验证规划。当前系统实现与已登记状态见 [项目状态](project-status.md)。

## 当前优先级

1. **内容一致性与质量**：按 [工程契约](engineering-contracts.md#角色接入) 维护角色与服装关联，核对编译 Token 与真实出图效果。
2. **目标安装版验收**：统一使用 [部署入口](desktop-deployment.md) 验证源码构建、EXE/DLL 产物、升级数据保留与启动身份。
3. **真实模型与设备验证**：针对目标显卡与环境验证 Anima、Krea 2 与短视频生成的真实出图、显存占用与异常恢复。
4. **性能与体验调优**：按实机测量数据优化图库冷启动与长任务耗时，避免推测性提前优化。

## 专项边界

### 性能与资源 (009)
- 实机测量图库冷/热进入、长任务占用及多轮静置下的显存释放。
- 保证桌宠隐藏及图库离页时可靠释放 GPU 上下文与内存图片引用。

### 陪伴与 Live2D (010)
- 验证真机环境下的原生渲染线程、参数校准与内置 Profile 适配。
- 保持原生窗口与宿主间的生命周期同步。

### Rust 网关与发行 (013)
- 验证无压缩升级包与完整 LZMA 包的构建绑定与文件清理。
- 确保运行时单实例持有 workspace，防止多进程并发冲突。
