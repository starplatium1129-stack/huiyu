## 维护边界

聊天/工作台/视频/分镜防抖、归档、凭据和 profile 写入先确认；正在输入法组合、生成/导入、媒体写入、未提交编辑或保存失败均拒绝维护。各参与者随组件生命周期注销。`cancelled` 解冻；封闭准入后失败进入 `blocked`，保持写入冻结但允许用户从托盘正常退出，不自动继续安装或重复提交任务。

已接受但尚未写入 submission intent 的任务在关闭时保留为待显式恢复，不误标验证失败。新宿主的维护状态确认其自身和认证网关就绪；页面显示另由实机验收证明。

部署先只读预检并备包/构建，再请求退出。`-InstallerPath` 固定实际包并传过 UAC，避免并行构建导致选包漂移；父进程等待并返回安装真实退出码。旧版无协议时明确要求正常退出，不尝试未知 CLI 或强杀。

## 实际安装中发现并修复

- 原凭据授权仍要求浏览器来源等于旧 HTTP 网关，错误拒绝 bundled UI。读写现在复用既有受信来源规则且仅允许三个登记窗口，未知窗口/旧端口/外站仍拒绝。
- 隔离 profile 的凭据另用路径哈希命名空间，候选验证不读真实用户 vault。唯一测试 endpoint 的真实读取、写入、读回和清除通过；生产命名不变。
- PowerShell 5/7 对 JSON 整数分别产生 Int32/Int64，实例检查现接受有效 PID 范围内的两者。
- Windows 批处理的中文帮助发生解析错误；入口帮助改为 ASCII，中文说明保留在 PowerShell/文档，模拟失败退出及帮助输出已验证。

首次安装 `ee08ac5a` 后，维护正确拒绝了一次失败凭据保存。未绕过保护；用户确认自行保留配置并退出后，再经唯一部署入口安装修正版 `1eae9ba7`。最终 EXE 全部字节与所选 NSIS 包内 payload 匹配，宿主/网关启动确认通过。

聊天、草稿、作品、项目、迁移记录和 workspace pointer 与最终安装前快照保持；设置仅新增 `aics_live2d_quality_v1`。后续维护探测因当前打开的编辑面板返回 `cancelled / OPEN_EDITOR`，窗口继续运行，没有为了复验强制退出或替用户提交配置。最终安装未开启生产 CDP；图片完整操作复用同前端源码的隔离候选证据。
