# 设备与外部条件验收清单

> 维护各专项需要实际设备或外部环境验证的稳定检查项 ID；优先级、状态与调度排期统一维护在 [未来规划](../roadmap.md)。

---

## 1. 执行边界

- **记录要求**：实际验证需登记源码/构建标识、环境、视口尺寸、系统 DPI 与应用缩放。**严禁将孤立截图或模拟结果当成真实设备通过**；已退役的 SD 新生成不再测试，仅保留历史任务查询、取消与旧作品验证。
- **连通性预检 vs 专项验收**：笔记本可执行轻量连通性检查（服务连通、模型加载且请求进入处理后即可停止任务）；以下画质、性能与跨设备场景属于专项验收。

## 2. 性能场景（009）

| ID | 操作与要求 |
| --- | --- |
| S01 | 首页 → 场景 → 绘制：测冷/热进入与首次操作响应 |
| S02 | 绘制 → 作品 → 返回：保持草稿/KeepAlive，不误取消已接受任务 |
| S03 | 场景/热门滚动、输入、清空筛选与返回锚点复现 |
| S04 | 作品/样张打开后立即关闭：检查焦点、滚动与 Blob 释放 |
| S05 | 连续 A → B → C → 返回：最终意图正确，迟到结果不覆盖 |
| S06 | `chat`/`companion-chat` 与普通页安全策略切换、任务确认与重启 |
| S07 | Live2D/语音与真实生成并发时复测 S01–S05 |
| S08 | 20 轮往返、隐藏/最小化/休眠恢复：资源单例、不补播、不累积 |

> F7 需绑定实际安装版在 WebView2、60/120 Hz、双主题/减少动态及 4K 150% DPI/多屏下按空载、语音/Live2D、生成负载分别记录 CPU/GPU/内存。
