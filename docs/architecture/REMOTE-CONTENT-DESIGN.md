# SEC-03 远程内容投影设计

> 远程拦截与审核索引契约由 `runtime-rs/src/remote_content.rs` 承接。未配置发布索引时拒绝远程内容（返回 `CONTENT_NOT_PUBLISHED`），本机完整库保持不变；真实素材审核与后续拓展见 [未来规划](../roadmap.md)。

---

## 1. 访问身份与安全边界

- **身份判定**：完全由服务端 `security::is_direct_local(headers, peer)` 生成上下文（本机直连 vs 远程共享 token），绝不读取请求体中的权限字段。
- **全分级支持与隔离**：本机直连可访问完整数据；远程访问仅限已列入发布索引的内容（成人向内容在目录缩略图保留 R18 默认模糊遮罩，但遮罩不替代访问授权，未审核或未知分级一律拒绝）。
- **前置拦截顺序**：`remote_content.rs` 在安装资源、预压文件（`.br`/`.gz`）、参考 release 及普通静态服务之前统一拦截 `/data`、`/assets`、`/character-references`、`/scene-showcase`；拒绝路径别名、符号链接越界、私有候选与参考库。
- **缓存隔离**：本机响应可用 `private` 缓存；远程投影响应强制 `Cache-Control: private, no-store` 且按身份设置 `Vary`，禁止向远程复用本机预压文件或 ETag。

---

## 2. 显式发布索引 (`state/remote-content-release.json`)

格式为 `{ "version": 1, "resources": [...] }`，作为本机操作员的显式人工发布声明（仅由离线/管理入口维护，不在用户请求中写入；删除该文件即可即时回滚并停止全部远程发布）：
- 每个条目须绑定唯一 `url`、合法 `rating`（`All` / `R15` / `R18`）、完整原文件 `sha256`、`bytes` 及人工审核时间 `reviewedAt`。
- **图片来源限制**：仅限合法资产/样张根目录内的 PNG / JPEG / WebP / AVIF；客户端仅凭稳定 ID 映射文件，不接受任意路径或评级参数。
- **JSON 来源限制**：仅限公开文件白名单，须核对整份源文件哈希，任何改动或哈希不一致立即失效。

---

## 3. 本机与远程投影边界

| 资源域 | 本机行为 | 远程初版投影 | 拒绝条件 |
| --- | --- | --- | --- |
| 场景 / 角色 / 蓝图 JSON | 完整白名单 | 仅公开字段（ID、标题、标签、分类、`rating`/`mature`）；**剥离** `prompt`、负面词、身份 token、LoRA | 缺字段、未知分级、源文件版本不一致 |
| `character-reference-view` | 已核验本机 release | **暂拒绝**（独立参考审核发布前保持本机专属） | 未绑定 release 或哈希不匹配 |
| `showcase` manifest | 完整本机 manifest | 仅已发布且分级合法的公开目录条目 | 未知 `rating`、未发布或路径未绑定 |
| `showcase` 缩略图 | 本机已登记媒体 | 发布索引绑定的缩略图（R18 默认模糊） | 无登记、路径或哈希不一致 |
| `showcase` 原图 | 本机已登记媒体 | **默认不开放**（需单独发布决定并按 ID 映射） | 未单独授权、未知分级、Range 越界 |
| `/assets` 运行时媒体 | 本机资源 | 逐类列入发布索引后按稳定 ID 开放 | 未列入发布索引或身份边界不明 |
