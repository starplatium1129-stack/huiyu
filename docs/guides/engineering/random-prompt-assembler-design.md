# 随机灵感（Random Prompt Assembler）设计边界

维持随机灵感模块的抽样规则、词库字典校验与状态覆盖所有权。全局契约见 [工程契约](../../engineering-contracts.md)。

---

## 1. 词条选择、画师与词典校验

- **画师候选取舍**：缺省候选从 `artistStyles.ts` 轻量白名单抽取；**手动选择优先**，仅同一轮由本模块生成的画师可被重掷替换，关闭随机画师后不残留注入项；切换角色/场景/服装/项目时清除旧单步撤销栈。
- **分类去重与消解**：词条按逗号拆分并在规范化后按分类去重；同族服装/时段/天气可叠加，互斥族系在同类别内消解。近景构图过滤鞋袜；泛化局部特写保守过滤，不改写用户显式手选词。
- **光照与镜头限制**：主镜头与主光照来自结构化控件；额外细节从 `randomPromptConstraints.ts` 已评审兼容表取值，严禁把所有光源、景别混成单个大随机池。
- **词典校验 (`data/tags/manifest.json`)**：显式登记重复词规范 ID 与别名遮蔽；写入前校验重复、悬空 `related`、非法分类/路径与符号链接，暂存同步发布并在失败时回滚（随后刷新 `.gz/.br` 缓存）。

---

## 2. 自由随机与场景变体

- **自由随机 (`randomSceneSettings.ts`)**：先抽取词库支持的地点、可见背景与主光，再匹配兼容动作、衣装、表情与镜头，最后由 `compilePromptRecipe` 分别适配 Anima（标签+补充句）、Krea（散文）与 MOSS（布局摘要）。非默认或参考图覆盖的服装保持不动。
- **已选场景变体**：锁定匹配当前角色的场景与蓝图，保留地点与时段，仅用独立运行时覆盖姿势、服装与摄影（不改写源数据；未解析 ID 不降级为自由随机）。
- **身份与关系保护**：
  - 复用反推身份分类排除固有外貌及种族特征（耳、尾、角等），可穿戴饰品不受此限。
  - 若场景含明确动作、嵌入式 caption 或叙事散文则保留原动作；仅替换可正向识别的独立衣装从句（夹带地点/持物关系的衣装描述与未知镜头描述均保守保留）。
- **覆盖重置与版本**：切场景、重选同场景或载入历史均清除临时覆盖；手改镜头/光照会重算摄影短语（手写英文画面描述优先）。草稿同步保留默认基线与覆盖。
- **随机序列版本**：抽样序列版本为 **`huiyu-random-v3`**（灵感 Seed 与生图 Seed 相互独立，不静默兼容旧版本配方）。
