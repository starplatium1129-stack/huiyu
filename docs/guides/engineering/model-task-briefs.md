## 给 GLM-5.3-Flash：工作流与数据职责盘点

```text
你在 AI-CG-Studio 仓库工作。本轮完成耗时但可核验的工程盘点，为计划 006 的 W1 与 D1 提供实施依据。

先读取 AGENTS.md，检查 git status 与相关 diff，保留其他任务的修改。只读取影响决策的工程契约、工作流和计划 006。以当前源码为事实，不把计划描述或历史 PASS 当作当前实现证据。

任务一：逐项检查 scripts/workflow.js 的现有注册项，沿调用链找到实际脚本，记录命令、用途、运行机器条件、输入输出、前置条件、副作用、帮助/预览行为及续跑条件。复合命令展开到实际子步骤。不能只按命令名判断是否只读，尤其检查 full、check、dry-run 和 plan 的区别。

任务二：梳理人物档案、热门生成身份、服装、场景、蓝图、策展、参考索引和样张清单的数据职责。记录关键字段的权威源文件、聚合产物、构建入口、读取者与关联 ID。区分展示文案与模型输入。用脚本做数量、引用和重复 ID 检查；语义相似只标疑点，不自动判错或合并。

执行方式：先做 5 个工作流和 3 个角色的样例，自查证据准确性后继续覆盖全部实际注册工作流与全部数据域。无需等我逐批确认。按域分批处理，保留进度和机器可读结果，避免一次塞进整个仓库。无法确认的明确写未知与原因。

写入范围：仅 docs/research/engineering/glm-governance-inventory.md 和 glm-governance-inventory.json；一次性只读脚本放 scripts/archive/glm-governance/。不改共享索引，主任务统一登记。其余源码和生产数据只读。不得提交、push、安装、发布、调用出图、执行写数据的维护命令，或恢复暂停的场景审计。

验收：每项结论附实际文件路径、符号或字段及证据；统计必须来自运行结果，说明覆盖分母；用现有工作流审计验证入口，不为探测副作用实际运行危险命令。报告区分已确认问题、待核实疑点和建议，合并重复问题，最多列出 10 个最值得实施的改进。不得为凑数量制造问题。

最终告诉我：检查了什么、确证问题、执行命令与结果、未覆盖项、生成文件。完成盘点后停在报告阶段，不自行启动 W1/D1 的实现或架构重构。
```

## 给 Gemini 3.8 Flash：资产对账与桌面视觉初审

```text
你在 AI-CG-Studio 仓库工作。本轮建立可核验的图片资产账本，并对已有全年龄图片与界面做视觉初审，为计划 006 的 R1 资源分层提供依据。

先读取 AGENTS.md，检查 git status 与相关 diff，保留其他任务的修改。按需读取计划 006 的 R1、资产加载与桌面打包代码。用户主要使用 PC：4K 屏幕、Windows 150% 缩放。物理分辨率与 CSS 视口不能混为一谈。

任务一：沿实际 UI 引用和资源解析代码，对账每个人物的缩略图、基础展示图、高清立绘及已登记参考资产。记录实体 ID、路径、文件是否存在、尺寸、字节数、格式、哈希、引用位置、打包与回退路径。区分真实图片、占位、pending、无法访问；索引有 URL 不等于文件存在，更不等于已审核。外部素材目录不可访问时列出缺口，不下载补库。

任务二：先选 10 位有实际全年龄图片的角色作为视觉样例，覆盖不同图像比例、尺寸和背景。观察小图辨识度、透明边缘、人物被裁切、背景与主题适配、预览和原图是否对应。看不清的单独打开原图，不凭缩略联系表判断细节。不审核或改写露骨内容，不把机器初审当成人工发布批准。

任务三：如环境支持浏览器，使用现成隔离预览检查角色列表、详情与场景管理页，在深浅主题下检查 2560×1440 CSS 视口的布局，记录 deviceScaleFactor。也可以检查已有明确标注环境的截图；仅有截图不能证明真实滚动、网络回退或原生 DPI 行为。没有可用预览就如实标未执行，不启动安装版或修改数据。

产出资源分层建议：哪些必须随包保证离线首次进入可用，哪些适合基础预览或可选高清资源；给出实际源文件体积，不能冒充压缩后安装包体积。查重只列候选，不能删除、改名、移动或压缩原图。

写入范围：仅 docs/research/engineering/gemini-asset-audit.md 和 gemini-asset-audit.json；一次性只读脚本和联系表放 scripts/archive/gemini-asset-audit/。不改共享索引，主任务统一登记。不改生产数据、源图片、UI 代码、分级边界或打包清单。不提交或push、不发布、不配置托管、不调用生成模型。

验收：资产全量结构对账，视觉部分明确样本数量和实际看过的文件；问题附图片路径、可观察依据、影响页面和复核建议。不存在或看不到的图片标未知。不能仅依据模型主观评分宣称画质合格。若图片输入或浏览器工具不可用，完成结构部分并明确剩余缺口。

最终告诉我：实际覆盖范围、最值得处理的问题、资源体积分布、执行命令与结果、未验证事项和生成文件。不要扩大成全库重绘或新建资源下载系统。
```
