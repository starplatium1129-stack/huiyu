# 桌面陪伴：工具与配置

桌宠支持角色聊天、Live2D 动作、语音和本机工具。看屏与绘图分别需要兼容的视觉模型或已准备的绘图模型；源码接线不代表目标安装版和设备已经验收，待验范围见[规划](../../roadmap.md)。

内置角色支持按模型参数切换表情，恢复默认表情时保留衣装；互动好感度按实际动作映射计算，加载、语音忙碌、门控和播放失败有相应反馈。

## 工具与权限

| 工具 | 对应端点/实现 | 说明 |
| --- | --- | --- |
| `capture_screen` / `read_image` | `/api/desktop-tools` | 抓取 Windows 主屏画面或读取工作区图片；性能以实际设备测量为准 |
| `run_command` | `/api/desktop-tools` | 默认关闭；仅操作员启用 trusted 档后按当前系统账户权限执行，不是工作区沙箱 |
| `read_file` / `write_file` | `/api/desktop-tools` | 读写 AI 工作区内的文本、脚本和配置 |
| `generate_character_image` | 桌宠编排 → `/api/tasks/v1` | 复用当前模型和角色绑定，提交私人任务，完成后回送对话并入册 |
| `search_drawing_catalog` / `generate_drawing_batch` | `/api/tasks/v1/companion-draw` | 查询本机素材，沿用 Muse 的目录配方和参数校验，通过本机任务队列出图 |
| `generate_image_from_reference` | `/api/interrogate/raw` → `/api/tasks/v1` | 使用本机 PixAI 反推参考图，再按所选角色和工作台编译结果生成；可取消 |

文件工具解析实际链接目标，拒绝指向 AI 工作区外的目录联接；通用命令的启用和撤销见[启动与排错](../../../STARTUP.md#运行配置与凭据恢复)。进程起始目录、命令白名单和取消机制均不能当作操作系统级隔离。

## 聊天与视觉配置

在桌宠设置中选择 API 模式，填写所用服务的地址、模型名和密钥。地址可以是本地代理 `http://127.0.0.1:8317/v1`，也可以是兼容服务的端点。

看屏需要图像输入能力，工具调用需要兼容的流式 Function Calling；可用性和延迟按实际服务核对。项目预设维护在 `src/config/chatApi.ts` 与 `ChatApiSettings.vue`。

## 常用操作

### 看屏
* **操作**：在桌宠输入框右侧点击 **看屏幕**。
* **流程**：
  1. 优先通过本机网关调用 Windows GDI 截取主屏并编码 JPEG；失败时尝试浏览器分享屏幕，用户取消或设备不支持时返回失败；
  2. 将画面和文字发送给当前配置的视觉服务，由聊天模型根据角色设定回应。

### 陪看

在桌宠上点右键打开操作菜单，再点底部的「陪看」。浏览器里的桌宠舞台从右上角进入。确认面板显示的视觉 API 地址后，点击「选择共享画面」，可选某个窗口或系统提供的其他共享来源。绘遇在本机比较缩小后的画面，连续检测到明显变化才向该 API 发送一张压缩图。聊天或语音输入忙碌时让出位置，勿扰期间暂停主动短评。默认「少说一点」，可以切换到「适中」，也能点「看现在」主动请角色点评当前画面。

如果勾选「等共享声音停下再开口」，可在系统选择器允许提供共享声音。绘遇只用声音强度判断空档，声音不会随图片发送。实时配音开启且声线可用时，短评可以朗读。短评留在陪看面板，图片和短评均不写入聊天记录。暂停期间仍保留共享来源，点「结束共享」释放它。隐藏桌宠、切换角色或更换视觉连接都会结束本次共享。

### 手机聊天

在桌宠打开「设置 → 手机聊天连接」，也可以直接到控制面板的「服务与连接」。请保持电脑和绘遇后台在线。手机会话按平台、账号和陪伴角色独立保存，角色沿用绘遇内的设定。聊天读取保存为主机配置的 API，没有配置时尝试本机 Ollama。手机出图需要支持工具调用的聊天 API、本机绘图模型，以及房间工具的绘图权限。

**QQ 私聊**。在 [QQ 开放平台](https://q.qq.com/qqbot/) 创建支持长连接的机器人。把 AppID 和 AppSecret 填到绘遇，启用并保存。生成私聊口令后，在手机 QQ 的机器人私聊里发送形如 `/绑定 abc123def456` 的整条命令。进度与成图会回到私聊。如果一批图较多、自动送达失败，或出图超过 QQ 的原消息回复期限，可以发 `/取图` 收取剩余图片。 [QQ 长连接文档](https://bot.q.qq.com/wiki/develop/api-v2/dev-prepare/event-emit/websocket.html)

**QQ 群聊**。给机器人开通群聊权限并把它加进目标群。在绘遇的「QQ 群聊」生成口令，回到目标群，先 `@` 机器人，再发形如 `/绑定群 abc123def456` 的整条命令。每个已绑定的群有自己的对话和批次。群成员 `@` 桌宠就能聊天，勾选「允许本机绘图 → 已绑定的群聊」并保存后也能请求出图。发起人可 `@` 桌宠发 `/开始绘图` 或 `/取消`。QQ 群消息的回复期限是 5 分钟。超过期限、自动回传失败或还有更多成图时，在原群 `@` 桌宠发 `/取图`。可以在绘遇解除单个群的绑定。 [QQ 群消息官方文档](https://bot.qq.com/wiki/develop/api-v2/autogen/event/group_at_message_create.html)

**在 QQ 里和 Muse 聊天**。在「服务与连接 → 手机聊天 · QQ」里选择交给 Muse 的私聊和群聊。群友可以 @ 机器人，也可按需开启普通群消息接收和主动发信。Muse 能发文字、图片，或查询公开网页后回复。帮助和取图等命令仍由绘遇处理。设置页显示最近 90 秒是否收到 Muse 的收信请求。[远程连接指南](../independent-inference.md#让-muse-收发-qq-群消息)

**个人微信**。先在同一台电脑运行 OpenClaw，安装 [腾讯官方微信插件](https://github.com/Tencent/openclaw-weixin) 并扫码绑定 ClawBot。然后在绘遇启用微信桥接并保存，生成桥接密钥。以下命令在项目根目录运行，用于把仓库内的桥接插件装到已有的 OpenClaw。

```powershell
openclaw plugins install ./tools/huiyu-wechat-bridge
```

把绘遇的「复制桥接配置」内容写入 `plugins.entries.huiyu-wechat-bridge.config`，将 `accountId` 替换成官方 `openclaw-weixin` 通道的账号 ID，并启用 `huiyu-wechat-bridge`。如果启用了 `plugins.allow`，保留原有条目并加入 `huiyu-wechat-bridge`。在 ClawBot 私聊发绘遇复制的绑定命令。出图后发 `/取图`，有多页成图时发 `/取图 2` 等。若绘遇运行地址或桥接密钥变更，更新插件配置后重新加载。 [OpenClaw 消息接入文档](https://docs.openclaw.ai/plugins/hooks/messages)

QQ 和微信私聊都支持 `/帮助`、`/取图`、`/取消`。先预览的批次可发 `/开始绘图` 开始。手机回传可能压缩大图，原图仍可在绘遇作品册查看。

**普通微信群的 Muse 卡片**。群友从群里的小程序卡片提问或传图，Muse 回答后，由提问者点击分享回群。项目可独立导入微信开发者工具，通过微信云开发连接 Muse。[导入与开通群卡片](../../../tools/muse-wechat-card/README.md)

### 对话绘图与图片反推
* **操作**：直接对桌宠发送指令：
  - *“夏目，帮我画一张你在海边喝汽水的插画”*
  - *“画一张夏目的泳装插画”*
* **流程**：
  1. 模型识别出图意图，发起 `generate_character_image` 工具调用；
  2. 桌宠读取跨窗口共享的工作台绘图参数，复用当前内容库与 Anima/Krea 编译器；角色 LoRA 从受控绑定取得，不接受模型提供的任意 LoRA 字符串；
  3. 将冻结的提示词、参数与来源提交到私人任务队列，对话显示当前阶段；点停止会请求取消原任务，接收状态未知时只查原任务、不重复提交；
  4. 生成完成后图片进入当前角色对话与作品册，点击图片可放大查看。聊天和归档仅保存持久媒体引用，不保存临时 Blob URL 或 Base64 图片；
  5. 中文原意保存在 description，英文画面描述保存在 visualDescription，交给实际编译通道。历史草稿卡仍可到工作台编辑，新的绘图工具直接生成。

开启「房间工具」、准备好本机原生绘图模型后，可以在桌宠或角色聊天里说「查一下夏目的女仆装，用素材库里这套衣服画三张」。也可以选用现成的场景或蓝图，自定义尺寸和种子。每批最多 16 张，生成的图片发回对话并尝试入册。关掉对话不会停止出图。回到原来的窗口、角色和分支，说「取回上次的图片」即可查看原批次。要停止出图可以点停止，也可以在原对话里说「取消上一次出图」。本机新建或改过而没有配套配方的素材可以从画室生成。

想确认后再画，可以说「先给我看三张的出图方案」。出图卡会列出每张的模型、尺寸和种子，可以逐张调整提示词，点「开始绘图」后才会排队。卡片随对话保存，回来能继续看进度和成图。一批结束后，可以单独重试失败的那张，或者重绘某张成图。新版出图前保留旧图，已入册的作品仍可从作品册查看。

独立聊天窗可选择、粘贴或拖入 PNG/JPEG/WebP 图片，先预览、移除，实际发送时保存原图。输入文字后发送会交给当前视觉聊天模型；点击「反推并生成」直接使用本机 PixAI 与绘图模型，不要求视觉聊天模型连接。反推保留服装、姿势与背景，默认以当前陪伴角色重新生成；它不是保留像素的图片编辑。也可在聊天中要求反推最近发送的图片并绘图。「看屏幕」与语音输入继续沿用各自服务；语音检测模型列表不代表真实录音识别已通过。

### 好感度与动作
* 互动按选中动作映射的 `bonus` 加分；部分摸头 / 摸手动作为 +5，专属动作或无奖励动作不承诺每次加分；
* 满分（100 分）解锁原作者专属告白动作（萌萌Q、喝茶邀请、我爱你）；
* 好感度徽章在顶部药丸实时显示当前等级与点数。
