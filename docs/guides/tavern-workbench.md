# 深度酒馆工作台

从首页进入「角色房间」，或在角色详情点「角色房间」。聊天区的「更多聊天操作」连接角色卡、世界书、玩家身份、记忆和归档。发送消息前，在房间设置里连接兼容 API、本机模型或 Muse。模型地址和选项见[房间 API 连接](setup-and-models.md#6-房间-api-连接)。

## 建立角色与世界

1. 选择「导入角色卡（PNG / JSON）」读取 Tavern V2 角色卡，也可以从「角色卡工作台」新建。可编辑角色描述、性格、场景、开场词和卡片内置世界书。卡片列表可导出 Tavern V2 JSON 或带嵌入数据的 PNG，便于在其他兼容客户端复用。
2. 进入「世界书管理」创建独立世界书或导入 SillyTavern World Info JSON。按设定配置关键词、正则、全词匹配和插入位置。可以设置单轮字数预算与递归扫描。消息菜单显示本轮实际命中的条目，方便核对触发效果。
3. 在「我的马甲与档案」切换玩家身份。进入「RP 预设与导演指令」可以配置扮演方式。

## 维持长剧情

- 在「记忆与前情摘要」查看手动保存的记忆、编辑前情提要，或开启自动滚动摘要。把关键人物关系、决定和未完成事件写进提要，便于后续续写。
- 较早消息进入「对话归档」。导出 JSON 可留作备份，Markdown 便于阅读。导入归档后，可以把当前剧情的旧消息并回对话。
- 房间可按设置同步好感与状态。为导入卡片准备情绪立绘后，房间会随对话情绪切换立绘。消息操作支持单句场景配图，角色房间也可接入语音与动态背景。请先准备对应的模型或服务。
