## 当前交付边界

源码沿用 Vue 3 / Vite / TypeScript / Pinia、Express 网关及 Tauri 2 桌面壳，覆盖角色/场景、绘图工作台、作品册、聊天/语音、Live2D 和视频分镜。SD、Anima、Krea 2 保留独立请求与编译路径；深浅主题、响应式界面及页面懒加载已有实现。

A01–A05 的聊天存储、流式合并、远程自配目标边界及绘画工具结果声明已按行为回归修复。角色绘画工具目前只准备草稿，真实任务接线尚未完成。训练页不在当前路由中，粒子肖像继续保留。

9 月 15 日导航优化及后续清理尚未同步安装版；没有修改提示词、分级、场景源数据或迁移用户作品，也没有完成真实出图、WebView2/多屏及 GPU 验收。各批次“通过”只覆盖其记录的环境与文件，不等于全站全部状态或设备交付完成。
