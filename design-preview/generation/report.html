当前最影响观感与使用的 7 处

以下结论来自本轮真实页面与源码，定位到具体区域；缺失样张不计入这七项。

01 / 页头

模式与工具挤在同一条视觉线上

场景 / 专家、专注、布局、灵感骰子和数据工具紧靠排列，重要程度接近。保留主要模式与布局按钮，将低频工具收进有文字名称的“更多工具”。

02 / 左右侧栏

画面描述有两个定位入口

左侧“描述”与右侧“编辑画面描述”指向相同内容，但右栏按钮看起来像单独工具。原型将描述统一留在素材域，并在当前场景旁给出明确入口。

03 / 类别与选项

不同层级反复使用凸起胶囊

素材分类、角色来源、引擎、模式都近似“选中小卡片”，层级难区分。一级分类用下划线，互斥模式保留分段控件，角色保留图片选择卡。

04 / 右栏

模型与画幅相距太远

2560 视口下常用设置集中在顶部，画幅留在很靠下的生成条，中间出现大片空档。把画幅与模型放在同一个滚动参数区，底部只固定状态和生成。

05 / 高级调整

折叠后看不到当前配方

现有“高级调整”只露出标题，检查步数或 CFG 必须展开。原型在收起状态显示紧凑摘要，具体字段仍渐进展开。

06 / 离线反馈

问题说明与恢复位置分离

顶部“未连接 / 控制面板”与右下角禁用原因相隔较远。对比状态将可点击的恢复入口放在禁用生成按钮旁，色彩之外始终有文字说明。

07 / 1280 窗口

三栏同时收窄损害信息完整性

角色来源标签换行，长模型名称被省略，参考信息被迫挤成短行。原型优先保留画布和参数；素材按需切换显示，长选项允许换行。

组件规则与状态

规则这一版的实现
视觉层级完整作品占据中央；两侧为不透明操作面。只给生成主动作使用实心强调色，选中类别用线条与文字同时表达。
尺寸与文字24px 页标题、16px 面板标题、14px 正文 / 主要按钮、13px 常规控件、12px 说明。基础控件 40px、紧凑按钮 36px、生成 46px；10px 控件圆角、16px 面板圆角。4 / 8 / 12 / 16 / 24px 间距。
现有变量直接导入 design-system.css 与 light-theme.css。深色保留当前实际蓝灰底，浅色保留暖纸与玫红；画布使用既有 --art-stage。没有改写正式全局变量。
参数与窄窗模型及全部合法尺寸来自 runtime-rs/src/images/catalog.json。大窗栏宽可拖动，聚焦分隔柄后左右键微调、Home 复位。1440px 以下素材按需与画布切换；参数区独立滚动，生成条固定可见。
状态反馈默认 / hover / selected / focus-visible / disabled / running / failed 均有明确形态。禁用文字使用 --text-disabled，不降低整体透明度。浮层沿用 StudioSelect / StudioPopover，图片使用原生 dialog 的模态焦点行为。
动态与画面无常驻装饰动画、无高成本模糊。控件反馈 150ms；减少动态效果时取消过渡。画布 object-fit:contain，横竖原图完整保留，不随输出画幅裁剪。
