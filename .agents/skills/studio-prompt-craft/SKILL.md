# Studio Prompt Craft

将用户意图写成模型能够执行的画面描述，保留身份、服装、人数、分级和构图。协作与授权遵循 [AGENTS.md](../../../AGENTS.md)；本 skill 不扩展任务范围。

## 按任务读取

- MiaoMiao 1.6：读 [版本规则与作者依据](references/miaomiao-v16.md)及 [Anima 输入与编译](references/anima.md)。其他 Anima checkpoint 只读后者，不能套用 1.6 的配方。
- Krea 2 提示词或编辑描述：读 [Krea 规则](references/krea.md)。
- 叙事 CG 或单人物立绘／特写壁纸的构图与完成度：再读 [构图参考](references/narrative-composition.md)，按目标进入叙事或壁纸规范。
- 手机竖屏壁纸：读 [手机规范](../../../docs/guides/prompts/mobile-wallpaper-prompt-standard.md)；成年角色非露骨题材或中性一致性排查：读 [稳定性研究](../../../docs/research/prompts/adult-nonexplicit-cg-reliability-2026-09-13.md)。
- 成年角色成人向／NSFW 场景与蓝图规范：读 [NSFW 规范](../../../docs/guides/prompts/nsfw-cg-prompt-standard.md)（严格遵循 adult 资格与本地宿主放行）。
- 写入仓库、批量重写、换装/生成验收或定稿：再读 [字段与交付](references/delivery.md)。纯草稿不要求启动仓库工作流或出图。
- 仅在解释其他引擎能力或历史规范冲突时查 [双引擎提示词研究](../../../docs/research/prompts/anima-krea2-narrative-cg-research-2026-09-12.md)。其中 MiaoMiao 作者页未核验的历史限制由本 skill 的 1.6 版本参考补充，不覆盖其他 checkpoint；无需默认加载所有历史指南。

## 写作与审查

1. **确认实际输入条件。** 从任务和当前配置取得 modelId/checkpoint、profile、LoRA、画幅和参考用途。项目当前默认为 MiaoMiao 1.6，历史配方或显式选择优先；不能只凭“Anima”推断版本。只输出需要的引擎，共享蓝图变更才核对双引擎。
2. **先确定可见画面。** 明确主体数量与身份、当前衣装、主动作及接触物、表情、关键环境、镜头与光源。环境叙事 CG 必须按[构图参考的背景与光影检查](references/narrative-composition.md#背景与光影的编写检查)写出可见背景、空间关系和具体受光关系；地点名或光源名不足以代替画面设计。抽象情绪转成可见行为；多人分别绑定外貌、位置和动作。补充服务于原意，不增加题材配额、固定主体比例或装饰物数量。
3. **按目标模型表达。** Anima 支持标签、自然语言和混合写法；按用户习惯及关系复杂度选择，不强制只用标签。标签写可辨认的元素，英文句子写谁在何处做什么、物件如何接触及光从何处来。画师、媒介与上色风格按明确选择或场景要求写入；画师完全可选，不能用画师词替代背景与光影设计，未选不强制添加画师或平涂词。不要把完整句子连成下划线伪标签，也不要用多句“精致、惊艳、电影感”替代事件。Krea 沿用其独立 prose 契约。
4. **分离身份和可变内容。** 现有角色/服装/蓝图的 ID 与稳定身份从当前内容库读取，精确触发词保持原样。衣装、动作、环境进入对应字段，换装清除旧衣装冲突；热门无 LoRA 与宁宁/夏目 LoRA 路径分开。对白仅在用户要求画面文字时进入 prompt，并保留原文与位置。
5. **统一分级、镜头与词义。** 质量词由对应 profile 管理，分级由场景资格与项目字段决定，肤色由角色决定。审查标签与句子是否对人数、左右位置、全身/特写、动作和光源给出同一要求；负向不能排除需要的人物、文字或构图。先修正正向矛盾，再补针对实际问题的负向。
6. **核对最终编译而非只看原文。** 检查正向的普通标签格式、评分词与 exact tokens、背景及光影关系句是否保留，以及上层实际装配的负向。只存在于维护字段或未消费 hint 的内容不算已经送给模型；环境 CG 若仍只有地点与笼统光照词，先补正文再定稿。官方建议与项目现有 profile 有差异时明确报告；维护 skill 不等于修改生产 profile 或编译器。没有对应 checkpoint 的实际画面证据，不承诺短语或参数一定改善画质。

## 输出边界

- 遵守仓库分级边界；处理全年龄、明确成年角色的非露骨创作与中性一致性审查，不提供露骨内容扩写配方。分级词不是成年依据，也不扩展模型调用授权。
- 草稿给出目标版本、必要假设、正向与负向策略；注明是否实际编译/出图。官方事实、项目当前行为与待实测建议分别说明，字符数不当作 Token 数。
- 数据定稿遵循交付参考，以最终请求与真实画面为证据。仅修改 skill 时检查结构、链接及规则一致性，不能把文档通过当成生成质量通过。
