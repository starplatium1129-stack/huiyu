# 画面构图与视觉设计规范

适用于全分级叙事 CG、单人立绘与特写场景设计。

## 1. 核心构图准则

- **角色与意图依据**：从角色身份、性格与当前服装出发，以可见姿态、表情与道具体现性格；用户指定的换装或平行设定优先。
- **先定视觉中心，聚焦单一片刻**：先明确观者第一眼看到的事件与空间焦点；呈现**同一瞬间**（避免把“取出又递出”等先后动作强塞入单帧），并确保动作、支撑、接触点与视线能同时成立（多人按主体分别绑定，分格按格定瞬间）。
- **题材重点**：
  - **叙事 CG**：人物与环境/道具互动、接触点、视线引导与光影氛围。
  - **单人立绘 / 壁纸**：人物轮廓、微表情、服饰材质与合理留白（纯色或安静背景同样高级）。
  - **亲密 / NSFW**：姿态体位、肢体交叠、局部焦点与氛围光线。

## 2. 空间、光影与双引擎呈现

- **景别与背景取舍**：取景须容纳关键动作与道具；明确前后遮挡关系，特写不强求全身或庞大环境，不堆砌无意义光效杂物。
- **主次光照与材质**：交代主光源方向（`window light`、`dappled sunlight`、`candlelight`、`dim lighting`），多光源须分清主次与区域；写出特定材质在当前光下的真实质感（湿发高光、雨滴玻璃、薄纱透光），避免全画面同等发亮。
- **双引擎差异**：
  - **Anima**：普通标签搭起景别、视角、动作、道具与光源骨架，末尾用 ≤ 2 句英文补足标签难表达的接触、视线与受光细节。
  - **Krea 2**：用连贯英文散文写出画面透视、站位与光影材质，禁用碎片堆词。
