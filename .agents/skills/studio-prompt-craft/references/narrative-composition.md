# 画面构图与视觉设计规范

适用于叙事 CG、单人立绘特写及各类分级场景的画面构建。

## 1. 核心创作原则

- **角色依据**：读取角色身份、性格、偏好及当前服装上下文，从中选择场景与行为；用可见的姿态、道具或表情表现性格。用户指定的换装、反差或平行设定优先，不把新编对白和剧情当作官方事实，也不把偏好变成固定场景模板。
- **先定视觉中心**：先明确观者应看到的核心事件或主体关系，再选择动作、景别与环境。道具、背景和光效各自应帮助表达事件、建立空间或衬托主体；按画面需要取舍，不固定标签数、道具数或构图。
- **聚焦单一片刻**：画面应呈现一个清晰、生动的可见瞬间，避免将连续动作（如“取出又递出”）机械叠加在同一张图内。
- **动作可同时成立**：明确谁在做什么、朝向谁，必要时交代手持、支撑、接触点及视线目标；避免同一只手承担不相容任务。无互动的画面无需额外安排手部动作，多人按主体分别描述，分格按格分别确定片刻。
- **构图服务主题**：
  - **叙事 CG**：突出人物与环境的互动、道具接触、视线方向以及光影氛围。
  - **单人立绘 / 桌面壁纸**：突出人物轮廓、神态微表情、服饰细节与合理的留白。
  - **亲密 / NSFW 场景**：突出人物姿态、肢体交叠、触碰重点与特定氛围光照。
- **全分级自由编排**：单人、多人（`compositionIntent: group`）、分格叙事（`triptych`）以及全景/特写均对全分级开放自由编排。

## 2. 空间与光影设计

- **环境与背景**：背景元素紧扣当前场景事件，避免无目的堆砌无关杂物或光效。立绘与特写场景允许极简背景或静谧色块，纯粹留白同样具有高级美感。
- **景别与空间**：让取景范围容纳关键动作与道具；明确必要的前后、遮挡和远近关系。特写不同时要求完整全身和大幅环境，背景复杂度与清晰度服从视觉中心。
- **光照系统**：
  - 明确主光源来源与方向（如 `window light`, `dappled sunlight`, `candlelight`, `dim lighting`）。
  - 让光照自然作用于角色与关键物件，产生合理的明暗层次。
  - 多光源可按场景共存，但要分清主次、方向与覆盖区域，避免无节制地强加“全套光效”。
- **色彩与材质**：结合发色、肤色和服装安排背景色与光色，检查人物是否清楚可辨；冷暖、明暗或同色层次均可，不固定配色。选择与事件相关的材质细节，并描述其受光方式，如湿发上的高光、玻璃后的雨滴、薄纱透光，避免只罗列材质名称或让所有表面统一发亮。

例如“雨天窗边双手捧杯”：核心是人物捧杯望窗的片刻，半身景别容纳脸、双手与杯子，窗上雨滴建立雨天环境，室内暖灯与窗外冷光在人物上形成层次。换成其他角色或地点时重新设计这些关系，不复制整句或同一套光效。

## 3. 双引擎表达要点

- **Anima**：
  - 普通标签构建骨架：景别（`close-up`, `cowboy shot`, `full body`）、视角（`from above`, `profile`, `view from behind`）、核心动作、关键道具与环境光。
  - 末尾可选简明英文，通常 1–2 句，补充肢体接触、细微视线、材质受光或空间关系；不重复整段标签，也不为控制句数删除必要关系。
- **Krea 2**：
  - 以自然英语完整描述画面：空间透视、人物位置（左/右/中央）、光线在物体上的投射以及材质质感。
  - 避免碎片化 tag 拼接，形成连贯的画面意境。
