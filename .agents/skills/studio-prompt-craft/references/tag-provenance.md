# D/G 标签溯源与语义保真

适用于 Anima 与 MOSS 的结构化正负向标签（Krea 散文、`promptProse`、`animaCaption`、质量配方及精确控制词按模型契约单独核对）。

## 1. 来源依据

- **凭据要求**：普通标签须有 Gelbooru（优先）或 Danbooru 的标签记录/本地缓存凭据（含规范名、原站链接、核验时间、类别及正数收录量，别名需映射）；仅凭英文合理、模型建议或本地词库存在不构成 D/G 凭据。
- **写回与保护**：核验原始数据与缓存放 `runtime/`，严禁伪造凭据或新建报告文件；专名、作品与画师触发词保持准确拼法，不跨身份替换。

## 2. 自动纠正边界

- **已核验词 / 可信别名**：归一到规范词并保留原权重与空格编译约定，核对最终正负向编译结果。
- **自组短语拆解**：仅当拆解后的基础词全部具备 D/G 凭据且动作、对象、材质与情绪不丢失时才拆解，细微关系保留在自然语言补充中。
- **未核验或歧义词**：**不等同于“自创/错误”**——已有条目保留待核状态，绝不靠猜删改；新写内容改用已核验基础词 + 自然语言。
- **负面标签**：替换须维持原有排除范围，禁止将单一否定短语拆成多个宽泛禁用词而误伤画面。

## 3. 批量处理原则

- 优先复用本地词库与缓存并去重，联网查词设有限超时；单站不可用或缺失时保留待核项并继续确定条目，不阻断整批处理。
- 纠偏后核对核心视觉事实（人数、身份、着装、姿态、接触、视线、景别、光源）未漂移；尊重用户已满意画面及定稿保护。
