# D/G 标签溯源与语义保真

适用于 Anima 和 MOSS 的结构化普通标签及负面标签。Krea 散文、`promptProse`、`animaCaption` 等自然语言无需逐词匹配词库；质量配方、LoRA 触发词、布局语法等控制项依据模型或项目契约单独核对。

## 来源依据

- 普通标签新增或替换为规范词时，使用 Gelbooru / Danbooru 的标签记录或已缓存的可信凭据；两站选其一即可，优先 Gelbooru，另一站可补充。不能仅凭英文自然、模型建议或项目词库收录就宣称有 D/G 来源。
- 复用项目已有核验数据，来源凭据包含规范名、D/G 原站链接、核验时间、类别及正数收录量。别名需另有可追溯的别名映射。来源存在只证明标签可追溯，仍需确认其含义符合当前画面。
- 新核验的原始结果及缓存沿用现有工具放入被忽略的 `runtime/`；不得伪造核验时间、来源链接或收录量，不新增报告文件。专名、作品和画师保留准确触发写法，不能为了匹配词库替换成另一个身份。

## 自动纠正的边界

- **已核验词**：保留规范含义；显示层可按编译约定使用空格，精确词及权重保持原语义。
- **可信别名**：自动归一到有凭据的规范词，保留权重，核对正负向与最终编译结果。
- **可等价拆解的自组短语**：仅在目标基础词均有凭据、且动作、对象、材质与情绪不丢失时拆解；细微关系可保留在已有自然语言中。需要补写时按本场景真实重写，不追加通用模板句。
- **未核验或有歧义**：不等同于“自创”或“错误”。已有内容保留待核状态，不猜测删除或换成近义词；新写内容改用有凭据的准确基础词，并用自然语言补充其余细节。不存在等价表达时保留不确定性，不冒充完成纠正。
- **负面标签**：拆解可能扩大排除范围，不能照搬正向规则。替换必须保持原排除范围，不把一个短语拆成多个独立禁用概念。

## 高效处理

- 先读本地可信词库与核验缓存，只对缺失项按需联网；批量去重、复用结果，不逐场景重复请求相同词。
- 联网设置有限超时；某站不可用时复用本地凭据、按需尝试另一站，仍不可用则保留待核项并继续可确定的纠正，不无限重试、不阻断整批。
- 纠正前后比较核心视觉事实：人数、身份、服装状态、姿态、持物、交互方向、视线、景别和光源。规范化不得悄悄改变这些事实；冲突仅影响相关条目，其余继续。
- “标签有来源”“最终编译正确”“真实画面满意”分别确认，不能互相代替。用户已认可的画面不因标签数量、句数或笼统的质量判断批量重写；遵守定稿保护。
