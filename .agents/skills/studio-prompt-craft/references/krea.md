# Krea 2 自然语言提示词规范

适用于本地 Krea 2 引擎。

- **文风与结构**：输出连贯具象的英文散文（清除标签堆叠、括号权重与 `masterpiece`/`8k` 等质量词），按 `画面媒介与主体 → 身份与衣着状态 → 动作与空间互动 → 环境与光影 → 镜头景别` 自然组织。
- **全分级表达**：对日常到亲密/NSFW 题材均使用准确具象的自然英语描述身体状态与接触关系。
- **字段组装**：由角色 `identityProse`、服装 `prose`、蓝图 `promptProse`（或 `nsfwProse`）、场景 `prompt` 与导演设置共同拼合；需确保环境、道具与镜头在 prose 中完整保留，避免机械堆砌 `wearing ...`。
- **负面与参数**：本地分支默认 `negative = ''`，排除项改写为明确正向目标状态（如 `a single person in a quiet room`）；采样参数以本地实际工作流为准。
