# Krea 2 自然语言提示词规范

适用于本地 Krea 2 引擎的画面描述编写与审查。

## 1. 核心编写原则

- **纯英文自然语言**：输出连贯、富有表现力的自然英语散文，彻底清除 Danbooru 堆词、括号权重及质量评分词。
- **结构化画面叙事**：
  `画面媒介与主体 → 身份与穿着状态 → 动作姿势与空间互动 → 环境与光影氛围 → 镜头与景别`
- **全分级自由创作**：支持从全年龄风景/日常到各类亲密、敏感、NSFW 场景的自由创作，以准确、具象的自然语言描述角色状态、衣装变化或身体细节。

## 2. 字段映射与消费

- 最终请求由 `identityProse`、服装 `prose`、蓝图 `promptProse`（或 `nsfwProse`）、场景 `prompt` 与导演设置共同组装。
- 散文应完整描述关键动作与空间关系，避免机械堆叠“wearing ...”碎片。
- 当蓝图精简时，Krea 端需确保关键环境、道具、镜头和光照在 prose 中保留完整的自然叙述。

## 3. 参数与负面策略

- **负面提示词**：本地当前分支默认 `negative = ''`，依靠清晰完备的正向描述界定画面，无需盲目填写负面词。
- **排除项表达**：如有排除需求，优先以正向的目标状态描述（如 `a single person in a quiet room` 代替机械的否定句）。
- **参数依据**：以本地 ComfyUI 工作流实际参数为准，不照搬未适配的官方示例参数。
