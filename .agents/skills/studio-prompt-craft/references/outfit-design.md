# 角色服装设计规范

适用于热门角色与原创角色衣柜企划、服装重塑与提示词校验；全分级（SFW / Sensitive / NSFW / R18）自由创作均须遵循。

## 1. 衣柜差异度与防撞车红线

- **按人设独立企划**：严禁跨角色套用“泳装 + 蕾丝睡裙 + 落肩针织 + 全裸”八股模板。围绕角色的世界观、职业身份、时代美学、标志色系与性格反差设计穿搭层次。
- **同角色明显区分**：同一角色任意两套服装必须在「廓形 / 场合 / 主色系 / 材质」中至少拉开 2 项差异，归一化 `tokens` 重合度原则上 `< 40%`。
- **道具与穿脱动作不单拆服装**：摘眼镜、摘面具、不撑伞、不拿团扇或零食、半褪外衣等瞬态变化写入蓝图 `action` / `promptProse`，严禁仅因少一件道具复制同一套服装。
- **SFW 穿搭均衡**：单角色 SFW 常规蓝图应覆盖 ≥ 3 套风格迥异的服装，避免 ≥ 60% 全部绑死默认制服；亲密/寝衣/裸露形态同样需贴合人设材质与光影气质，避免跨角色千篇一律的空壳命名（如 `silver_lace_lingerie`、`silver_summer_bikini`）与只写 `["nude"]` / `"No clothing."` 的敷衍占位。

## 2. 五要素设计感结构（非全裸建议 `6–10` 词）

1. **主廓形与层次**：外套、内搭、腰线与裙裤长度/剪裁（如短款翻领夹克配高腰百褶宽裤）。
2. **色彩配比**：主色 + 中性过渡色 + 角色点缀色（控制 2–3 色，避免全白或全黑平铺）。
3. **面料与工艺细节**：精挑 1–2 个能出图的质感特征（如粗花呢、府绸、真丝滚边、压褶、铜扣、暗纹刺绣），避免堆砌空洞高频词。
4. **标志性配饰**：胸针、领结、发带、腰封、颈链、腕表或袖扣等强化角色记忆点。
5. **鞋袜落脚点**：明确袜型（及膝袜/裤袜/裸足）与鞋型（乐福鞋/短靴/玛丽珍等），保证全身或七分身构图完整。

## 3. 词条与命名洁净度

- **标准标签格式**：`tokens` 统一使用小写英文、**空格分词**的可出图 D/G 视觉词，避免下划线混杂，严禁 ≥ 4 词英文散文碎片（如 `century-old comfort`、`elf ears friendly`、`king of knights style`）或抽象氛围形容词；`prose` 必须为**自然英文**（禁止中文），供 Krea 2 / MOSS 直接拼装。
- **严格隔离外貌与环境**：服装 `tokens` 与 `prose` 只描写衣物、材质与发饰/配饰（如发带、发夹、颈圈、帽子），严禁混入角色固有外貌（发色、发型、瞳色、兽耳、精灵耳、泪痣、身材/表情词）或场景天气、时段、光源与地点。
- **中文命名直观准确**：直接体现核心色调、面料/剪裁与单品组合，不使用空洞营销词或跨角色复制模板名与 ID。
- **代码硬校验 vs 人工审校边界**：落库时 `prompt_guard.rs` / `popular.rs` 硬拦截 16 个环境词（`beach`/`summer`/`classroom`/`bedroom` 等）与工作室角色名泄漏，渲染层 `wardrobeContent.ts` 静默过滤其余天气/时段/光影/地点词；重合度 `< 40%`、6–10 词、全裸非占位、无中文 `prose` 与无外貌泄漏属人工/批审红线。
